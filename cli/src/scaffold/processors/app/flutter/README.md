# Flutter app owner

## Responsibility
Writes Dart widget, test target and web platform shell. The parent dispatcher selects this owner only for the explicit flutter key.

## Phạm vi
Ghi Widget Dart, target test và khung platform web. Dispatcher cha chỉ chọn owner này khi key flutter được yêu cầu tường minh.

## Boundary
This owner does not resolve templates, install dependencies or execute external tools.

## Ranh giới
Owner này không resolve template, cài dependency hoặc chạy công cụ bên ngoài.

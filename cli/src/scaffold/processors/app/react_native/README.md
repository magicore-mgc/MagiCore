# React Native app owner

## Responsibility
Writes Expo metadata and JavaScript entrypoints. The parent dispatcher selects this owner only for the explicit react-native key.

## Phạm vi
Ghi Metadata Expo và entrypoint JavaScript. Dispatcher cha chỉ chọn owner này khi key react-native được yêu cầu tường minh.

## Boundary
This owner does not resolve templates, install dependencies or execute external tools.

## Ranh giới
Owner này không resolve template, cài dependency hoặc chạy công cụ bên ngoài.

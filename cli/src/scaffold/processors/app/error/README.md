# App scaffold errors

## Responsibility
Owns the typed unsupported-framework result while preserving the existing English diagnostic. I/O errors keep their anyhow source chain.

## Phạm vi
Sở hữu lỗi typed khi framework không được hỗ trợ và giữ diagnostic tiếng Anh hiện tại. Lỗi I/O giữ source chain anyhow.

## Recovery
Select an explicitly supported framework or invoke the separate multi-platform route.

## Khôi phục
Chọn framework được hỗ trợ tường minh hoặc gọi route đa nền tảng riêng.

# Bevy fallback writer

Writes the built-in fallback `Cargo.toml` and `src/main.rs`. The package name still uses the shared `slugify` helper, and file creation still uses `write_file`.

Ghi `Cargo.toml` và `src/main.rs` của fallback có sẵn. Tên package vẫn qua helper `slugify` dùng chung và tạo file qua `write_file`.

# .NET library scaffold

## Responsibility
Creates an SDK-style `.csproj` and a minimal C# library source. It does not invoke the .NET SDK.

## Phạm vi
Tạo `.csproj` kiểu SDK và source thư viện C# tối thiểu. Không gọi .NET SDK.

## Tests / Kiểm thử
The nearest source tests are in `test/`; they are source-only until repository-wide refactoring closes.

Test gần owner nằm trong `test/`; hiện chỉ là source cho tới khi refactor toàn repo hoàn tất.

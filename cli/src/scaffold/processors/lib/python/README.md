# Python library scaffold

## Responsibility
Creates setuptools `pyproject.toml`, a `src` package, a pytest import smoke test, and a local src-layout conftest. It does not install the package or invoke Python tooling.

## Phạm vi
Tạo `pyproject.toml` dùng setuptools, package theo `src`, test import bằng pytest và conftest cho src-layout. Không cài package hay gọi Python tool.

## Tests / Kiểm thử
The nearest source tests are in `test/`; they are source-only until repository-wide refactoring closes.

Test gần owner nằm trong `test/`; hiện chỉ là source cho tới khi refactor toàn repo hoàn tất.

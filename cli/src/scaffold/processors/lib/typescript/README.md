# TypeScript library scaffold

## Responsibility
Creates an ESM package manifest, strict declaration-emitting tsconfig, and `src/index.ts`. It does not install dependencies or run `tsc`.

## Phạm vi
Tạo package ESM, tsconfig strict có declaration và `src/index.ts`. Không cài dependency hay chạy `tsc`.

## Tests / Kiểm thử
The nearest source tests are in `test/`; they are source-only until repository-wide refactoring closes.

Test gần owner nằm trong `test/`; hiện chỉ là source cho tới khi refactor toàn repo hoàn tất.

# Go library scaffold

## Responsibility
Creates a Go module, a minimal exported `Hello` function, and its assertion test. It does not invoke the Go compiler.

## Phạm vi
Tạo Go module, hàm `Hello` export tối thiểu và test assertion. Không chạy Go compiler.

## Tests / Kiểm thử
The nearest source tests are in `test/`; they are source-only until repository-wide refactoring closes.

Test gần owner nằm trong `test/`; hiện chỉ là source cho tới khi refactor toàn repo hoàn tất.

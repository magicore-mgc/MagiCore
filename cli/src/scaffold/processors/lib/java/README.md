# Java library scaffold

## Responsibility
Creates a Maven `pom.xml` and a minimal Java library source. It does not invoke Maven or a JDK.

## Phạm vi
Tạo Maven `pom.xml` và source thư viện Java tối thiểu. Không gọi Maven hoặc JDK.

## Tests / Kiểm thử
The nearest source tests are in `test/`; they are source-only until repository-wide refactoring closes.

Test gần owner nằm trong `test/`; hiện chỉ là source cho tới khi refactor toàn repo hoàn tất.

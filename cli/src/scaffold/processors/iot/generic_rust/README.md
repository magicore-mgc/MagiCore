# Generic Rust writer

## Responsibility
Minimal Cargo manifest and no_std Rust entrypoint used by the current fallback arm.

## Phạm vi
Manifest Cargo tối thiểu và entrypoint Rust no_std của nhánh fallback hiện có.

## Boundary
This owner writes only its own output files and does not start external build tools.

## Ranh giới
Owner này chỉ ghi file output của mình và không chạy công cụ build bên ngoài.

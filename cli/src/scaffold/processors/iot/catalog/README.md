# IoT board and framework catalog

## Responsibility
Owns the explicit supported framework set, public board-to-generator aliases and default board per generator.

## Phạm vi
Sở hữu danh sách framework hỗ trợ tường minh, ánh xạ board công khai sang generator và board mặc định theo generator.

## Boundary
This catalog does not generate files or decide template-registry availability.

## Ranh giới
Catalog này không sinh file và không quyết định template registry có sẵn hay không.

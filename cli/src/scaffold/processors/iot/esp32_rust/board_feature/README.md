# ESP-HAL board feature mapping

## Responsibility
Maps only the three board names with verified ESP-HAL features. Unknown boards return the local typed error.

## Phạm vi
Chỉ ánh xạ ba board có ESP-HAL feature đã xác minh. Board lạ trả về lỗi typed cục bộ.

## Boundary
This owner performs no registry lookup and makes no claim that the hardware toolchain is installed.

## Ranh giới
Owner này không tra registry và không khẳng định toolchain phần cứng đã được cài.

# ESP-HAL Rust writer

## Responsibility
Cargo manifest with the selected verified feature and the embedded Rust entrypoint.

## Phạm vi
Cargo manifest với feature đã xác minh và entrypoint Rust embedded.

## Boundary
This owner writes only its own output files and does not start external build tools.

## Ranh giới
Owner này chỉ ghi file output của mình và không chạy công cụ build bên ngoài.

# ESP-HAL local errors

## Responsibility
Owns the typed unverified-board failure while retaining the existing English diagnostic.

## Phạm vi
Sở hữu lỗi typed cho board chưa xác minh và giữ diagnostic tiếng Anh hiện có.

## Recovery
Choose one of the three board features declared by the IoT catalog.

## Khôi phục
Chọn một trong ba feature board đã khai báo trong catalog IoT.

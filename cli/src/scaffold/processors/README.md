# Scaffold processors

## Purpose

Owns native scaffold writers per core. `write_file`/`slugify` are the only shared helpers; each core processor owns its own framework subfolders and README.

## Vietnamese

Owner writer scaffold native theo core. `write_file`/`slugify` là helper dùng chung duy nhất; mỗi processor core sở hữu thư mục framework và README riêng.

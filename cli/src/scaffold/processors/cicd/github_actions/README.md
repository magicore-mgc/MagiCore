# GitHub Actions output owner

## Responsibility
CI workflow with pinned checkout, verified MagiCore CLI installation and opt-in trusted OIDC publishing.

## Phạm vi
Workflow CI với checkout pin, cài MagiCore CLI đã verify và publish OIDC trusted opt-in.

## Boundary
This owner writes only its provider output and does not invoke the provider CLI.

## Ranh giới
Owner này chỉ ghi output của provider và không gọi CLI của provider.

# Cloudflare Worker output owner

## Responsibility
Wrangler configuration and JavaScript Worker entrypoint.

## Phạm vi
Cấu hình Wrangler và entrypoint Worker JavaScript.

## Boundary
This owner writes only its provider output and does not invoke the provider CLI.

## Ranh giới
Owner này chỉ ghi output của provider và không gọi CLI của provider.

# Web container resource-name owner

Generates the stable Web container image and Kubernetes resource name. It enforces the Kubernetes DNS label byte limit and adds a deterministic BLAKE3 suffix when the readable slug is too long.

## Tiếng Việt

Sinh tên image container Web và tên resource Kubernetes ổn định. Owner giữ giới hạn byte DNS label Kubernetes và thêm hậu tố BLAKE3 xác định khi slug đọc được quá dài.

# Docker asset owner

Wires five shared output owners: project README instructions, local image name, Compose document, MGC entrypoint, and the shared dockerignore. This directory is an export-only aggregator; behavior and nearest tests live in the five named owner folders below.

## Chủ sở hữu asset Docker

Nối năm owner output dùng chung: hướng dẫn README project, tên image local, tài liệu Compose, entrypoint MGC và dockerignore dùng chung. Thư mục này chỉ gom export; hành vi và test gần nhất nằm trong năm folder owner có tên tương ứng.

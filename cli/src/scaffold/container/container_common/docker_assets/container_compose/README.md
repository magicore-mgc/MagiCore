# Docker Compose owner

Builds the shared Compose service, configurable MGC image, selected command and shared MGC data volume. Container defaults remain owned by the container coordinator.

## Owner Docker Compose

Sinh service Compose dùng chung, image MGC có thể cấu hình, command được chọn và volume dữ liệu MGC. Giá trị mặc định container vẫn thuộc coordinator.

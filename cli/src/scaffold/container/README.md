# Container scaffold

Owns CLI-generated Docker Compose, Dockerfile, entrypoint and Web Kubernetes development assets. Core runtime selection and generated commands stay on the existing MGC-managed lifecycle path.

Phạm vi: asset Docker Compose, Dockerfile, entrypoint và Kubernetes Web development do CLI sinh. Chọn runtime theo core nhưng dependency/lifecycle vẫn đi qua MGC.

This folder only reorganizes current behavior. Docker and K8s coverage is limited to the profiles and manifests already present in source and CLI E2E.

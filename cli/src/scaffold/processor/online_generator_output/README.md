# online_generator_output

Copy online generator output under strict bounds — sao chép output generator online theo giới hạn chặt.
Bounded and link-safe generator output.

This owner implements one scaffold responsibility and exposes only the required parent API. It preserves existing generated output, failure behavior and security boundaries.

Owner này triển khai một trách nhiệm scaffold và chỉ export API cần cho module cha. Giữ nguyên output sinh ra, hành vi lỗi và ranh giới an toàn hiện tại.

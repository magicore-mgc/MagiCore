# Web template layer assembly

Owns the ordered shared/frontend/backend/fullstack layer sequence and the decision to use a monorepo composite when a split fullstack leaf is absent. It calls the existing shared readiness and framework-mapping owners.

Chịu trách nhiệm thứ tự layer shared/frontend/backend/fullstack và quyết định dùng monorepo composite khi thiếu leaf fullstack split. Owner gọi readiness và framework mapping dùng chung hiện có.

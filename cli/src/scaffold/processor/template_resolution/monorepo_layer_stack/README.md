# Monorepo layer stack

Owns explicit `[frontend, backend]` and combined-fullstack fallback stack construction, preserving frontend/backend language mapping and partial order. Existing product-level scaffold cases live beside this owner.

Chịu trách nhiệm dựng stack `[frontend, backend]` tường minh và fallback từ fullstack kết hợp; giữ nguyên ánh xạ ngôn ngữ frontend/backend và thứ tự partial. Các case scaffold sản phẩm cũ được đặt gần owner.

# Web framework catalog

Owns the current 67-row Web metadata catalog. Shared type, frontend rows, backend rows by language, and fullstack rows by backend/runtime family have separate owners. The catalog coordinator preserves the existing global order and create-config inference route.

This metadata table is not a list of fully supported framework lifecycle lanes and does not generate templates. Error handling for unsupported names remains owned by the existing scaffold error module.

# Catalog framework Web

Sở hữu catalog metadata Web hiện có gồm 67 row. Type dùng chung, frontend, backend theo ngôn ngữ và fullstack theo họ backend/runtime có owner riêng. Coordinator giữ thứ tự toàn cục và route suy create config hiện tại.

Bảng metadata này không phải danh sách framework đã được xác minh hỗ trợ đủ lifecycle và không sinh template. Lỗi framework không hỗ trợ tiếp tục do module scaffold error hiện tại sở hữu.

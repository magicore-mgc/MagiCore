# Web framework metadata type

Owns the shared immutable `(name, sub_type, base)` record used by the frontend, backend and fullstack catalogs. This is a passive data type, so behavior tests belong to catalog owners.

# Type metadata framework Web

Sở hữu record bất biến `(name, sub_type, base)` dùng chung bởi catalog frontend, backend và fullstack. Đây là kiểu dữ liệu thụ động; test hành vi thuộc owner catalog.

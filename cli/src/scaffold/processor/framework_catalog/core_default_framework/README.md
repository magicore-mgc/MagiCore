# Core default framework / Framework mặc định theo core

Owns the existing core-to-default-framework mapping shared by scaffold consumers. `framework_catalog` preserves the `Scaffolder::default_framework` route and delegates here. The fallback remains `generic`; no per-core default is changed.

## Tiếng Việt

Owner này quản lý mapping core sang framework mặc định đang được scaffold dùng chung. `framework_catalog` giữ route `Scaffolder::default_framework` và delegate về đây. Fallback vẫn là `generic`; không đổi default của core nào.

# Web context / Context Web

Owns Web-specific context construction and the existing `WebTemplateContext` processor API. Framework-mode inference, project identity, TypeScript compatibility selection, execution architecture/lane and template-layer labels retain their current values. Token validation and target-path substitution delegate to the shared renderer.

## Tiếng Việt

Owner này dựng context riêng cho Web và giữ API `WebTemplateContext` của processor. Suy mode framework, định danh project, chọn lớp tương thích TypeScript, kiến trúc/lane thực thi và nhãn template giữ nguyên giá trị hiện tại. Kiểm tra token và thay token đường dẫn delegate tới renderer dùng chung.

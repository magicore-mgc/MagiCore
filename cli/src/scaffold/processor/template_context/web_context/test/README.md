# Web context tests / Test context Web

These nearest tests protect project/framework values, TypeScript selection, frontend execution metadata and typed rejection of unsupported required keys. They do not create a project or claim runtime scaffold coverage.

## Tiếng Việt

Test gần owner bảo vệ giá trị project/framework, lựa chọn TypeScript, metadata thực thi frontend và từ chối có kiểu khi bắt buộc context không hỗ trợ. Test không tạo project và không claim coverage scaffold runtime.

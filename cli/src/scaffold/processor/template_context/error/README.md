# Template-context errors / Lỗi template context

Owns typed errors for undeclared/unsupported template keys and invalid Core target selection. Display strings match the existing scaffold/hardware diagnostics, and conversion into `anyhow::Error` retains the concrete source for downcasting.

## Tiếng Việt

Owner này quản lý lỗi typed cho token/context template không khai báo/không hỗ trợ và lựa chọn target Core không hợp lệ. Display khớp diagnostic scaffold/hardware hiện có; chuyển sang `anyhow::Error` vẫn giữ concrete source để downcast.

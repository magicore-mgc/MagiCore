# Core context / Context core

Owns the existing `CoreTemplateContext` values for non-Web scaffold materialization. IoT board selection remains framework-specific and fail-closed; non-IoT cores keep the legacy target mapping. Token contract rendering delegates to the shared renderer.

## Tiếng Việt

Owner này quản lý giá trị `CoreTemplateContext` hiện có cho materialize scaffold ngoài Web. Chọn board IoT vẫn theo framework và fail-closed; core không phải IoT giữ mapping target legacy. Render contract token delegate renderer dùng chung.

# Renderer tests / Test renderer

Protects accepted token whitespace forms, validation order, exact diagnostics, typed error preservation, and project-path substitutions including unknown-token preservation. Tests are authored, not executed in the current source-first phase.

## Tiếng Việt

Bảo vệ dạng khoảng trắng token được chấp nhận, thứ tự validate, diagnostic chính xác, giữ lỗi typed và thay token đường dẫn project, gồm cả việc giữ nguyên token lạ. Test đã viết nhưng chưa chạy trong phase source-first hiện tại.

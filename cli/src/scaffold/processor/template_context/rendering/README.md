# Template rendering / Render template

Owns shared declared-token validation, substitution order, and project-name path replacement used by Web and Core context wrappers. Undeclared/unsupported values fail before writing, and existing English error text is retained through a local typed error.

## Tiếng Việt

Owner này quản lý kiểm tra token đã khai báo, thứ tự thay thế và thay token đường dẫn project dùng bởi wrapper context Web/Core. Giá trị không khai báo/không hỗ trợ bị từ chối trước khi ghi file; nội dung lỗi tiếng Anh hiện tại được giữ qua lỗi typed cục bộ.

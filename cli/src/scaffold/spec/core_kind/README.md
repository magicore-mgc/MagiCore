# core_kind

Owns the stable `CoreKind` variants and their lowercase string conversion used by scaffold paths and artifact identifiers.

Quản lý các biến thể `CoreKind` ổn định và phép chuyển sang chuỗi viết thường dùng trong đường dẫn scaffold và mã artifact.

The owner covers all nine existing values. It does not infer or add product support for a core.

# normalize_name

Owns the exact name normalization used by scaffold parsing: lowercase, `_` to `-`, then trim. It intentionally does not collapse repeated separators, rewrite spaces, or validate names.

Quản lý phép chuẩn hóa chính xác được parser dùng: lowercase, đổi `_` thành `-`, rồi trim. Owner này không gộp dấu phân cách lặp, không viết lại dấu cách và không validate tên.

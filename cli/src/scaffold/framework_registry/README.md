# Framework directory

## Purpose

Owns the static list of core/framework ids MagiCore accepts, plus the IoT board aliases and default boards. It is data only: no framework source, no templates, no generators. Support answers "may the user ask for this?", never "can we synthesize it here?".

## Vietnamese

Sở hữu danh sách tĩnh các id core/framework mà MagiCore chấp nhận, cùng alias board IoT và board mặc định. Chỉ là dữ liệu: không source framework, không template, không generator. Câu trả lời là "user có được yêu cầu cái này không?", không phải "có tự sinh được không?".

# `mgc init` command owners

EN: This module preserves the public `commands::init::run` route and coordinates the existing multi-core wizard/scaffold flow. Dedicated owners handle core selection, Hardware root materialization, project metadata, name validation, Web feature choice, and Web manifest enrichment. The `--signature` compatibility option writes the existing plain-text core marker; it is not cryptographic signing.

VI: Module này giữ nguyên route công khai `commands::init::run` và điều phối wizard/scaffold đa core hiện tại. Các owner riêng xử lý chọn core, tạo root Hardware, metadata, xác thực tên, chọn feature Web và bổ sung manifest Web. Tùy chọn tương thích `--signature` ghi marker core dạng plain-text đang có; đây không phải chữ ký mật mã.

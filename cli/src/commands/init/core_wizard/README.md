# Core wizard owner

EN: Owns the feature-gated IoT wizard adapter, available-core choice, and per-core wizard routing. It calls the same project-name and Web-feature owners and preserves the current core list/order.

VI: Quản lý cầu nối wizard IoT theo feature, lựa chọn core đang có và định tuyến wizard từng core. Owner gọi lại phần tên dự án/feature Web hiện có, giữ nguyên danh sách và thứ tự core.

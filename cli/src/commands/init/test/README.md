# `mgc init` tests

EN: Contains the existing project-metadata behavior test nearest to the init implementation. The test body is moved byte-for-byte; runtime execution is deferred to the project-wide verification phase.

VI: Chứa test hành vi metadata vốn có, đặt gần implementation init. Body test được chuyển nguyên byte; chạy test để dành cho pha verification toàn dự án.

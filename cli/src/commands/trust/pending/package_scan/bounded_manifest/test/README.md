# Bounded manifest tests

Tests here cover the size limit, symlink rejection on Unix, and rejection of a directory where a regular manifest file is required.

# Test đọc manifest có giới hạn

Test tại đây kiểm tra giới hạn kích thước, chặn symlink trên Unix và từ chối thư mục tại vị trí bắt buộc là file manifest thường.

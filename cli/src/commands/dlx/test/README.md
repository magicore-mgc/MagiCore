# `mgc dlx` invocation tests

These tests check that the command preserves all parsed arguments, captures the caller's directory and selects the `Dlx` package-run purpose. Product lifecycle coverage remains in `cli/tests/dlx_e2e.rs`.

Test tại đây kiểm tra lệnh giữ nguyên argument, lấy working directory của caller và chọn purpose `Dlx`. Kiểm tra lifecycle product nằm tại `cli/tests/dlx_e2e.rs`.

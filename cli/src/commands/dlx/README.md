# `mgc dlx` command owner

This owner captures the caller's working directory and forwards the invocation to the shared MagiCore package runtime with the `Dlx` purpose. Installation, binary verification and execution remain owned by `package_runtime`.

Owner này chụp working directory của caller và chuyển invocation tới package runtime dùng chung của MagiCore với purpose `Dlx`. Cài đặt, xác minh binary và thực thi tiếp tục thuộc `package_runtime`.

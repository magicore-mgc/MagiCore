# Install execution types

Owns the result record passed between install preparation and the locked adapter tail. Its fields and crate visibility are unchanged; the shared facade keeps the existing re-export path.

Sở hữu record kết quả truyền giữa bước chuẩn bị install và tail adapter có lock. Fields và crate visibility giữ nguyên; facade dùng chung giữ re-export path hiện tại.

# Locked graph loading error tests

These nearest-owner tests lock down error display strings, concrete source types and recovery classification. They do not exercise filesystem or registry behavior; runtime integration coverage remains in the CLI's lock-replay tests.

Các test sát owner khóa chuỗi thông báo, kiểu source cụ thể và phân loại hướng khắc phục. Chúng không giả lập filesystem hoặc registry; kiểm thử runtime vẫn thuộc nhóm lock-replay của CLI.

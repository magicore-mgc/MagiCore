# Locked graph loading

Reads legacy and v4 lock documents, selects the MGC core owner, and enumerates locked package ids. `error/` owns typed diagnostics, recovery classification and its nearest tests. Existing parser, symlink and version-dispatch behavior stays unchanged.

Nạp lock legacy/v4, xác định core owner của MGC và liệt kê package id trong lock. `error/` sở hữu thông báo có kiểu, phân loại hướng xử lý và test gần nhất. Giữ nguyên parser, kiểm tra symlink và thứ tự dispatch version.

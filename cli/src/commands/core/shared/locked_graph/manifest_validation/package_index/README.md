# Package index

Builds the lock-row lookup tables once for a single owner-scoped closure check. It keeps the existing unscoped name lookup for legacy manifest roots and separate owner/ecosystem/name/version indexes for explicit roots and graph edges.

Dựng một lần các bảng tra lock row cho một lần kiểm tra closure theo owner. Giữ tra cứu tên không scope cho legacy manifest root và các index owner/ecosystem/name/version riêng cho root tường minh cùng cạnh graph.

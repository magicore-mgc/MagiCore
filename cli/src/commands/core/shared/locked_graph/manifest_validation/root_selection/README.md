# Manifest root selection

Validates explicit owner roots or the legacy same-name fallback against every active manifest dependency. Ambiguous versions, malformed pins, duplicate roots and extra roots in selected ecosystems remain fail-closed; sibling ecosystem roots are handled independently.

Đối chiếu root owner tường minh hoặc fallback legacy cùng tên với từng dependency manifest đang bật. Version mơ hồ, pin sai định dạng, root lặp và root thừa trong ecosystem được chọn tiếp tục bị từ chối; root ở ecosystem anh em được xử lý độc lập.

# Shared core command owners

This folder owns shared core-command policy, state, transaction gateways and safe file-write primitives used by multiple cores. `mod.rs` is wiring-only; the same-name `shared.rs` is now a 122-line facade over core_identity, mutation_gateway, package_add/remove/list/update, install_execution, audit_policy, lock_reuse, locked_graph and adapter_factory owners. The outer `core/shared.rs` facade preserves established `core::shared::*` routes. Core-specific behavior belongs under its own core owner. AI project/Python/dev/runtime behavior belongs to `core/ai/`; Bevy optimizer setup belongs to `core/game/`; Cloud and Lib adapter bindings belong to their respective owners; Hardware materialization belongs to `core/hardware/`; Web install layout, package links and lockfile `why` belong to their Web owners.

`install_policy/age_gate/` owns minimum-release-age reuse decisions. `manifest_delta/` builds exact-version dependency manifests and merges the corresponding resolved graph. `install_profile/` renders opt-in timing diagnostics for shared add/remove/install stages. `mutation_journal/` owns journal schema, safe writes, staging, completion, recovery, restoration and rollback; `shared.rs` retains the single mutation gateway and public routes while its 32 functions and InstallExecution live in focused owners. This remains an intermediate structural pass; continue decomposing all remaining owners before the repository-wide source phase closes. Core-specific behavior stays with its core owner.

The nearest `test/` owner beside `shared.rs` holds 28 mutation-journal regression cases in six behavior files. Its `mod.rs` preserves the shared coordinator's test context and feature gates. These are authored test sources; runtime behavior is not considered verified until the tests run.

# Dịch vụ lệnh core dùng chung

Folder này sở hữu policy, state, mutation gateway và primitive ghi file an toàn dùng chung giữa nhiều core. `mod.rs` chỉ wiring; `shared.rs` cùng tên hiện là facade 122 dòng nối các owner core_identity, mutation_gateway, package_add/remove/list/update, install_execution, audit_policy, lock_reuse, locked_graph và adapter_factory. Facade `core/shared.rs` giữ các đường gọi `core::shared::*` đã có. Logic riêng của core nằm dưới owner core tương ứng. Logic project/Python/dev/runtime của AI thuộc `core/ai/`; optimizer Bevy thuộc `core/game/`; adapter Cloud và Lib thuộc owner tương ứng; materialize Hardware thuộc `core/hardware/`; install layout, package link và lockfile `why` của Web thuộc owner Web.

`install_policy/age_gate/` sở hữu quyết định reuse theo minimum-release-age. `manifest_delta/` tạo manifest dependency ghim version chính xác và gộp resolved graph tương ứng. `install_profile/` in diagnostic timing tùy chọn cho các bước add/remove/install dùng chung. `mutation_journal/` sở hữu schema journal, ghi an toàn, staging, completion, recovery, restore và rollback; `shared.rs` giữ mutation gateway duy nhất cùng các public route, còn 32 function và InstallExecution nằm trong owner chuyên trách. Đây vẫn là lượt refactor cấu trúc trung gian; tiếp tục bóc các owner còn lại trước khi đóng phase source toàn repo. Logic riêng từng core vẫn ở owner core tương ứng.

Owner `test/` gần `shared.rs` giữ 28 ca regression mutation-journal trong sáu file theo hành vi. `mod.rs` bảo toàn test context và feature gate của shared coordinator. Đây là test source đã viết; chưa thể coi hành vi runtime đã được xác minh cho tới khi test được chạy.

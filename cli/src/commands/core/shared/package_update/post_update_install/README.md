# Post-update install

Owns changed-version reporting, optional locked incremental installation, journal completion, rollback on failure, and the command hint when installation is deferred.

## Tiếng Việt

Owner này giữ output version thay đổi, incremental install có lock tùy chọn, hoàn tất journal, rollback khi lỗi và gợi ý lệnh khi hoãn install.

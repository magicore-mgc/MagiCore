# Update target selection

Selects all dependencies or resolves explicitly named dependencies against the parsed manifest. It preserves request order and the shared unknown-package error.

## Tiếng Việt

Chọn toàn bộ dependency hoặc tra tên được yêu cầu trong manifest. Owner giữ nguyên thứ tự request và lỗi dùng chung khi package không tồn tại.

# Package update resolution

Resolves selected dependencies one at a time through the existing adapter, retains package flags, skips unchanged versions and mutates only the in-memory manifest.

## Tiếng Việt

Resolve dependency được chọn lần lượt qua adapter hiện có, giữ cờ package, bỏ qua version không đổi và chỉ sửa manifest trong bộ nhớ.

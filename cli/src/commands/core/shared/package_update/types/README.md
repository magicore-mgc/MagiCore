# Update target type

Carries the selected dependency name, current version and dev/optional/peer flags between target selection and resolution; it is private to the shared update owner.

## Tiếng Việt

Type này chuyển tên dependency, version hiện tại và cờ dev/optional/peer giữa bước chọn target và resolve; chỉ dùng riêng trong owner update dùng chung.

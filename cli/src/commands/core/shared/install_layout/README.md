# Install layout policy

## Purpose

Owns the `MAGICORE_WEB_STRICT_LAYOUT` override that selects flat vs strict install layout. The policy is core-independent: non-web cores always report `false`.

## Vietnamese

Sở hữu override `MAGICORE_WEB_STRICT_LAYOUT` chọn layout install flat hay strict. Policy độc lập core: core không phải web luôn trả `false`.

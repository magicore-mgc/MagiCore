# mutation_gateway

Native mutation ownership, writer lock, journal recovery and mutation lock validation.
Quyền sở hữu mutation native, writer lock, phục hồi journal và xác thực lock mutation.

This owner uses the shared crate error factories and preserves the existing cross-core API.
Owner này dùng factory lỗi chung của crate và giữ API hiện có giữa các core.

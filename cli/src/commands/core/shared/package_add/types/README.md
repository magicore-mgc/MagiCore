# Add progress type

Carries resolved IDs, manifest-added records and the changed flag between the package-resolution, commit and post-install phases. It stays private to the existing shared package-add owner.

## Tiếng Việt

Type này chuyển ID đã resolve, record package được thêm vào manifest và cờ thay đổi giữa các phase resolve/commit/post-install. Nó chỉ nằm trong owner package-add dùng chung hiện có.

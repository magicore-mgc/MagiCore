# Xcode and simulator discovery

## Responsibility / Trách nhiệm

Owns Xcode project/workspace discovery, audited `xcrun` probes, available iPhone selection and best-effort boot.

## Tests / Kiểm thử

Project preference and simulator result checks.

## Tiếng Việt

Owner này tìm project/workspace Xcode, gọi probe `xcrun` qua scope có kiểm soát, chọn iPhone khả dụng và thử boot simulator. Test kiểm tra ưu tiên project và kết quả tìm simulator.

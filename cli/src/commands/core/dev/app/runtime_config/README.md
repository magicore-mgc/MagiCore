# App runtime and project config reads

## Responsibility / Trách nhiệm

Owns optimizer runtime mapping plus regular-file reads for Swift scheme and Android application ID.

## Tests / Kiểm thử

Config parse and external symlink refusal.

## Tiếng Việt

Owner này ánh xạ runtime optimizer và đọc file thường để lấy Swift scheme cùng Android application ID. Test kiểm tra parse cấu hình và từ chối symlink ra ngoài project.

# App tool policy tests / Test chính sách tool App

These pure cases verify the existing executable allowlist without spawning any process.

Các case thuần xác nhận allowlist executable hiện có và không tạo tiến trình con.

## Tiếng Việt

Các test thuần xác nhận allowlist executable hiện có và không tạo process con. Chúng không chứng minh executor chạy thành công; tích hợp vẫn chưa được kiểm tra runtime.

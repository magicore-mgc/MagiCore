# Audited app tool invocation

## Responsibility / Trách nhiệm

Owns the strict tool allowlist, DevServer execution scope and project audit log setup.

## Tests / Kiểm thử

Pure allowlist tests run without spawning. Executor integration remains part of deferred verification.

## Tiếng Việt

Owner này giữ allowlist tool nghiêm ngặt, execution scope `DevServer` và khởi tạo audit log dự án. Test allowlist không tạo process con; tích hợp executor còn chờ phase verification.

# Android device probing

## Responsibility / Trách nhiệm

Owns audited `adb` calls and strict parsing of ready device rows.

## Tests / Kiểm thử

Header/offline/unauthorized/ready device records.

## Tiếng Việt

Owner này gọi `adb` qua execution scope đã kiểm soát và phân tích nghiêm ngặt các dòng thiết bị sẵn sàng. Test bao phủ header và trạng thái offline, unauthorized, ready.

# iOS command tests / Test lệnh iOS

Pure argument tests cover Xcode invocation order. The existing CLI E2E covers SwiftPM; Objective-C/Xcode simulator execution still needs macOS/Xcode E2E.

Test argv thuần kiểm tra thứ tự lệnh Xcode. E2E hiện có kiểm tra SwiftPM; chạy Objective-C/Xcode Simulator vẫn cần E2E trên macOS/Xcode.

## Tiếng Việt

Test argv thuần kiểm tra thứ tự tham số Xcode. E2E hiện có kiểm tra SwiftPM; chạy Objective-C/Xcode Simulator vẫn cần E2E trên macOS/Xcode. Chưa chạy test trong phase source-only.

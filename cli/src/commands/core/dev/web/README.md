# Web dev delegate / Delegate dev Web

## Responsibility / Trách nhiệm

Re-exports the canonical Web lifecycle implementation; this module does not introduce a second Web runner.

## Tests / Kiểm thử

Behavior tests remain next to `core::web::dev_at_root`.

## Tiếng Việt

Owner này re-export Web lifecycle chuẩn; không tạo runner Web thứ hai. Test hành vi vẫn nằm cạnh `core::web::dev_at_root`.

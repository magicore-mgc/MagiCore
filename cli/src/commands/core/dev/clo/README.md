# Cloud dev command / Lệnh dev Cloud

## Responsibility / Trách nhiệm

Keeps stable cloud dev/deploy and `cloud_type` API paths; unsupported native operations remain explicit.

## Tests / Kiểm thử

Unsupported action behavior is under its owner test; cloud adapter identity remains owned by the adapter.

## Tiếng Việt

Folder này giữ đường dẫn API cloud dev/deploy và `cloud_type`; thao tác native chưa được hỗ trợ vẫn báo rõ ràng. Hành vi từ chối được test tại owner riêng; identity vẫn do cloud adapter sở hữu.

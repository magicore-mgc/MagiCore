# Cloud project type / Loại dự án Cloud

## Responsibility / Trách nhiệm

Reads project identity through the Cloud adapter and returns the adapter-owned cloud type.

## Tests / Kiểm thử

Existing add/install/update/remove callers remain mapped to the stable public function.

## Tiếng Việt

Owner này đọc identity dự án qua Cloud adapter và trả loại cloud do adapter sở hữu. Các caller add/install/update/remove vẫn dùng public function ổn định.

# Game framework command mapping

This owner maps the existing Game adapter result to the legacy Bevy, Godot, Unity, or Unreal behavior. It does not detect support independently or add engines.

Owner này ánh xạ kết quả Game adapter hiện tại sang hành vi Bevy, Godot, Unity hoặc Unreal đang có. Nó không tự nhận diện hỗ trợ hay thêm engine.

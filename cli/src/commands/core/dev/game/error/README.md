# Game dev error owner

This folder defines typed diagnostics for Game-specific unsupported dev decisions. Shared path, framework-detection, and process errors continue to use the existing common error owners.

Thư mục này khai báo lỗi typed cho các quyết định dev Game chưa được hỗ trợ. Lỗi path, nhận diện framework và process dùng chung tiếp tục thuộc error owner chung hiện có.

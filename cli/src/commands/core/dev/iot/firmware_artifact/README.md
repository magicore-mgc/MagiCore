# Firmware artifact lookup / Tìm firmware artifact

## Responsibility / Trách nhiệm

Owns the safe Cargo-manifest name lookup, preferred target path and release ELF fallback scan.

## Tests / Kiểm thử

Original preferred-target, fallback and missing-artifact cases remain local.

## Tiếng Việt

Owner này tìm tên manifest Cargo an toàn, ưu tiên artifact theo target yêu cầu rồi mới quét ELF release dự phòng. Test giữ các trường hợp preferred target, fallback và artifact thiếu.

# IoT board and target / Bo mạch và target IoT

## Responsibility / Trách nhiệm

Validates a board against the framework registry before honoring a target override and resolves the registered chip ID.

## Tests / Kiểm thử

Original board ownership and target override cases remain local.

## Tiếng Việt

Owner này xác nhận board có trong registry trước khi nhận target override và phân giải chip ID đã đăng ký. Test giữ các case board ownership và target override.

# IoT dev error owner

This folder defines typed diagnostics for IoT-specific unsupported dev decisions. Shared detection and process errors continue to use the existing common error owners.

Thư mục này khai báo lỗi typed cho các quyết định dev IoT chưa được hỗ trợ. Lỗi nhận diện và process dùng chung tiếp tục thuộc error owner chung hiện có.

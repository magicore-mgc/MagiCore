# IoT framework command mapping

This owner maps the current IoT adapter result to the existing ESP32-Rust, PlatformIO, or Zephyr dev command. It does not add framework support.

Owner này ánh xạ kết quả IoT adapter hiện tại sang dev command ESP32-Rust, PlatformIO hoặc Zephyr đang có. Nó không bổ sung hỗ trợ framework.

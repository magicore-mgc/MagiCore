# CICD dev command / Lệnh dev CI/CD

## Responsibility / Trách nhiệm

Keeps the existing `core::dev::cicd` API stable and owns provider detection; generation, verify and deploy each live in focused owners.

## Tests / Kiểm thử

Provider detection is exercised indirectly by owner contract cases; generated configuration does not prove a remote pipeline ran.

## Tiếng Việt

Folder này giữ API `core::dev::cicd` và nhận diện provider; sinh cấu hình, verify và deploy nằm trong owner chuyên biệt. Test provider cục bộ không chứng minh pipeline từ xa đã chạy.

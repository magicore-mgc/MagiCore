# Project config tests / Test cấu hình dự án

## Responsibility / Trách nhiệm

Preserves custom/default chain and symlink rejection cases for both readers.

## Tests / Kiểm thử

The tests are registered but not executed in the source-only phase.

## Tiếng Việt

Test giữ nguyên case chain mặc định/tùy chỉnh và từ chối symlink cho cả hai reader. Test đã được đăng ký nhưng chưa chạy trong source-only phase.

# CICD project configuration / Cấu hình dự án CI/CD

## Responsibility / Trách nhiệm

Owns safe `mgc.toml` reads for the verify chain and configured deploy targets.

## Tests / Kiểm thử

Custom/default chain parsing and external symlink refusal stay under this owner.

## Tiếng Việt

Owner này đọc an toàn `mgc.toml` để lấy verify chain và deploy target đã cấu hình. Test kiểm tra chain mặc định/tùy chỉnh và từ chối symlink trỏ ra ngoài.

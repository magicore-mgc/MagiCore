# CICD deployment / Deploy CI/CD

## Responsibility / Trách nhiệm

Keeps configured provider and target rejection explicit. It never adds a vendor CLI pass-through.

## Tests / Kiểm thử

Provider and target errors have their own focused test owners.

## Tiếng Việt

Owner này giữ hành vi từ chối rõ ràng đối với provider/target đã cấu hình không hỗ trợ. Không chuyển tiếp lệnh CLI của nhà cung cấp. Test lỗi được đặt trong owner riêng.

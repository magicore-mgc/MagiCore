# Provider error tests / Test lỗi provider

## Responsibility / Trách nhiệm

Preserves the original unsupported/deploy and CI-only diagnostic assertions.

## Tests / Kiểm thử

The cases explicitly ensure no vendor CLI pass-through is claimed.

## Tiếng Việt

Các test giữ nguyên assertion lỗi unsupported/deploy và provider chỉ chạy trên CI. Chúng xác nhận MagiCore không tuyên bố có thể gọi vendor CLI.

# Deployment provider errors / Lỗi provider deploy

## Responsibility / Trách nhiệm

Maps provider kind to the current shared diagnostic and refuses unsupported local deployment.

## Tests / Kiểm thử

Cloudflare/GCP unsupported and CI-only provider cases are local.

## Tiếng Việt

Owner này ánh xạ loại provider sang diagnostic hiện hành và từ chối deploy cục bộ chưa hỗ trợ. Test bao gồm Cloudflare/GCP không hỗ trợ và provider chỉ dùng cho CI.

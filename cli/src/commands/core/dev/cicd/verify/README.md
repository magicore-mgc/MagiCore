# Verify chain / Chuỗi verify

## Responsibility / Trách nhiệm

Validates the complete configured chain before executing audit, test or build; unknown steps and empty chains still fail closed.

## Tests / Kiểm thử

Step parsing, test lane and build policy have nearest-owner cases.

## Tiếng Việt

Owner này kiểm tra toàn bộ chain trước khi chạy audit, test hoặc build; step lạ và chain rỗng vẫn bị từ chối. Test step parsing, test lane và build policy được đặt gần owner.

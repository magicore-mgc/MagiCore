# Verify build-step policy / Chính sách bước build

## Responsibility / Trách nhiệm

Rejects a CICD build request because CI/CD configuration does not produce a local artifact.

## Tests / Kiểm thử

The CICD failure and supported Web control assertion are local.

## Tiếng Việt

Owner này từ chối yêu cầu build CICD vì cấu hình CI/CD không tạo artifact cục bộ. Test assertion lỗi CICD và control Web mà không gọi build.

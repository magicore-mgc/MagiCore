# Build-step tests / Test bước build

## Responsibility / Trách nhiệm

Preserves the unsupported CICD and supported Web assertions.

## Tests / Kiểm thử

Does not invoke a build.

## Tiếng Việt

Test giữ nguyên assertion rằng CICD không hỗ trợ build cục bộ và Web là control được hỗ trợ. Không thực thi lệnh build.

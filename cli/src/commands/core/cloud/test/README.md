# Cloud owner tests

`cloud.rs` checks that a Cloud adapter cannot be bound to a project with a foreign persisted identity. `error.rs` checks diagnostic and source preservation at the typed boundary. These test sources are authored but have not been compiled or run.

# Test owner Cloud

`cloud.rs` kiểm tra không gắn adapter Cloud vào project có identity thuộc core khác. `error.rs` kiểm tra giữ diagnostic và source ở typed boundary. Các source test đã viết nhưng chưa compile hoặc chạy.

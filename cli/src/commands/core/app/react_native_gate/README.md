# React Native dependency gate

Owns the adapter-independent decision to pass React Native dependency operations through the shared `dep_gate`, including its existing compatibility policy and `.magicore/exec.log` audit destination. It does not invoke another package manager.

# Gate dependency React Native

Sở hữu quyết định chuyển thao tác dependency React Native qua `dep_gate` dùng chung, gồm policy compatibility hiện tại và đích audit `.magicore/exec.log`. Owner này không gọi package manager khác.

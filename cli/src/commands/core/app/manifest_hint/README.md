# App manifest hints

Owns the mapping from App language plus dependency verb to the existing typed manifest-guidance error. This is explanatory guidance only and does not claim a native dependency lifecycle exists.

# Manifest hint của App

Sở hữu ánh xạ ngôn ngữ App và verb dependency sang lỗi hướng dẫn manifest có kiểu hiện tại. Đây chỉ là hướng dẫn, không khẳng định đã có dependency lifecycle native.

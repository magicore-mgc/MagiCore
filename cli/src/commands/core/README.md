# Per-core commands

## Purpose

Groups the explicit per-core command families (`create-*`, `install-*`, `add-*`, `remove-*`, `list-*`, `update-*`) plus shared core helpers. Each core owns its subfolder.

## Vietnamese

Nhóm lệnh per-core (`create-*`, `install-*`, `add-*`, `remove-*`, `list-*`, `update-*`) cùng helper dùng chung. Mỗi core sở hữu thư mục con riêng.

# AI optimizer runtime detection

Owns the mapping from AI framework name and declared package evidence to the shared optimizer `DetectedRuntime`. It does not detect frameworks or install runtimes; those remain in their adapter and executor owners.

# Nhận diện runtime optimizer AI

Sở hữu ánh xạ từ tên framework AI và bằng chứng package đã khai báo sang `DetectedRuntime` dùng chung. Owner này không dò framework hay cài runtime; các phần đó thuộc adapter và executor tương ứng.

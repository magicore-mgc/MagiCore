# AI-local typed errors

Owns `AiCoreError`, its stable English diagnostics, and the Python execution source chain. Constructors used by sibling AI owners are scoped to the AI command subtree; the error type remains private outside the AI error owner.

# Lỗi typed cục bộ AI

Sở hữu `AiCoreError`, diagnostic English ổn định và source chain của lỗi chạy Python. Constructor cần cho owner sibling được giới hạn trong cây lệnh AI; type lỗi không public ra ngoài owner error AI.

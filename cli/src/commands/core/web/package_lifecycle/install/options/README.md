# Web install options owner

Defines the private typed input passed between install stages. Keep this type limited to user-selected install options; computed target state belongs to the install plan.

Sở hữu input private có kiểu truyền giữa các bước install. Chỉ đặt lựa chọn do người dùng cung cấp ở đây; trạng thái target đã tính thuộc install plan.

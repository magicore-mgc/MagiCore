# Web monorepo target installer owner

Owns the typed install request, Web workspace graph/topological ordering, bounded target scheduling, and exact native-member compat check. It preserves the existing per-target mutation-lock helper boundary and root-lock placeholder.

Sở hữu request install có kiểu, graph workspace Web/thứ tự topo, điều phối target có giới hạn và kiểm tra compat chính xác cho member native. Giữ ranh giới mutation-lock từng target và root-lock placeholder hiện có.

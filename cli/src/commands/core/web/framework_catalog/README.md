# framework_catalog

Framework relationships and ordered package seed data.
Quan hệ framework và dữ liệu seed package có thứ tự.

This owner maps full-stack names to backend leaves and exposes ordered seed data to manifest seeding and focused tests. It does not select registry versions.

Owner này ánh xạ tên full-stack sang backend và cung cấp seed có thứ tự cho manifest và test. Nó không chọn version registry.

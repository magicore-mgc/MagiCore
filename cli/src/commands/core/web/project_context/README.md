# project_context

Web project identity and operation gates.
Nhận diện project Web và các cổng cho thao tác.

This owner selects project root, backend language/adapter, freshness and package-manager compatibility, and native install environment. Keep selection precedence and fail-closed checks here.

Owner này chọn thư mục gốc, ngôn ngữ/adapter backend, độ mới, tương thích package manager và môi trường cài native. Giữ thứ tự ưu tiên và kiểm tra fail-closed tại đây.

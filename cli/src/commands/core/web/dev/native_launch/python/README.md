# Web native Python dev owner

Owns Django `manage.py`, Python `main.py`/`src.main`, explicit FastAPI ASGI selection and `.venv` interpreter lookup. Detection precedence remains local to this language lane.

Sở hữu Django `manage.py`, Python `main.py`/`src.main`, chọn FastAPI ASGI tường minh và tìm interpreter `.venv`. Thứ tự nhận diện nằm trong lane ngôn ngữ này.

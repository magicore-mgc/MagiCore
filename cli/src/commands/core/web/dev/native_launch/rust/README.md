# Web native Rust dev owner

Owns Cargo manifest detection, MGC-verified source projection, and `cargo run --locked --offline`. Builds without the shared Lib adapter retain the current explicit refusal.

Sở hữu nhận diện Cargo manifest, source projection do MGC xác minh và `cargo run --locked --offline`. Bản CLI không có shared Lib adapter vẫn giữ lỗi từ chối rõ ràng.

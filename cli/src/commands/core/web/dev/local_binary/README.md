# local_binary

Resolve project-local binaries and PATH — phân giải binary cục bộ và PATH.
Project-local executable resolution.

This owner contains the implementation for this responsibility and re-exports it through `mod.rs`. Keep the current API, ordering, diagnostics, and failure behavior at its boundary.

Owner này chứa implementation cho trách nhiệm trên và export qua `mod.rs`. Giữ nguyên API, thứ tự, diagnostic và hành vi lỗi tại ranh giới của owner.

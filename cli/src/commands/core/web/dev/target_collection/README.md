# Web dev target collection owner

Builds the ordered set of frontend/backend launch targets from the shared Web project mode and centralized port table. This is the single aggregation point consumed by dev preflight.

Tạo tập launch target frontend/backend có thứ tự từ project mode Web dùng chung và bảng port trung tâm. Đây là điểm gom duy nhất mà dev preflight sử dụng.

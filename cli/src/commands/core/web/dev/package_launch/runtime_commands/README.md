# Web runtime command owner

Owns the current explicit Bun/Deno runtime branches plus Node and TSX command launch. Bun/Deno arguments always pass shared runtime policy before a launch description is returned.

Sở hữu các nhánh runtime Bun/Deno tường minh cùng lệnh Node/TSX. Bun/Deno luôn qua runtime policy dùng chung trước khi trả mô tả launch.

# Web framework launcher registry

Wires one owner per supported framework. Ordering mirrors the former match and each owner returns `None` for unrelated tokens; only the matching framework resolves a local binary or environment.

Nối từng framework vào owner riêng. Thứ tự giống match cũ; owner trả `None` với token không thuộc nó, chỉ framework trùng mới resolve binary/env.

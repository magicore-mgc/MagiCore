# Backend initializer catalog

Owns the four supported backend initializer mappings and their argument templates. This owner does not launch packages; its results return through the catalog dispatcher.

# Catalog initializer backend

Sở hữu bốn mapping initializer backend được hỗ trợ cùng mẫu tham số. Owner này không tự chạy package; kết quả được trả qua dispatcher catalog.

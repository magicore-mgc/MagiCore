# Web online-generator catalog

This owner selects static official initializer records by scaffold mode and framework. It only describes package, binary, provenance identity and argument slots; actual execution remains in `create/initializer/` through MagiCore's shared package-runtime engine. Frontend and backend mappings, shared data types and tests have separate owners.

# Catalog generator online Web

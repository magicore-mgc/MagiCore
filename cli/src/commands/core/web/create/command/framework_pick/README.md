# Native Web starter pick

## Purpose

Owns the rule that only a `Default` scaffold ref with a natively supported sub-type/framework pair selects the native starter; everything else returns `None` so the registry lane handles it.

## Vietnamese

Sở hữu quy tắc: chỉ khi scaffold ref là `Default` và cặp sub-type/framework được hỗ trợ native mới chọn starter native; mọi trường hợp khác trả `None` để lane registry xử lý.

# create

Web scaffold entry flow, initializer execution and configuration.
Luồng scaffold Web, chạy initializer và cấu hình.

The create command delegates validation/configuration and online generator execution while preserving the existing command contract.

Lệnh create ủy quyền kiểm tra/cấu hình và chạy generator online, giữ nguyên contract lệnh hiện tại.

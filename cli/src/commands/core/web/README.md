# Web core command owner

`mod.rs` exports the Web command API. `web.rs` is the implementation facade only. Project detection and operation gates live under `project_context/`; create orchestration/configuration under `create/`; dev command owners under `dev/`; framework request, framework seed data, and optional feature data each have separate owners; `manifest_seed/` resolves package versions and edits generated manifests. `package_lifecycle/`, `workspace_layout/`, `install_layout/`, `links/`, and `dependency_why/` keep their focused responsibilities. Tests are grouped by behavior under `test/` and registered through the Web implementation module.

Test được nhóm theo hành vi trong `test/` và đăng ký qua module implementation Web.

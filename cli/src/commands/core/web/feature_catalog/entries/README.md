# Ordered feature catalog entries

This folder contains four contiguous, data-only groups. `entries/mod.rs` exports the groups in the exact order used by the original catalog. The fragments have no independent behavior or errors; the parent catalog owns the record type and verification.

Thư mục này chứa bốn nhóm dữ liệu liên tiếp. `entries/mod.rs` xuất nhóm theo đúng thứ tự catalog cũ. Các mảnh không có hành vi hay lỗi riêng; catalog cha sở hữu type bản ghi và việc xác minh.

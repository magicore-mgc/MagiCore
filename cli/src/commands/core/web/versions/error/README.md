# Web version error owner

EN: Owns the typed error categories and compatibility constructors for age policy, npm tags, registry failures and release selection.

VI: Sở hữu nhóm lỗi typed và constructor tương thích cho age policy, npm tag, registry và chọn release.

`crate::error::web_scaffold_*` remains a compatibility re-export. The source definitions now sit beside the Web version owner.

`crate::error::web_scaffold_*` vẫn là re-export tương thích; định nghĩa source đã chuyển sát owner version Web.

# Seed resolution owner

EN: Keeps an explicit compatible range, validates it under an armed age policy, or delegates the latest lookup to the registry owner.

VI: Giữ range tương thích tường minh, kiểm tra range khi age policy bật hoặc giao tra latest cho owner registry.

This owner does not choose seed data and never substitutes a pinned historical version after registry failure.

Owner này không chọn dữ liệu seed và không thay bằng version lịch sử ghim sẵn khi registry lỗi.

# Eligible release owner

EN: Selects stable registry releases allowed by `eligible_versions`, the current latest tag, and an optional age policy.

VI: Chọn stable release được `eligible_versions`, latest tag hiện tại và age policy tùy chọn cho phép.

The owner does not fetch metadata or write manifests. A missing/invalid latest tag or an empty eligible result remains an error.

Owner này không tải metadata và không ghi manifest. Thiếu/sai latest tag hoặc không có kết quả hợp lệ vẫn trả lỗi.

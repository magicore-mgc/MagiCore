# Registry request owner

EN: Owns age-armed npm metadata, the shared pooled HTTP client, concrete selectors, and fatal registry fallback diagnostics.

VI: Sở hữu metadata npm có age gate, HTTP client pool dùng chung, selector version cụ thể và lỗi registry không được bỏ qua.

The owner retains the configured registry, request timeout, connection pool, keep-alive, user-agent and JSON/status validation behavior.

Owner giữ registry cấu hình, timeout, pool kết nối, keep-alive, user-agent và cách kiểm tra status/JSON hiện tại.

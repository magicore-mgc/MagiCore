# Web package-link name type

`PackageLinkName` keeps the validated relative target path separate from the user-facing package name so scoped names retain their scope and diagnostics remain readable.

# Type tên link package Web

`PackageLinkName` tách relative target path đã kiểm tra khỏi tên package hiển thị để scoped name giữ nguyên scope và diagnostic dễ đọc.

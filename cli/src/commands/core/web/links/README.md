# Web package links

This owner implements `mgc link` and `mgc unlink` for Web projects. `link/` and `unlink/` own the commands; `package_input/`, `package_name/`, `package_source/`, and `package_source/global_roots/` own validation and lookup responsibilities. Source lookup order is explicit relative/absolute path, project `node_modules`, `MAGICORE_GLOBAL_PACKAGE_ROOT`, MagiCore's managed global Web package directory, then the user cache directory. Absolute paths use the native platform path rules. `unlink` refuses ordinary files/directories and removes filesystem symlinks only. Symlink creation/removal stays platform-specific. `core::shared::{link,unlink}` remains available as a compatibility facade.

Local typed refusal and source-lookup variants preserve established diagnostics; filesystem failures retain the OS error as their source. Scoped package targets preserve both `@scope` and package segments, while unsafe path segments and platform-special filename characters are rejected. Link/unlink use no-follow metadata checks so dangling symlinks remain visible, and scoped operations refuse a symlink or non-directory at the scope parent. Focused tests live under each owner’s `test/`; they are authored but not compiled or executed in this structural pass. Path-based check-then-act remains a race window and is tracked as a filesystem-safety follow-up.

# Web package links

Owner này triển khai `mgc link` và `mgc unlink` cho Web project. `link/` và `unlink/` sở hữu lệnh; `package_input/`, `package_name/`, `package_source/` và `package_source/global_roots/` sở hữu kiểm tra và tra cứu. Thứ tự tìm source: path tương đối/tuyệt đối tường minh, `node_modules` của project, `MAGICORE_GLOBAL_PACKAGE_ROOT`, thư mục global Web do MagiCore quản lý, rồi cache user. Absolute path dùng quy tắc path native. `unlink` từ chối file/thư mục thường và chỉ gỡ filesystem symlink. Tạo/gỡ symlink theo từng OS. `core::shared::{link,unlink}` còn là facade tương thích.

Lỗi từ chối và tìm source có kiểu, giữ diagnostic hiện có; lỗi filesystem giữ OS error làm source. Target scoped giữ đủ hai phần `@scope` và tên package; path không an toàn và ký tự filename đặc biệt theo nền tảng bị từ chối. Link/unlink dùng metadata không follow để nhìn thấy dangling symlink và từ chối scope parent là symlink hoặc không phải thư mục. Test nằm trong `test/` gần từng owner; đã viết nhưng chưa compile/chạy trong lượt source-first này. Race giữa kiểm tra path và thao tác filesystem vẫn là follow-up an toàn.

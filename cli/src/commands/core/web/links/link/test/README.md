# Web package link tests

Tests for link target occupancy and symlink creation, including dangling links. Unix and Windows cases are compiled only on their matching operating system.

# Test lệnh link package Web

Test đặt gần việc kiểm tra target và tạo symlink, có cả dangling link. Ca Unix và Windows chỉ được biên dịch trên hệ điều hành tương ứng.

# Web package link command

This folder owns the `mgc link` command, target occupancy checks and platform-specific symlink creation. Scoped links create or accept only a real scope directory; source lookup, package-name normalization and argument validation are separate owners under `links/`.

# Lệnh link package Web

Thư mục này sở hữu lệnh `mgc link`, kiểm tra target và thao tác tạo symlink theo từng hệ điều hành. Link scoped chỉ tạo hoặc chấp nhận scope directory thật; tìm source, chuẩn hóa tên package và kiểm tra đầu vào nằm ở các owner riêng dưới `links/`.

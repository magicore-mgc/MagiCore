# manifest_seed

Resolve registry versions and apply framework/feature packages to generated Web manifests.
Phân giải version registry và ghi package framework/feature vào manifest Web sinh ra.

This owner preserves manifest placement, dependency-section choice, user selectors, age-gate policy, and file write semantics.

Owner này giữ nguyên vị trí manifest, chọn dependency section, selector user, age gate và cách ghi file.

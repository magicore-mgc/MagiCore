# error / Lỗi

Classify self-update failures by validation, transfer, integrity, provenance, archive or rollback boundary.
Phân loại lỗi self-update theo version, tải, integrity, provenance, archive hoặc rollback.

## Files / Tệp

- `mod.rs` exports the command-local error type.
- `error.rs` owns typed variants and stable English display messages.

# install / Cài bản cập nhật

Owns binary replacement and rollback, with exact-version checking in a separate child owner.
Sở hữu thay binary và rollback; kiểm tra version chính xác nằm ở owner con riêng.

- `install.rs` — backup, swap, probe ordering and rollback.
- `version_probe/` — exact output token rule.

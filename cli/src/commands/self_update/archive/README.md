# archive / Archive

Owns isolated staging and delegates ZIP, tar.gz and executable permission work to focused owners.
Sở hữu staging biệt lập và giao ZIP, tar.gz, quyền thực thi cho owner nhỏ hơn.

- `archive.rs` — staging coordinator.
- `zip/` and `tar_gz/` — format readers.
- `executable/` — platform permission.

# Dependency gate test support

Provides shared `DepContext` and compatibility fixtures used by nearest owner tests. This module is compiled only under `cfg(test)` and does not participate in production behavior.

Cung cấp fixture `DepContext` và compat dùng chung cho test gần owner. Module chỉ được biên dịch với `cfg(test)`, không tham gia luồng production.

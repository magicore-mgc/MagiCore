# Dependency gate errors

Owns typed compatibility-disabled, unsupported-operation and native-adapter-identity failures. `Display` preserves the existing English text; `anyhow` retains the local typed value for downcasting. Shared CLI rendering still owns output formatting and exit status.

Test gần nhất so khớp message với factory cũ và kiểm tra typed downcast. Không dùng chuỗi lỗi để điều khiển policy.

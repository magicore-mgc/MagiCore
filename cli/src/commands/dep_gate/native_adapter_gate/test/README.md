# Local unit tests

These tests cover identity mismatch, content-store/resolver capability requirements, native update support, and explicit compatibility refusal. `adapter_stub.rs` contains the test-only `PackageAdapter` double; assertion cases remain in `native_adapter_gate.rs`.

Các test này bao phủ identity mismatch, capability content-store/resolver, native update và từ chối compat tường minh. `adapter_stub.rs` chứa `PackageAdapter` giả chỉ dùng trong test; assertion nằm trong `native_adapter_gate.rs`.

# App ownership

Owns the exact Flutter and Swift operation cells and explicit unsupported React Native, Kotlin, Objective-C and other combinations. Flutter install/add/update/remove are supported through the native path; offline still depends on the shared store guard. Swift install is native, while Swift source mutations remain closed until the Package.swift writer uses the crash-recovery transaction. Kotlin catalog edits have the same transaction gap. React Native has framework engines but no dependency install runner; Objective-C has no native dependency operation.

Mỗi verb được xét riêng; không suy rộng capability theo core App.

# IoT ownership

Owns ESP32 Rust install/add/update/remove cells only. The shared guard requires Cargo manifest evidence; list and other ecosystems stay unsupported. The ESP32 Rust branch uses the native Lib/Rust engine and does not spawn Cargo. PlatformIO and Zephyr toolchain availability is not resolver/store/materializer ownership, so their package operations remain closed.

PlatformIO/Zephyr tool availability does not grant dependency ownership.

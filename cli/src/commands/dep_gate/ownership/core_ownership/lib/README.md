# Lib ownership

Owns Lib operation differences after the shared concrete-manifest guard: TypeScript, Rust, Python, Go, Java, and .NET exact lifecycle/list cells. TypeScript uses the embedded Web engine. Rust/Python/Go/Java/.NET remove and update use the native mutation path; Java add requires Maven POM and .NET add requires one root `.csproj`. A native `list` needs verified installed-state evidence: Python has its managed environment inventory, while other listed ecosystems remain closed until they publish one.

Manifest format phải được chứng minh ở guard chung; policy này không tự xác nhận file manifest.

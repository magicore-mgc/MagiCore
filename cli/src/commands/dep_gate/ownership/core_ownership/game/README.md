# Game ownership

Owns the Bevy install/add/update/remove cells. The shared guard requires a concrete Cargo manifest and blocks unsupported list. Game/IoT list stays unsupported until the adapter verifies installed-state evidence; parsing declared ranges cannot be reported as installed versions. Other game engines have no package operation runner.

Không biến parser/template support thành package lifecycle.

`test/` kiểm tra ownership mutation Bevy và từ chối list khi chưa có bằng chứng trạng thái đã cài.

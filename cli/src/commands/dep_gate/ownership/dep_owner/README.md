# Ownership result type

Owns the three non-interchangeable outcomes returned by the dependency policy: `Native`, `ScaffoldOnly`, and `Unsupported`. The enum describes lifecycle ownership; it does not execute commands or imply that a scaffold-only inventory can install packages.

Sở hữu ba kết quả policy riêng biệt. Giữ mô tả capability trung thực; compatibility vẫn do gate ngoài từ chối.

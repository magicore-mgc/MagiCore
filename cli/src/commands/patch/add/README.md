# Add patch / Patch add

Validates the package/range, reads a bounded patch source, writes a content-addressed patch file under the project store, then records it in `mgc.toml`.

Xác thực package/range, đọc patch có giới hạn, ghi file patch định danh theo nội dung vào project store rồi ghi cấu hình `mgc.toml`.

# Path resolution / Phân giải đường dẫn

## Responsibility / Trách nhiệm

Resolves user and nearest project configuration paths without writing. No direct path test existed in the baseline.

## Tiếng Việt

Chọn đường dẫn config user và project gần nhất, không ghi file. Baseline chưa có test trực tiếp; runtime vẫn hoãn.

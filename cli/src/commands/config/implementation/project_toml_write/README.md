# Project TOML write / Ghi TOML project

## Responsibility / Trách nhiệm

Keeps project-lock and pending-journal checks, immutable core identity, regular-file validation and atomic write order.

## Tiếng Việt

Giữ project lock và kiểm tra journal, bảo vệ core identity, xác nhận regular file và thứ tự ghi atomic.

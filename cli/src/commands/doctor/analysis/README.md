# Doctor diagnostics

This coordinator combines toolchain and store findings in their original order, then derives the report health label. Individual issue policies remain in named local owners.

# Chẩn đoán doctor

Coordinator này ghép finding toolchain và store theo đúng thứ tự cũ, sau đó xác định health label của report. Policy từng issue nằm trong owner cục bộ có tên rõ ràng.

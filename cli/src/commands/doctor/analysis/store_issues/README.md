# Store issue policy

This owner distinguishes a missing store, a non-directory path, failed write probe, inaccessible state and unknown disk capacity. Only the missing-store issue suggests `mgc doctor check --fix`; existing permissions are never auto-changed and no recursive `chmod` command is emitted.

# Policy lỗi store

Owner này phân biệt store thiếu, path không phải thư mục, write probe thất bại, trạng thái không truy cập được và dung lượng disk chưa biết. Chỉ lỗi store thiếu mới gợi ý `mgc doctor check --fix`; permission hiện hữu không tự đổi và không phát lệnh `chmod` đệ quy.

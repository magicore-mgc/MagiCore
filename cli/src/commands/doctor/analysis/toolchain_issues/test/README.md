# Toolchain diagnostic tests

Tests cover required-tool selection, stable messages/action ordering, and the warning emitted when a found tool has no guarded version result. Inputs are synthetic inventory rows; no tool is launched.

# Test diagnostic toolchain

Test bao phủ chọn tool bắt buộc, thông điệp/thứ tự action ổn định và cảnh báo khi tool đã tìm thấy nhưng không có kết quả version qua executor. Dữ liệu là inventory giả lập; test không chạy tool.

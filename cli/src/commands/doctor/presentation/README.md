# Doctor presentation

This owner renders the human-readable and JSON report. When remediation is requested, it appends the actual outcome to human output or a top-level JSON `remediation` object. With no remediation request, it omits that key and preserves the existing report fields.

# Presentation doctor

Owner này render report human-readable và JSON. Khi có yêu cầu remediation, owner thêm kết quả thật vào output terminal hoặc object JSON cấp cao `remediation`. Khi không yêu cầu sửa, key đó bị lược bỏ và các field report hiện tại được giữ nguyên.

# Doctor command options

This owner declares the Clap subcommand and flags only. `--fix` is deliberately bounded to creating a missing store directory and reports its verified outcome in text or JSON; it does not change permissions. Runtime handling lives in the doctor coordinator.

# Tùy chọn lệnh doctor

Owner này chỉ khai báo subcommand và cờ Clap. `--fix` được giới hạn rõ ở việc tạo store đang thiếu và báo kết quả xác minh ở text hoặc JSON; lệnh không đổi permission. Coordinator doctor xử lý runtime.

# Registry reachability

This owner preserves the network module's configured outbound connection order and probes each host/port once before producing the public `RegistryStatus` model. Network policy and probe mechanics remain owned by `commands::network`.

# Reachability registry

Owner này giữ nguyên thứ tự outbound connection do network module cấu hình và probe từng host/port một lần để tạo model `RegistryStatus` công khai. Policy mạng và cơ chế probe vẫn thuộc `commands::network`.

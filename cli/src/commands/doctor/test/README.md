# Doctor coordinator tests

These tests verify the coordinator returns success only for a completed repair or an already-writable store, and preserves storage errors for failed/skipped repairs.

# Test coordinator doctor

Các test xác nhận coordinator chỉ trả thành công khi sửa xong hoặc store đã ghi được; lỗi storage được giữ lại khi repair thất bại/bị bỏ qua.

# Toolchain inventory

This owner implements a closed six-row inventory: Node, Python 3, Rust, Cargo, Git and Docker. `TOOLCHAIN_PROBES` pins each display name, executable basename and exact argv; a nearest-owner test pins its order and arguments. Python uses `-S --version` to skip `site` and `sitecustomize`; Rust uses the executor-approved `-vV` host query.

PATH is read as an OS string and split with OS path APIs. Empty/missing entries are skipped; the first regular-file candidate wins, with `.exe` lookup on Windows. Relative PATH parents are pinned to an absolute directory, keeping the executable leaf for MGC allowlist recognition. The selected path is revalidated and passed directly to `mgc_exec::run`, so the child does not repeat PATH lookup. The executor command API accepts UTF-8 paths only: a found non-Unicode executable is displayed safely but its probe returns `?`.

Each probe has a five-second timeout, MGC process-tree supervision and bounded stdout/stderr capture. The child environment is cleared; MGC restores the guarded PATH and Windows-required process variables, then this owner passes only UTF-8 values for `HOME`, `CARGO_HOME`, `RUSTUP_HOME`, `RUSTUP_TOOLCHAIN`, `ASDF_DATA_DIR`, `MISE_DATA_DIR`, `PYENV_ROOT` and `VOLTA_HOME`. Runtime startup variables such as `NODE_OPTIONS`, `PYTHONPATH`, `PYTHONHOME` and `PYTHONSTARTUP` are omitted. A custom shim needing an unlisted variable can be found but return `?`. Version display uses the first line available in the bounded MGC stdout tail, strips controls and caps text at 256 bytes; visible paths escape terminal controls.

This is process supervision, not sandboxing. A malicious executable earlier on PATH still runs with the current user's permissions and can have side effects or access the network. Rechecking a selected path does not eliminate the same-user race between validation and the OS opening it. The executor accepts a string command path, so non-Unicode executable paths are not runnable. These limits are not a security certification.

Executor caveat: `ExecutionScope::constraints()` declares fields such as `audit_log_required`, `cwd_locked` and `no_arbitrary_args`, but current source has no execution path that reads those constraints. This probe sets `log_path: None`, so it creates no executor audit record; its safe argv boundary is enforced by this doctor's fixed table. Do not treat the scope label as enforcing an audit trail, cwd lock, network restriction or arbitrary-argument policy. Shared enforcement remains a separate core finding.

# Inventory toolchain

Owner này triển khai inventory đóng sáu hàng: Node, Python 3, Rust, Cargo, Git và Docker. `TOOLCHAIN_PROBES` khóa tên hiển thị, basename executable và argv chính xác; test gần owner khóa thứ tự và đối số. Python dùng `-S --version` để bỏ `site` và `sitecustomize`; Rust dùng query host `-vV` được executor cho phép.

PATH được đọc dạng OS string và tách bằng API path của OS. Entry thiếu/rỗng được bỏ qua; candidate file thường đầu tiên được chọn, Windows còn tìm dạng `.exe`. Parent PATH tương đối được ghim thành directory tuyệt đối, giữ leaf để MGC nhận diện đúng tên allowlist. Path được kiểm tra lại và truyền thẳng cho `mgc_exec::run`, không tra PATH lần hai trong process con. API command của executor chỉ nhận path UTF-8: executable không Unicode được hiển thị an toàn nhưng probe trả `?`.

Mỗi probe có timeout 5 giây, MGC giám sát cây process và capture stdout/stderr có giới hạn. Environment child được xóa; MGC khôi phục PATH đã guard và biến process bắt buộc của Windows; owner chỉ truyền các giá trị UTF-8 cho `HOME`, `CARGO_HOME`, `RUSTUP_HOME`, `RUSTUP_TOOLCHAIN`, `ASDF_DATA_DIR`, `MISE_DATA_DIR`, `PYENV_ROOT`, `VOLTA_HOME`. Biến startup runtime như `NODE_OPTIONS`, `PYTHONPATH`, `PYTHONHOME`, `PYTHONSTARTUP` bị bỏ. Shim tùy biến cần biến ngoài danh sách có thể được tìm thấy nhưng trả `?`. Version lấy dòng đầu còn trong bounded MGC stdout tail, bỏ control và giới hạn 256 byte; path hiển thị escape control terminal.

Đây là giám sát process, không phải sandbox. Executable độc hại đứng trước trên PATH vẫn chạy với quyền user hiện tại, có thể gây side effect hoặc truy cập mạng. Kiểm tra lại path không chặn race cùng user giữa lúc validate và lúc OS mở file. Executor nhận command path dạng string nên không chạy được executable path không Unicode. Các giới hạn này không phải chứng nhận bảo mật.

Giới hạn executor: `ExecutionScope::constraints()` khai báo `audit_log_required`, `cwd_locked`, `no_arbitrary_args` nhưng source hiện không có luồng thực thi nào đọc các constraint này. Probe truyền `log_path: None`, vì vậy không tạo audit record của executor; ranh giới argv an toàn hiện do bảng cố định của doctor đảm bảo. Không được hiểu nhãn scope là đã ép audit, khóa cwd, chặn mạng hay ép policy đối số. Enforcement dùng chung vẫn là finding riêng của core.

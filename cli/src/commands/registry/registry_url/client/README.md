# Registry HTTP client

## Purpose

Owns building registry HTTP clients: redirect policy, proxy bypass for loopback hosts, and the admin timeout read from `MGC_REGISTRY_ADMIN_TIMEOUT_SECS` with a bounded default.

## Vietnamese

Sở hữu việc dựng HTTP client cho registry: policy redirect, bỏ qua proxy với host loopback, và admin timeout đọc từ `MGC_REGISTRY_ADMIN_TIMEOUT_SECS` với default có giới hạn.

# Registry URL errors

Defines the typed failures for invalid registry bases, insecure transport, invalid path extension, timeout configuration, and client construction. URL parsing and policy remain in the sibling `registry_url` owner.

Định nghĩa lỗi typed cho URL registry sai, transport không an toàn, nối path không hợp lệ, cấu hình timeout và tạo client. Logic parse/chính sách URL nằm ở owner `registry_url` cùng cấp.

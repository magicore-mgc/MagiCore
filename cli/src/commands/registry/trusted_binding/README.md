# Trusted publisher binding

Owns OCI core namespace mapping and the authenticated request that binds a package to a trusted CI repository. URL policy and safe client construction are delegated to the shared registry URL owner; this folder owns trust-specific diagnostics.

Quản lý ánh xạ namespace core OCI và request xác thực để bind package với repository CI tin cậy. Chính sách URL và client an toàn dùng owner URL registry chung; folder này giữ lỗi riêng của trust.

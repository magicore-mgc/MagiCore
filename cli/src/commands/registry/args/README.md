# Registry arguments

Owns the public Clap structs, subcommands, defaults, and environment bindings for `mgc registry`. Keep these names and field contracts stable because the CLI definition and dispatcher consume them.

Quản lý struct Clap, subcommand, giá trị mặc định và biến môi trường public của `mgc registry`. Giữ ổn định tên và field vì phần định nghĩa CLI và dispatcher đang dùng chúng.

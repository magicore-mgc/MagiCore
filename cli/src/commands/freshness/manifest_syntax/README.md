# Manifest Syntax freshness owner

Validates the manifest structures currently accepted by freshness gates; it does not broaden parsing.

Xác thực cấu trúc manifest hiện được freshness gate chấp nhận; không mở rộng parsing.

The owner preserves current lock, error and ecosystem semantics; its facade only wires modules.

Owner giữ nguyên semantics lock, lỗi và ecosystem hiện tại; facade chỉ nối module.

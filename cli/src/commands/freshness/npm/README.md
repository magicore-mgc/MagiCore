# Npm freshness owner

Owns npm name/spec projection, supported semver filtering and Web dev root checks.

Sở hữu projection tên/spec npm, lọc semver hỗ trợ và check root cho Web dev.

The owner preserves current lock, error and ecosystem semantics; its facade only wires modules.

Owner giữ nguyên semantics lock, lỗi và ecosystem hiện tại; facade chỉ nối module.

# Unity freshness owner

Owns the reserved Unity dependency projection, still unwired until native lock writing exists.

Sở hữu projection dependency Unity đang để dành, chưa nối tới khi có ghi lock native.

The owner preserves current lock, error and ecosystem semantics; its facade only wires modules.

Owner giữ nguyên semantics lock, lỗi và ecosystem hiện tại; facade chỉ nối module.

# Profile freshness owner

Owns the default profile-store path and fail-before-spawn gate bound to current lock bytes.

Sở hữu đường dẫn profile store mặc định và gate fail-before-spawn gắn với byte lock hiện hành.

The owner preserves current lock, error and ecosystem semantics; its facade only wires modules.

Owner giữ nguyên semantics lock, lỗi và ecosystem hiện tại; facade chỉ nối module.

# Flutter freshness owner

Owns pubspec projection and app-feature-aware Flutter SDK-expanded lock checks.

Sở hữu projection pubspec và kiểm tra lock Flutter mở rộng SDK theo feature app.

The owner preserves current lock, error and ecosystem semantics; its facade only wires modules.

Owner giữ nguyên semantics lock, lỗi và ecosystem hiện tại; facade chỉ nối module.

# Virtual Store Root

Owns validation of `node_modules/.magicore` before dedupe enumerates entries. It returns the canonical root or a typed refusal and never creates it.

Sở hữu xác thực `node_modules/.magicore` trước khi dedupe duyệt entry. Owner trả root canonical hoặc lỗi từ chối có type, không tự tạo root.

# Virtual-store cleanup owner

Owns the existing `node_modules/.magicore` cleanup pass. The coordinator calls it only after atomic lock commit and successful MGC build verification. `root.rs` rejects symlinked/non-directory roots and confines canonical roots; `measurement.rs` counts only regular-file logical lengths without following symlinks; `virtual_store_cleanup.rs` removes only unreferenced directories and adds the observed length only after removal succeeds. Per-path failures are typed and surfaced through the existing partial-GC report. The JSON compatibility field `disk_saved_bytes` is not a physical-space measurement. Path-based inspection still has a concurrent replacement race that has not been validated against hostile concurrent filesystem mutation; do not claim race-proof cleanup until the platform runtime checks close it.

Sở hữu lượt dọn `node_modules/.magicore` hiện có. Coordinator chỉ gọi sau atomic lock commit và build MGC thành công. `root.rs` chặn root là symlink/không phải directory và giới hạn root canonical; `measurement.rs` chỉ đếm độ dài logic của file thường, không follow symlink; `virtual_store_cleanup.rs` chỉ xóa directory không còn được tham chiếu và cộng độ dài quan sát được sau khi xóa thành công. Lỗi theo path được gõ kiểu và đưa vào báo cáo GC partial hiện có. Field JSON tương thích `disk_saved_bytes` không phải phép đo dung lượng vật lý. Việc kiểm tra theo path vẫn có race khi tiến trình khác đồng thời thay cây thư mục; chưa xác minh chống được mutation đồng thời có chủ đích, nên chưa được tuyên bố cleanup chống race hoàn toàn cho đến khi kiểm tra runtime theo từng OS xác nhận.

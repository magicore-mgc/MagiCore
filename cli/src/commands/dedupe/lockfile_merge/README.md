# Lockfile merge owner

Merges only records whose complete TOML serialization is identical. Package name/version is not enough to erase core, ecosystem, registry, source or target ownership. The typed serialization error preserves the prior `anyhow` message and source chain. Two frozen tests now live under `test/`.

Chỉ gộp record có toàn bộ TOML serialization giống hệt. Tên/version không đủ để xóa owner core, ecosystem, registry, source hoặc target. Lỗi serialize typed giữ nguyên message `anyhow` và source chain trước đây. Hai test cũ được chuyển vào `test/`.

# Dedupe report owner

Renders the established JSON schema or human-readable terminal report. JSON conversion errors retain their typed serialization source. The legacy `disk_saved_bytes` JSON field remains stable but contains the observed logical lengths of regular files in successfully removed paths; it does not assert physical SSD blocks reclaimed. Terminal wording uses the same limited meaning.

Render schema JSON đã có hoặc báo cáo terminal cho người dùng. Lỗi chuyển JSON giữ source serialize typed. Field JSON legacy `disk_saved_bytes` được giữ ổn định nhưng chứa tổng độ dài logic quan sát được của file thường trong các path đã xóa thành công; không khẳng định block SSD vật lý đã được thu hồi. Câu terminal cũng dùng đúng ý nghĩa giới hạn này.

# Build verification owner

Runs the existing MGC build command only after confirming that the ambient current directory and requested project resolve to the same canonical root. Local typed errors preserve the refusal wording and build context. The owner does not introduce another build process route.

Chỉ gọi lệnh build MGC hiện có sau khi xác nhận thư mục hiện tại và project yêu cầu cùng canonical root. Error typed cục bộ giữ nguyên câu từ chối và build context. Owner không tạo route process build khác.

# Outdated command owners / Owner lệnh outdated

This folder decomposes the shared CLI and MCP outdated query. The public paths remain commands::outdated::run and commands::outdated::outdated_json. Query routing keeps the Web feature gate and uses the native resolver for the other adapter-backed cores.

Thư mục tách luồng outdated dùng chung cho CLI và MCP. Giữ nguyên đường dẫn public commands::outdated::run và commands::outdated::outdated_json. Router giữ feature gate Web và dùng native resolver cho các core còn lại có adapter.

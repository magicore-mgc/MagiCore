# Native outdated orchestration tests / Test orchestration outdated native

Exercises the native query's empty-manifest early return with a temporary Lib/Rust project. The test intentionally avoids requiring an MGC lock or registry access and does not claim coverage of non-empty resolver behavior.

Kiểm tra nhánh return sớm của native query bằng project Lib/Rust tạm. Test không cần MGC lock hoặc registry và không khẳng định đã phủ nhánh resolver khi có dependency.

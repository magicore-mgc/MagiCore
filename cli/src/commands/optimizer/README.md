# Optimizer command

## Purpose

This command coordinates hardware discovery, core/runtime detection, optimization adapter selection, and guarded configuration writes. Runtime recognition is owned by `runtime_detect/`; adapter-specific predicates and generated settings are not duplicated here.

## Phạm vi

Lệnh này điều phối phát hiện phần cứng, core/runtime, chọn adapter tối ưu và ghi cấu hình có kiểm soát. Nhận diện runtime thuộc `runtime_detect/`; điều kiện adapter và cấu hình sinh ra không được sao chép ở đây.

# Linux PCI GPU probe

## Purpose

Reads PCI class/vendor/device/name metadata from sysfs; missing or malformed entries preserve Available/Partial/Unavailable semantics.

## Phạm vi

Đọc metadata class/vendor/device/name PCI từ sysfs; entry thiếu hoặc sai định dạng vẫn giữ đúng Available/Partial/Unavailable.

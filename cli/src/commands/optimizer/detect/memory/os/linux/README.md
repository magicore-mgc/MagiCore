# Linux cgroup memory

## Purpose

Owns Linux cgroup membership traversal and finite ancestor-limit selection. Path validation and v1/v2 behavior remain unchanged.

## Phạm vi

Sở hữu việc dò membership Linux cgroup và chọn giới hạn hữu hạn nhỏ nhất từ ancestor. Kiểm tra path và quy tắc v1/v2 giữ nguyên.

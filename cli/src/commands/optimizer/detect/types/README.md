# Hardware model types

## Purpose

Defines HardwareInfo, GpuInfo, GpuDetectionStatus, and SystemProfile. These DTOs retain their existing serde schema and have no separate behavior tests.

## Phạm vi

Định nghĩa HardwareInfo, GpuInfo, GpuDetectionStatus và SystemProfile. Các DTO giữ nguyên schema serde; không tạo test hành vi riêng cho type thuần.

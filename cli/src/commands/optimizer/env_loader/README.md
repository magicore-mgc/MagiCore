# Optimizer environment loader

## Purpose

Stable `commands::optimizer::env_loader` facade. It dispatches project-owned optimizer settings to runtime mapping, `.env` parsing, Cargo TOML validation, safe project-file access, and local diagnostics.

## Phạm vi

Facade ổn định `commands::optimizer::env_loader`. Module điều phối cấu hình optimizer thuộc project tới owner runtime, parser `.env`, kiểm tra Cargo TOML, đọc file project an toàn và lỗi typed cục bộ.

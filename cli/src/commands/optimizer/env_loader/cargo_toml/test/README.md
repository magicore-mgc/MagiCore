# Cargo TOML fail-closed tests

## Purpose

Checks rejection of an unsupported string value for `lto`, zero build jobs, and an attempt to replace the process `PATH` through `[env]`.

## Phạm vi

Kiểm tra việc từ chối giá trị chuỗi `lto` không hỗ trợ, số build job bằng 0 và ý định thay biến `PATH` của tiến trình qua `[env]`.

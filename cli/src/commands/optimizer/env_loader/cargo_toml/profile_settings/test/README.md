# Cargo profile environment tests

## Purpose

Checks that Candle runtime settings merge with Cargo build/profile settings, including the generated environment keys and TOML string representation.

## Phạm vi

Kiểm tra cấu hình runtime Candle được gộp với build/profile Cargo, gồm key môi trường sinh ra và cách giữ nguyên biểu diễn chuỗi TOML.

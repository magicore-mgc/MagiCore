# Optimizer command tests

## Purpose

Contains optimizer orchestration, adapter dispatch, environment-loading, and generator tests that span multiple implementation owners. Runtime-detection behavior tests live beside their owner under `runtime_detect/`.

## Phạm vi

Chứa test điều phối optimizer, dispatch adapter, nạp môi trường và generator có phạm vi qua nhiều implementation owner. Test hành vi nhận diện runtime nằm cạnh owner trong `runtime_detect/`.

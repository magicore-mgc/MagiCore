# Shared project-file owner

## Purpose

This owner reads regular project manifests without following symlinks. Read failures remain best-effort; the current API does not expose a typed read error.

## Phạm vi

Owner này đọc manifest thường của project nhưng không đi theo symlink. Lỗi đọc vẫn được xử lý best-effort; API hiện tại không xuất error type riêng.

# Shared package-manager owner

## Purpose

This owner selects the Node-family package manager by the existing lockfile precedence. Web and Cloud share the result; this code does not install or invoke a package manager.

## Phạm vi

Owner này chọn package manager hệ Node theo thứ tự lockfile hiện có. Web và Cloud dùng chung kết quả; mã này không cài đặt hay chạy package manager.

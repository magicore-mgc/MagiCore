# Cloud runtime owner

## Purpose

This owner recognizes Pulumi/CDK Node.js projects. An arbitrary package.json does not qualify without the existing IaC/SDK evidence.

## Phạm vi

Owner này nhận diện dự án Pulumi/CDK chạy Node.js. Một `package.json` bất kỳ không đủ điều kiện nếu thiếu bằng chứng IaC/SDK như quy tắc hiện tại.

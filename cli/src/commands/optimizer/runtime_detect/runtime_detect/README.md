# Core dispatch owner

## Purpose

Selects the core-specific detector, applies the existing generic Rust fallback, and adds Web native-language evidence only for optimizer dispatch.

## Phạm vi

Chọn detector theo core, áp dụng fallback Rust chung hiện có và chỉ bổ sung bằng chứng ngôn ngữ native cho Web trong luồng optimizer.

# Runtime result types

## Purpose

This owner defines the shared DetectedRuntime and PackageManager enums. The declarations have no independent behavior; detector tests exercise their contracts.

## Phạm vi

Owner này định nghĩa enum dùng chung `DetectedRuntime` và `PackageManager`. Bản thân type không có xử lý độc lập; các test detector kiểm tra contract của chúng.

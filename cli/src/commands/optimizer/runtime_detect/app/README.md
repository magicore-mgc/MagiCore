# App runtime owner

## Purpose

This owner preserves Flutter, React Native, and Rust-native marker precedence. Detection remains read-only and returns the existing runtime enum.

## Phạm vi

Owner này giữ nguyên thứ tự nhận diện Flutter, React Native và Rust-native. Việc phát hiện chỉ đọc project và trả về enum runtime hiện có.

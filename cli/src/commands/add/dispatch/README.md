# Add lane dispatch

Dispatches the existing request to one of the nine recognized core lanes. Feature attributes, argument order, lane APIs, the `MCP_INSTALL_AFTER_ADD = false` default and the unknown/not-in-build error distinction are preserved. It performs no adapter or external package-manager call itself.

## Tiếng Việt

Điều phối request hiện có tới một trong chín lane core đã biết. Giữ feature attribute, thứ tự đối số, API lane, default `MCP_INSTALL_AFTER_ADD = false` và phân biệt lỗi unknown/core-not-in-build. Bản thân dispatcher không gọi adapter hay package manager bên ngoài.

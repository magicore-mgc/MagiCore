# MCP stdout capture

Owns stdout redirection, disk-backed capture, the existing 1 MiB bound and truncation marker, and restoration during error or early-drop paths.

## Phạm vi

Folder này sở hữu chuyển hướng stdout, capture bằng file tạm, giới hạn 1 MiB và marker truncate hiện tại, cùng khôi phục khi lỗi hoặc drop sớm.

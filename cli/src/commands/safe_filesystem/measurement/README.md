# Logical Payload Measurement

Counts regular-file logical lengths beneath a validated directory, skips symlinks and uses checked addition. It reports payload bytes, not filesystem blocks or guaranteed reclaimed disk space.

Đếm độ dài logic của file thường dưới thư mục đã xác thực, bỏ qua symlink và cộng có kiểm tra tràn. Kết quả là byte payload, không phải block filesystem hay số dung lượng chắc chắn thu hồi.

# Directory Root Validation

Owns no-follow checks for existing directory roots, canonical containment of child directories and typed path failures. It does not create paths or provide race-free directory handles.

Sở hữu kiểm tra root thư mục không follow symlink, giới hạn thư mục con canonical và lỗi path có type. Owner không tạo path và chưa cung cấp directory handle chống race.

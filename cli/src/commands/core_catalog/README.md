# Core identity catalog

This owner defines the shared recognized-core name predicate used by add/remove to distinguish an unknown core from one compiled out of the current CLI build. It does not claim that every recognized core has every operation; lane availability remains feature- and command-specific.

## Tiếng Việt

Owner này định nghĩa predicate tên core được nhận diện dùng chung cho add/remove, để phân biệt core lạ với core không được compile vào CLI hiện tại. Catalog không claim mỗi core hỗ trợ mọi thao tác; lane vẫn phụ thuộc command và feature.

# Search error owner / Owner lỗi search

Defines local transparent errors for registry configuration, request transport, response decoding and JSON serialization. Each variant preserves the original display and underlying source; it adds no retry or recovery policy.

Khai báo lỗi transparent cục bộ cho cấu hình registry, truyền request, giải mã response và serialize JSON. Mỗi variant giữ nguyên nội dung hiển thị cùng source gốc; owner không tự thêm retry hay recovery.

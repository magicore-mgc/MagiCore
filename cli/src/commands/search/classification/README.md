# Search core classification owner / Owner phân loại core cho search

Owns the exact keyword order and default label used by the `mgc search` command. It remains separate from the Info command's similarly named classifier because their keyword sets and fallback labels differ.

Quản lý đúng thứ tự keyword và nhãn mặc định của `mgc search`. Owner này tách riêng classifier cùng tên ở lệnh Info vì tập keyword và nhãn fallback của hai bên khác nhau.

# Search query owner / Owner của truy vấn tìm kiếm

Builds the exact-match query text and the existing page-size/offset values. It deliberately preserves the current saturating subtraction and multiplication behavior.

Tạo chuỗi truy vấn exact-match cùng kích thước trang/offset hiện tại. Owner cố ý giữ nguyên phép trừ bão hòa và phép nhân đang dùng.

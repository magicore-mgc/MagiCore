# Package info errors / Lỗi lệnh thông tin package

This owner classifies missing-Web-adapter, registry-fetch and JSON-serialization failures. The public command still returns `anyhow::Result`; registry failures retain their source chain and existing display text.

## Tiếng Việt

Owner này phân loại lỗi thiếu Web adapter, truy vấn registry và serialize JSON. API command vẫn trả `anyhow::Result`; lỗi registry giữ source chain và câu hiển thị hiện tại.

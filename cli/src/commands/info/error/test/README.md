# Package info error tests / Test lỗi package info

Tests cover the command-local diagnostic text and preservation of the registry source chain. They are registered by the nearest error owner and have not been executed in the source-refactor phase.

## Tiếng Việt

Test xác nhận thông báo lỗi cục bộ và source chain của lỗi registry. Test được đăng ký ngay trong owner error và chưa chạy ở giai đoạn refactor source.

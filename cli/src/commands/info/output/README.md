# Package info output / Output thông tin package

Owns the private JSON projection shared by `mgc info --json` and the MCP versions handler, plus the existing human renderer. Keep schema keys and types stable. Registry version strings are sorted lexically for JSON and the five recent display entries; `dist_tags` preserve the source map's iteration semantics.

## Tiếng Việt

Owner này chứa JSON projection riêng được dùng chung bởi `mgc info --json` và MCP versions handler, cùng renderer người đọc hiện tại. Giữ ổn định key/type của schema. Version registry được sort theo chuỗi cho JSON và năm mục recent; `dist_tags` giữ cách duyệt map nguồn hiện tại.

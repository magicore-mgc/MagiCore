# Package core label / Nhãn core package

Owns the existing ordered keyword heuristic used by `mgc info`. A label is informational only; package metadata does not prove a package's actual framework, language, or compatible core. Earlier matching categories keep precedence.

## Tiếng Việt

Owner này chứa heuristic keyword có thứ tự mà `mgc info` đang dùng. Nhãn chỉ mang tính tham khảo; metadata không chứng minh framework, ngôn ngữ hay core tương thích thật. Nhóm khớp trước tiếp tục có ưu tiên.

# Core label tests / Test nhãn core

Tests pin the existing categories and the current Web-frontend-before-backend precedence. They do not assert that keyword matching is authoritative framework detection.

## Tiếng Việt

Test đóng băng các nhóm hiện có và ưu tiên Web-frontend trước backend. Các test không khẳng định dò keyword là nhận diện framework chính xác.

# Audit strict-mode owner / Owner strict mode audit

Owns strict-mode environment resolution and the shared audit exit decision. It preserves explicit MGC_AUDIT_STRICT precedence, CI defaulting, finding failures and incomplete-scanner handling.

Sở hữu resolve strict mode từ environment và quyết định exit audit dùng chung. Giữ precedence MGC_AUDIT_STRICT, mặc định CI, lỗi finding và xử lý scanner chưa đủ.

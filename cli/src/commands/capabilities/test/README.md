# Capability command tests / Test command capability

These tests protect the shared JSON row shape for every feature-enabled core and the error returned for an explicitly selected unknown core. The CLI/MCP routing and real all-core feature build remain separate runtime checks.

Các test này bảo vệ schema hàng JSON dùng chung của mọi core có feature và lỗi khi chọn core không biết. Route CLI/MCP và build feature all-core thật vẫn phải được kiểm riêng ở runtime.

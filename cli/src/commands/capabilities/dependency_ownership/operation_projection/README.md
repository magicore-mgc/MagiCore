# Operation projection / Projection operation

For one `DepContext`, this owner enumerates `DepOp::ALL`, calls the dependency gate, and serializes the closed owner/tool vocabulary plus the existing Cargo manifest precondition for Bevy and ESP32 Rust. It contains no independent ownership policy.

Với một `DepContext`, owner này duyệt `DepOp::ALL`, gọi dependency gate rồi serialize vocabulary owner/tool đóng cùng điều kiện Cargo manifest hiện có cho Bevy và ESP32 Rust. Nó không chứa policy ownership độc lập.

# Manifest variants / Biến thể manifest

This owner publishes the explicit Lib and AI manifest-variant maps that the lifecycle matrix checks. Each cell is recomputed through the operation projection and the existing dependency gate. Keep the names and gate conditions in sync with the owner tests and `dep_gate`; do not broaden a manifest lane here.

Owner này công bố map biến thể manifest tường minh của Lib và AI để lifecycle matrix kiểm tra. Mỗi cell được tính lại qua operation projection và dependency gate hiện có. Giữ tên/điều kiện gate khớp test và `dep_gate`; không mở rộng lane manifest tại đây.

# Language projection / Projection language

This owner walks the canonical split-language list and publishes only rows that differ from the base core row. It attaches the same manifest-format requirements used by the C0 gate; an absent format remains absent rather than being guessed.

Owner này duyệt danh sách split-language chuẩn và chỉ công bố hàng khác hàng cơ sở. Nó gắn đúng điều kiện định dạng manifest của C0 gate; thiếu định dạng thì giữ `None`, không suy đoán.

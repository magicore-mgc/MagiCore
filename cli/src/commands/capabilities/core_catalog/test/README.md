# Core catalog tests / Test catalog core

These tests lock the published core-name order and the stable unknown-core diagnostic at the catalog owner. Feature-matrix runtime behavior is covered separately by the CLI build and lifecycle E2E and is not claimed by these source tests.

Các test này khóa thứ tự tên core được công bố và lỗi unknown-core tại owner catalog. Hành vi runtime theo feature matrix được kiểm ở CLI build/E2E riêng, không được khẳng định chỉ nhờ source test này.

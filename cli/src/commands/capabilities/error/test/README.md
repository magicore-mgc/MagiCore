# Capability error tests / Test lỗi capability

These nearest-owner tests protect the unknown-core display string used by CLI and MCP error surfaces. They do not replace feature-matrix compilation or command-level runtime verification.

Test gần owner này bảo vệ câu lỗi unknown-core dùng ở CLI và MCP. Chúng không thay thế việc compile feature matrix hoặc kiểm tra runtime của command.

# Shared dev dispatch

This owner holds the exhaustive core-name route table for `mgc dev`. It does not detect projects or build framework commands; those responsibilities stay in `ProjectContext` and the core-specific dev owners.

Owner này giữ bảng route theo tên core cho `mgc dev`. Nó không nhận diện project hay dựng command framework; các trách nhiệm đó thuộc `ProjectContext` và dev owner riêng của core.

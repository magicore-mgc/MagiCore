# Dev dispatch tests

Tests here lock the core-name-to-route table. They do not claim that each core's runtime has passed; runtime lifecycle checks belong to the core owner and its integration lane.

Test tại đây khóa bảng ánh xạ tên core sang route. Chúng không xác nhận runtime từng core; kiểm tra lifecycle runtime thuộc owner core và lane tích hợp tương ứng.

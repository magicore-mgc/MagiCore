# script_policy

Owns the pre-spawn policy gates for package-manager tokens and executable runtime selection. It parses and checks the declared program before the guarded executor is called; it does not spawn processes.

# script_policy (VI)

Folder này sở hữu các cổng policy trước khi spawn: token package manager và lựa chọn executable runtime. Owner parse/kiểm tra program trước khi gọi executor có rào chắn; không tự spawn process.

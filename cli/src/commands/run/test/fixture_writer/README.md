# fixture_writer

Owns the shared test-only helper that creates parent directories and writes temporary project files. It performs no command execution or product filesystem operation.

# fixture_writer (VI)

Folder này sở hữu helper chỉ dùng trong test để tạo thư mục cha và ghi file project tạm. Helper không chạy lệnh hay ghi filesystem của sản phẩm.

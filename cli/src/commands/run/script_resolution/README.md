# script_resolution

Reads named script entries from `mgc.toml` and `package.json`, then resolves the project script with the current `mgc.toml`-first precedence. Parsing and fallback behavior are unchanged.

# script_resolution (VI)

Đọc script theo tên trong `mgc.toml` và `package.json`, sau đó phân giải theo thứ tự `mgc.toml` trước như hiện tại. Không đổi cách parse hoặc fallback.

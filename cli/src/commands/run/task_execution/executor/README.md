# executor

Builds the child-process environment and `mgc-exec::ExecOptions`, including inherited `PATH`, lifecycle event, optional native Python environment, optimizer variables, timeout, compatibility scope and policy context. Process launch remains delegated to `mgc-exec`.

# executor (VI)

Dựng environment và `mgc-exec::ExecOptions`, gồm `PATH` kế thừa, lifecycle event, native Python environment nếu phù hợp, optimizer variables, timeout, compatibility scope và policy context. Việc chạy process vẫn do `mgc-exec` đảm nhiệm.

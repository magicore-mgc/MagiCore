# task_execution

Coordinates a resolved task script: loads the operation policy context, applies the current script gates, chooses the project-local Web `.bin` path only for package-manifest scripts, and builds the private `TaskRequest`. The request type is local to this owner.

# task_execution (VI)

Điều phối script đã phân giải: nạp policy context của operation, áp dụng các cổng hiện tại, chỉ chọn Web `.bin` cục bộ cho script từ package manifest và tạo `TaskRequest` riêng của owner.

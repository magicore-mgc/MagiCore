# runtime_policy

Owns the run-script timeout default/environment override and the existing project-file runtime detection used when loading optimizer variables. The detection order and values are preserved.

# runtime_policy (VI)

Folder này sở hữu timeout mặc định/ghi đè environment và logic nhận diện runtime qua file project để nạp optimizer variables. Giữ nguyên thứ tự và kết quả nhận diện.

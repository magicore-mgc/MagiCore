# Import lock merge / Merge lock import

Owns the policy that replaces only the active core's legacy-compatible package entries, preserves sibling/ambiguous pins and updates deterministic root dependencies/metadata.

Sở hữu policy chỉ thay entry tương thích legacy của core hiện tại, giữ pin core khác/owner mơ hồ và cập nhật root dependency/metadata có thứ tự.

# Import signing policy / Policy ký import

Owns the pure choice between signed output, explicit unsigned output and refusal. It does not read the keyring or write artifacts; those remain inside the transaction coordinator.

Sở hữu quyết định thuần giữa ký, unsigned opt-in và từ chối. Module không đọc keyring hay ghi artifact; các bước đó vẫn nằm trong coordinator.

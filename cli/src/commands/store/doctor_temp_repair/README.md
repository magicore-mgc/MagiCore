# Doctor Temp Repair

## Responsibility

Removes only old, recognized MagiCore temp entries after path-safety checks.

## Trách nhiệm

Chỉ xóa temp MagiCore hợp lệ đã cũ sau kiểm tra an toàn path.

Implementation: `doctor_temp_repair.rs`; `mod.rs` only wires this owner.

Triển khai: `doctor_temp_repair.rs`; `mod.rs` chỉ nối owner này.

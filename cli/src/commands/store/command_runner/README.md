# Command Runner

## Responsibility

Finds the project, applies shared mutation gates and dispatches store commands.

## Trách nhiệm

Tìm project, áp gate mutation dùng chung và điều phối lệnh store.

Implementation: `command_runner.rs`; `mod.rs` only wires this owner.

Triển khai: `command_runner.rs`; `mod.rs` chỉ nối owner này.

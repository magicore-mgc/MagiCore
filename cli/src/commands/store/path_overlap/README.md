# Store path overlap / Quan hệ overlap path Store

Shares the exact component-prefix overlap predicate between backup and restore. Callers remain responsible for canonicalizing the paths required by their own operation.

Dùng chung đúng predicate overlap theo tiền tố component giữa backup và restore. Mỗi caller vẫn chịu trách nhiệm canonicalize path theo yêu cầu riêng.

# Backup payload copy / Copy payload backup

Owns the established order for virtual-store tree copy followed by no-follow database copy, then reports logical payload sizes. Safe filesystem and backup-storage owners remain the only filesystem primitives.

Quản lý thứ tự copy cây virtual-store rồi database no-follow, sau đó đo logical payload. Các primitive filesystem vẫn do safe-filesystem và backup-storage sở hữu.

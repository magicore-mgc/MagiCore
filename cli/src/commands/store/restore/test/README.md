# Restore Tests

Coordinator tests cover database-only restore preserving the current virtual store and an active project maintenance lock stopping restore before project or safety-backup mutation.

Test coordinator bao phủ restore chỉ có database nhưng giữ nguyên virtual store hiện tại, và maintenance lock đang hoạt động chặn restore trước khi sửa project hoặc safety backup.

These cases are authored but have not been run in the source-first phase.

Các case đã được viết nhưng chưa chạy trong phase source-first.

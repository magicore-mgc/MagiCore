# Virtual-store restore

Replaces the project vstore through the safe clear and tree-copy owners. The source tree must already have passed backup validation; valid internal package links are rebased to the destination and unsafe targets are refused before project mutation.

# Khôi phục virtual store

Thay vstore project qua owner clear an toàn và copy cây. Cây nguồn phải qua xác thực backup; package link nội bộ hợp lệ được rebase về đích và target không an toàn bị từ chối trước khi sửa project.

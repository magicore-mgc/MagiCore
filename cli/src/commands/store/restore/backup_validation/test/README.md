# Backup validation tests

These tests cover empty and partial backups, regular database acceptance, and refusal of unsafe roots or entries. They are authored but intentionally not executed in the current source-first phase.

# Test xác thực backup

Các test bao phủ backup rỗng/từng phần, chấp nhận database thường và từ chối root/entry không an toàn. Test đã được viết nhưng chủ đích chưa chạy trong phase source-first hiện tại.

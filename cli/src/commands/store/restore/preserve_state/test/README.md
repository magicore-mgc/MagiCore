# Preserve-state tests

Source cases verify that selected existing database and vstore data are copied to the safety backup and that absent components do not create fake backup entries. These tests are not run in this source-first phase.

# Test bảo toàn state

Test source xác minh database/vstore hiện có được copy vào safety backup và thành phần vắng mặt không tạo entry giả. Chưa chạy trong phase source-first.

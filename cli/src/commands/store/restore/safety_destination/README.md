# Safety destination / Đích safety backup

Selects or accepts the explicit pre-restore safety-backup path, resolves its prospective root, rejects overlap with the restore source and protected project stores, creates it through the existing no-follow owner, then rechecks canonical identity and overlap before any preservation/restore mutation.

Chọn hoặc nhận path safety backup tường minh, resolve root dự kiến, từ chối overlap với restore source và Store project được bảo vệ, tạo qua owner no-follow hiện có, rồi kiểm tra lại canonical identity/overlap trước mọi mutation preserve/restore.

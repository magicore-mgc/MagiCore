# Project state tests / Test project state

Checks post-lock state capture and rejection of a backup root inside protected project data. These test bodies are registered only by `project_state/mod.rs` and are not inline in production source.

Kiểm tra chụp state sau lock và từ chối backup root bên trong dữ liệu project được bảo vệ. Test body chỉ được đăng ký bởi `project_state/mod.rs`, không inline trong production source.

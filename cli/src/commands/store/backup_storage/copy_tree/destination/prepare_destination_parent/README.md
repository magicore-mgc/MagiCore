# Destination parent preparation

Owns existing/missing parent preparation. Existing symlink parents resolve to their canonical target according to the current shared store behavior. It calls the destination-root owner and returns its typed errors.

# Chuẩn bị parent destination

Chịu trách nhiệm chuẩn bị parent đã có hoặc còn thiếu. Parent symlink hiện có được resolve về target canonical theo hành vi store hiện tại. Owner gọi owner root và giữ nguyên lỗi typed.

# Prospective destination root

Owns non-creating projection of an existing or missing destination path. The function preserves canonical existing-ancestor handling and does not create the missing suffix.

# Root đích dự kiến

Chịu trách nhiệm tính path đích đã có hoặc còn thiếu mà không tạo thư mục. Function giữ cách xử lý ancestor canonical và không tạo phần path còn thiếu.

# Staging Lease

## Responsibility

Classifies leases by process liveness, age, install lock and promoted coverage.

## Trách nhiệm

Phân loại lease theo PID, tuổi lease, install lock và promoted coverage.

Implementation: `staging_lease.rs`; `mod.rs` only wires this owner.

Triển khai: `staging_lease.rs`; `mod.rs` chỉ nối owner này.

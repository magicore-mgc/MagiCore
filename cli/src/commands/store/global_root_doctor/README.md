# Global Root Doctor

## Responsibility

Inspects shared native-root safety without creating roots or hashing package bytes.

## Trách nhiệm

Kiểm tra an toàn root native dùng chung, không tạo root hay hash package.

Implementation: `global_root_doctor.rs`; `mod.rs` only wires this owner.

Triển khai: `global_root_doctor.rs`; `mod.rs` chỉ nối owner này.

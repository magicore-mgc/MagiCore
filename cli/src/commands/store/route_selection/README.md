# Route Selection

## Responsibility

Maps core/framework lanes to MagiCore-owned native store roots.

## Trách nhiệm

Ánh xạ lane core/framework sang store root native của MagiCore.

Implementation: `route_selection.rs`; `mod.rs` only wires this owner.

Triển khai: `route_selection.rs`; `mod.rs` chỉ nối owner này.

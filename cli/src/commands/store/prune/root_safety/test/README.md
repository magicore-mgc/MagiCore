# Root safety tests

These nearest tests cover missing paths, DB symlinks and unsafe lock roots before SQLite open or lock creation. Symlink cases are platform-gated for Unix/Windows.

# Test an toàn root

Các test gần owner này kiểm tra path thiếu, DB symlink và lock root không an toàn trước khi mở SQLite hoặc tạo lock. Case symlink được gate theo Unix/Windows.

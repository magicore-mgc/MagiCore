# Game framework records / Record framework Game

## Responsibility / Trách nhiệm

Owns the 4 existing qualification rows for game, exported in the original catalog order.

Sở hữu 4 dòng qualification hiện có của game và export theo thứ tự catalog ban đầu.

## Errors and tests / Lỗi và test

This static data owner has no error path. Existing catalog tests remain in the CLI test owner until source closure.

Owner dữ liệu tĩnh này không có nhánh lỗi. Test catalog giữ ở CLI test owner tới khi source pass đóng.

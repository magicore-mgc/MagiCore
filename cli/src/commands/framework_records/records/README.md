# Per-core framework records / Record framework từng core

## Responsibility / Trách nhiệm

Each core folder owns its existing qualification rows; the shared records.rs assembles them in the original order. Web has three focused data families.

Mỗi folder core sở hữu các dòng qualification hiện có; records.rs ghép chúng theo thứ tự gốc. Web có ba nhóm dữ liệu nhỏ.

## Errors and tests / Lỗi và test

Static tables have no local error behavior. One catalog test checks all rows after source closure.

Bảng tĩnh không có xử lý lỗi riêng. Một test catalog kiểm tra toàn bộ row sau khi đóng source.

# Store

**Purpose:** Shared store ownership and doctor diagnostics.

**Mục đích:** Lỗi quyền sở hữu shared store và store doctor.

This folder owns only these CLI diagnostic factories. The parent facade preserves their existing names and behavior.

Folder này chỉ sở hữu các hàm tạo diagnostic tương ứng. Facade phía trên giữ nguyên tên và hành vi hiện có.

# CLI Error Message Facade

**Purpose:** Explicitly re-exports focused diagnostic owners while preserving the existing outer error factory paths. Typed error contracts belong with their functional owners in a later migration.

**Mục đích:** Re-export tường minh các owner diagnostic nhỏ, giữ nguyên đường dẫn factory lỗi hiện có. Typed error contract sẽ chuyển về owner chức năng trong một đợt migration riêng.

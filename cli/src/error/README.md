# CLI error facade

## Purpose

Facade for root and compatibility diagnostics. Functional modules own their typed errors; this module re-exports and renders once with English output, redaction and stable exit codes.

## Vietnamese

Facade cho lỗi root và diagnostic tương thích. Module chức năng tự sở hữu lỗi typed; module này re-export và render một lần với output tiếng Anh, redaction và exit code ổn định.

# Current-project adapter entry

Resolves the process current directory and delegates to the root-bound factory. Keep current-directory failure propagation and the empty fallback chain unchanged.

# Điểm vào adapter của project hiện tại

Lấy thư mục hiện tại của process rồi giao cho factory gắn root. Giữ nguyên cách truyền lỗi khi không lấy được current directory và fallback chain rỗng.

# Configured project tests / Test project có cấu hình

These tests verify the configured-project branch through the resolver entry point so marker validation and config adoption are exercised together.

Các test gọi entry point của resolver để kiểm tra chung nhánh config, xác thực marker và nhận identity.

The source tests are authored but not compiled or executed.

Source test đã viết nhưng chưa biên dịch hoặc chạy.

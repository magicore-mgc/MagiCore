# Core identity tests / Test identity core

These tests pin canonical alias matching and prove a conflicting selector remains downcastable as the local identity error.

Các test khóa quy tắc khớp alias chuẩn và xác nhận lỗi selector xung đột vẫn downcast được thành lỗi identity cục bộ.

The source tests are authored but not compiled or executed.

Source test đã viết nhưng chưa biên dịch hoặc chạy.

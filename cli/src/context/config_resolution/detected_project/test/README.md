# Detected project tests / Test project được nhận diện

These tests exercise signature-based resolution through the coordinator, including the rule that a rejected override must not create an identity marker.

Các test chạy luồng nhận diện chữ ký qua coordinator, gồm điều kiện override bị từ chối không được tạo marker identity.

The source tests are authored but not compiled or executed.

Source test đã viết nhưng chưa biên dịch hoặc chạy.

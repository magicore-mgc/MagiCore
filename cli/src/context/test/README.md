# Context tests / Test context

This directory holds tests for public `ProjectContext` accessors and execution-summary formatting. Tests use the native Web adapter only when the `web` feature is enabled.

Thư mục này chứa test cho accessor public và định dạng execution summary của `ProjectContext`. Test chỉ tạo Web adapter khi feature `web` được bật.

The test source is authored but has not been compiled or executed.

Source test đã được viết nhưng chưa biên dịch hoặc chạy.

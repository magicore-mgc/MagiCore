# Bare add mapper tests

Tests verify bare add routes to each supported core contract, retains Web's `no_install` behavior, and fails closed for missing/unknown cores or the wrong verb.

## Tiếng Việt

Test xác nhận bare add đi đúng hợp đồng từng core, giữ xử lý `no_install` của Web, và từ chối khi thiếu/không biết core hoặc nhận nhầm verb.

# Bare install mapper tests

These tests cover bare-command routing, all nine exact core names, missing/unknown-core failures and the wrong-verb guard without invoking package managers.

## Tiếng Việt

Các test này kiểm tra route `mgc install`, đủ chín tên core chính xác, lỗi thiếu/không biết core và hàng rào verb sai; không gọi package manager.

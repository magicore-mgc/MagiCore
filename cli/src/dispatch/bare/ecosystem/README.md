# Bare ecosystem requirement

Owns the shared helper that requires a detected project core and returns the exact original identifier. It never invents a Web fallback or validates a different core; missing identity uses the existing typed shared bare-route error. Callers retain `crate::dispatch::bare::ecosystem::require_ecosystem`.

# Yêu cầu core của bare command

Sở hữu helper dùng chung để yêu cầu project đã nhận diện core và trả lại nguyên mã core. Helper không tự bịa fallback Web hay validate core khác; thiếu identity dùng lỗi bare route typed đang chia sẻ. Caller giữ nguyên route `crate::dispatch::bare::ecosystem::require_ecosystem`.

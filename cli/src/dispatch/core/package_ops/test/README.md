# Package dispatch coordinator tests / Test coordinator dispatch package

These tests cover the pure command-to-core selection boundary for all nine cores and ensure create/install commands do not enter package dispatch. They do not execute downstream package operations.

Các test kiểm tra ranh giới chọn core thuần cho cả chín core và bảo đảm lệnh create/install không đi vào package dispatch. Các test không chạy thao tác package phía dưới.

# AI package dispatch tests / Test điều phối package AI

These tests protect the `ai` command classifier: add, remove, list, and update are owned here; a different core is not. They do not execute package operations or prove registry/install behavior.

Các test bảo vệ bộ phân loại lệnh `ai`: add, remove, list, update thuộc owner này; core khác bị từ chối. Test không chạy thao tác package và không chứng minh registry/install hoạt động.

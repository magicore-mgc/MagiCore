# cicd package dispatch tests / Test điều phối package cicd

These tests protect the `cicd` command classifier: add, remove, list, and update are owned here; a different core is not. They do not execute package operations or prove registry/install behavior.

Các test bảo vệ bộ phân loại lệnh `cicd`: add, remove, list, update thuộc owner này; core khác bị từ chối. Test không chạy thao tác package và không chứng minh registry/install hoạt động.

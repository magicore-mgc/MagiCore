# Shared add mapping

Owns the single conversion from normalized add options to the nine `CoreCommand::Add*` variants. Bare and explicit adapters translate their CLI schemas here; this owner does not validate support or execute package operations.

## Vietnamese

Folder này sở hữu phép đổi duy nhất từ tùy chọn add đã chuẩn hóa sang chín variant `CoreCommand::Add*`. Adapter bare và explicit chuyển schema CLI vào đây; owner này không kiểm tra capability hoặc chạy package operation.

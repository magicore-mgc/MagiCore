# Dispatch types facade tests

These tests verify that the stable `crate::dispatch::types` facade exposes common/core route types together without changing the route discriminator.

## Tiếng Việt

Test kiểm tra façade ổn định `crate::dispatch::types` xuất kiểu lệnh dùng chung và kiểu theo core, đồng thời giữ nguyên discriminator của tuyến.

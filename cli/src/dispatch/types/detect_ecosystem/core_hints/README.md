# Core-hint normalization and validation

Canonicalizes legacy `cloud` to `clo`, rejects multiple declarations in deterministic order, and validates the resulting core name against the supported core catalog. Local typed errors preserve existing user-visible messages.

## Tiếng Việt

Chuẩn hóa `cloud` cũ thành `clo`, từ chối nhiều khai báo theo thứ tự xác định và đối chiếu tên core với catalog hỗ trợ. Lỗi typed cục bộ giữ nguyên thông báo hiện có.

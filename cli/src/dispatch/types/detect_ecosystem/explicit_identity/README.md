# Explicit project identity owner

Reads `.mgc.core` before `mgc.toml` and returns an explicit project core. Marker and config parsing errors propagate so detection never falls through to weaker manifest evidence.

## Tiếng Việt

Đọc `.mgc.core` trước `mgc.toml` và trả về core khai báo tường minh. Lỗi đọc marker/cấu hình được giữ nguyên để bộ dò không rơi xuống bằng chứng manifest yếu hơn.

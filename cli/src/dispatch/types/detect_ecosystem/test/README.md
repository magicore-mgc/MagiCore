# Ecosystem detection nearest tests

Covers explicit identity precedence, fail-closed parsing, symlink rejection, conflicting declarations, canonical names, no implicit writes, and detection from nested directories.

## Tiếng Việt

Kiểm tra ưu tiên identity tường minh, parse fail-closed, từ chối symlink, khai báo xung đột, tên core chuẩn, không tự ghi file và nhận diện từ thư mục con.

# Project lock validation owner

Validates TOML syntax for an existing `mgc.lock` before native-manifest fallback. It deliberately does not infer a single core from a multi-core lock.

## Tiếng Việt

Kiểm tra cú pháp TOML của `mgc.lock` nếu file tồn tại trước khi fallback sang manifest native. Owner này không suy luận một core duy nhất từ lock đa core.

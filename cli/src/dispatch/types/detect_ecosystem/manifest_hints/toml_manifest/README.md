# Cargo and Python TOML core hints

Reads `package.metadata.magicore.core` from Cargo.toml and `tool.magicore.core` from pyproject.toml. Both files are parsed when present; malformed syntax prevents fallback.

## Tiếng Việt

Đọc `package.metadata.magicore.core` trong Cargo.toml và `tool.magicore.core` trong pyproject.toml. Cả hai file đều được parse nếu hiện diện; cú pháp sai chặn fallback.

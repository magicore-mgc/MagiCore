# Manifest core-hint owner

Collects explicit MagiCore core declarations from Node package.json, Cargo.toml and pyproject.toml in a fixed order. It parses every present manifest and returns raw declarations for canonical resolution by `core_hints`.

## Tiếng Việt

Thu thập khai báo core MagiCore tường minh từ package.json của Node, Cargo.toml và pyproject.toml theo thứ tự cố định. Owner parse mọi manifest hiện diện rồi trả khai báo thô để `core_hints` chuẩn hóa.

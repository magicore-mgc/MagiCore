# Shared list mapping

Owns the single conversion from a list request to the nine `CoreCommand::List*` variants. It only carries the explicit compatibility option; policy and execution stay in the existing owners.

## Vietnamese

Folder này sở hữu phép đổi duy nhất từ request list sang chín variant `CoreCommand::List*`. Owner chỉ chuyển cờ tương thích tường minh; policy và thực thi giữ ở owner hiện có.

# Dev/Build/Flash route

## Purpose

Owns the dev, build and flash arms of the common dispatcher. Each arm keeps the exact argument mapping, feature gating (`iot`) and async call from the original dispatcher; the dispatcher keeps three separate arms.

## Vietnamese

Sở hữu các nhánh dev, build và flash của dispatcher chung. Mỗi nhánh giữ nguyên mapping tham số, gate theo feature (`iot`) và lời gọi async như dispatcher gốc; dispatcher vẫn giữ ba arm riêng.

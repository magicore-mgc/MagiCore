# Recursive workspace pipeline tests

These tests compose filter, dependency-order and identity-planning owners without calling the recursive command coordinator or package handlers. They use only temporary project files and parsed CLI values.

## Tiếng Việt

Các test này ghép owner lọc, thứ tự dependency và identity plan nhưng không gọi coordinator command recursive hoặc package handler. Chúng chỉ dùng file project tạm và CLI value đã parse.

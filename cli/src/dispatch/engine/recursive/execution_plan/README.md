# Recursive execution plan

This owner resolves the effective core and validates explicit per-core commands for every selected workspace before command execution begins. It returns immutable path/core targets; it does not change the process working directory or invoke handlers.

## Tiếng Việt

Owner này resolve core hiệu lực và xác minh lệnh per-core tường minh cho mọi workspace được chọn trước khi bắt đầu thực thi. Nó trả về danh sách path/core; không đổi working directory của process và không gọi handler.

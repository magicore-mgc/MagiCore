# Workspace-order tests

These tests use temporary manifests to cover dependency-first ordering, stable fallback for paths without manifests, graph-construction error propagation, and cycle rejection.

## Tiếng Việt

Các test dùng manifest tạm để kiểm tra thứ tự dependency-first, fallback ổn định cho path thiếu manifest, truyền lỗi dựng graph và từ chối cycle.

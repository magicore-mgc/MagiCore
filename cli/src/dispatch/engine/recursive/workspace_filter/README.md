# Recursive workspace filter

This owner matches `--filter` against supported workspace manifest names and relative paths. Missing manifests use the workspace directory name; malformed manifests propagate errors. It does not reorder targets or execute commands.

## Tiếng Việt

Owner này so `--filter` với tên trong manifest workspace được hỗ trợ và đường dẫn tương đối. Manifest vắng thì dùng tên thư mục workspace; manifest hỏng thì truyền lỗi lên. Owner không sắp thứ tự target và không chạy command.

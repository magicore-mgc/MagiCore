# Workspace-filter tests

These tests cover scoped package names, relative paths, the missing-manifest directory fallback, and malformed-manifest errors using temporary files only.

## Tiếng Việt

Các test này dùng file tạm để kiểm tra tên package có scope, path tương đối, fallback tên thư mục khi thiếu manifest và lỗi manifest hỏng.

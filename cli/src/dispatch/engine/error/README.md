# Engine policy errors

This shared owner defines the five error categories used by the audit-strict and recursive/filter policies, then converts each category into the existing diagnostic. It is visible only inside the `dispatch::engine` subtree and does not define public crate API.

## Vietnamese

Owner dùng chung này khai báo năm nhóm lỗi của audit-strict và recursive/filter policy, rồi chuyển từng nhóm thành diagnostic hiện có. Phạm vi chỉ trong cây `dispatch::engine`, không tạo API công khai của crate.

# Recursive and filter policy

This owner holds the supported-command matrix for `--recursive` and the explicit refusal paths for unsupported recursive/filter usage. It classifies command values only; `engine::run` remains responsible for ordering and calling the workspace handler.

## Vietnamese

Owner này giữ ma trận lệnh hỗ trợ `--recursive` và các nhánh từ chối tường minh cho recursive/filter chưa được nối. Nó chỉ phân loại command; `engine::run` vẫn chịu trách nhiệm thứ tự và gọi workspace handler.

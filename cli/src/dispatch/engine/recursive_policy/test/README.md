# Recursive policy tests

The supported matrix test parses every current CLI spelling into a command value. Rejection tests call only policy functions. They do not run the recursive workspace implementation, package handlers, or filesystem/network operations.

## Vietnamese

Test ma trận parse toàn bộ tên CLI hiện hỗ trợ thành command value. Test từ chối chỉ gọi policy function; không chạy workspace recursion, package handler hay thao tác filesystem/network.

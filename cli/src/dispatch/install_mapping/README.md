# Shared install mapping

Owns the single conversion from normalized install options to the nine `CoreCommand::Install*` variants. Bare and explicit per-core adapters translate their CLI schemas here; this owner does not validate support or execute package operations.

## Vietnamese

Folder này sở hữu phép đổi duy nhất từ tùy chọn install đã chuẩn hóa sang chín variant `CoreCommand::Install*`. Adapter bare và adapter từng core chuyển schema CLI vào đây; owner này không kiểm tra capability hoặc chạy package operation.

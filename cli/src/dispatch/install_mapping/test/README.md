# Shared install mapping tests

Tests protect the exact core-name table and every field forwarded into the shared `CoreCommand::Install*` contract. They do not run package managers.

## Tiếng Việt

Test bảo vệ bảng tên core chính xác và mọi trường được chuyển vào hợp đồng `CoreCommand::Install*`. Các test không chạy package manager.

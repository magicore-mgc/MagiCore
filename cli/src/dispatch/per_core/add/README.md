# Per-core add adapter

Converts the nine explicit `AddCommands` variants into normalized add requests. Final `CoreCommand::Add*` construction is centralized in `dispatch/add_mapping/`.

## Vietnamese

Folder này đổi chín variant `AddCommands` thành request add đã chuẩn hóa. Việc dựng `CoreCommand::Add*` cuối cùng được gom tại `dispatch/add_mapping/`.

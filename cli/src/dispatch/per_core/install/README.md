# Per-core install adapter

Converts the nine explicit `InstallCommands` variants into normalized install requests. Final `CoreCommand::Install*` construction is centralized in `dispatch/install_mapping/`.

## Vietnamese

Folder này đổi chín variant `InstallCommands` thành request cài đặt đã chuẩn hóa. Việc dựng `CoreCommand::Install*` cuối cùng được gom tại `dispatch/install_mapping/`.

# Per-core engine adapter tests

These cases exercise every current engine command mapping and assert the CLI payload is retained. They call only the type adapter; they do not start servers, execute binaries, build/flash hardware, deploy infrastructure, install tools, or mutate caches.

## Vietnamese

Các ca này kiểm tra mọi ánh xạ engine hiện tại và xác minh payload CLI được giữ nguyên. Test chỉ gọi adapter kiểu dữ liệu; không khởi động server, chạy binary, build/flash phần cứng, deploy hạ tầng, cài tool hoặc sửa cache.

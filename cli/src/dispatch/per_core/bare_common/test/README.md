# Per-core bare common adapter tests

These tests distinguish the 14 commands converted to shared dispatch from the five package operations that must fall through to core detection. They inspect type conversion only and do not execute commands or mutate projects.

## Vietnamese

Các test phân biệt 14 lệnh chuyển sang dispatch dùng chung với năm package operation phải tiếp tục qua bước nhận diện core. Test chỉ kiểm tra chuyển kiểu, không chạy lệnh hoặc sửa dự án.

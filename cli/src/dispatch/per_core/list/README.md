# Per-core list adapter

Converts the nine explicit `ListCommands` variants into normalized list requests. Final `CoreCommand::List*` construction is centralized in `dispatch/list_mapping/`.

## Vietnamese

Folder này đổi chín variant `ListCommands` thành request list đã chuẩn hóa. Việc dựng `CoreCommand::List*` cuối cùng được gom tại `dispatch/list_mapping/`.

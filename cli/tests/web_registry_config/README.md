# Web registry configuration tests

This folder owns integration coverage for the public `mgc::commands::web_registry_config` API. The root `web_registry_config.rs` file remains the Cargo target facade.

Folder này chứa integration test cho API public `mgc::commands::web_registry_config`. File gốc `web_registry_config.rs` vẫn là facade giữ tên Cargo target.

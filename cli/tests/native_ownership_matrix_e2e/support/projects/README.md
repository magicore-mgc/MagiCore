# Project fixtures / Fixture dự án

`library.rs` builds language manifests; `web.rs` owns the Web backend fixture; `ai_app.rs` owns AI/Flutter fixtures; `game_iot.rs` owns Bevy/ESP32 fixtures. Project files are created only inside E2E temporary directories.

`library.rs` dựng manifest theo ngôn ngữ; `web.rs` sở hữu fixture backend Web; `ai_app.rs` sở hữu fixture AI/Flutter; `game_iot.rs` sở hữu fixture Bevy/ESP32. File dự án chỉ được tạo trong thư mục tạm E2E.

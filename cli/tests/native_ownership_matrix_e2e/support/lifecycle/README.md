# Lifecycle helpers / Helper lifecycle

These helpers assemble MagiCore add/install/remove/update operations and check blocked mutations. Arguments and fixture transitions stay centralized; assertions are in `../../test/`.

Helper dựng thao tác MagiCore add/install/remove/update và kiểm tra mutation bị chặn. Argument và chuyển trạng thái fixture được gom tại đây; assertion nằm trong `../../test/`.

# detection

EN: Detects a MagiCore project only when the project root has a regular `mgc.toml` file. The helper keeps its crate-internal path and does not parse the manifest.

VI: Chỉ nhận diện project MagiCore khi root có file thường `mgc.toml`. Helper giữ nguyên đường dẫn crate-local và không parse manifest.

# Hardware source modules

EN: Crate-root map for the Hardware adapter. `adapter/` owns capability implementations, `detection/` checks the shared MagiCore manifest marker, and `sbom.rs` delegates SBOM generation to the shared engine.

VI: Sơ đồ module gốc của Hardware adapter. `adapter/` sở hữu các capability, `detection/` kiểm tra marker manifest MagiCore dùng chung, còn `sbom.rs` ủy quyền sinh SBOM cho engine dùng chung.

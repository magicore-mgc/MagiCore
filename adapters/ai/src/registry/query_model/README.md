# query_model

Routes the stable public query API to the provider-specific owner.

Điều phối API truy vấn công khai đến owner provider tương ứng.

This owner preserves the current API and behavior. Provider gaps and input-hardening limits are tracked by S191; this structural pass does not change them.

Owner này giữ nguyên API và hành vi hiện tại. Gap provider và giới hạn hardening input được ghi trong S191; đợt tách cấu trúc này không thay đổi chúng.

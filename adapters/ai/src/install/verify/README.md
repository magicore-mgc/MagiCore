# Model checksum verification

This owner preserves the public compatibility function for verifying model checksums. The checksum implementation remains in the download checksum owner, so verification rules have a single implementation.

Owner này giữ hàm tương thích công khai để xác minh checksum model. Phần thực thi checksum vẫn thuộc owner checksum của download để chỉ có một nơi định nghĩa quy tắc.

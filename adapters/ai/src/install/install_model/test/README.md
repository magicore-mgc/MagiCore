# Model-install tests

This folder owns the existing model-install lifecycle tests. They cover local artifact installation and remote SHA-256 verification; test execution is deferred until repository-wide source closure.

Folder này sở hữu các test vòng đời cài model hiện có: cài artifact local và xác minh SHA-256 từ nguồn remote. Chưa chạy test cho đến khi đóng refactor source toàn repository.

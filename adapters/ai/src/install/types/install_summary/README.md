# Install summary

This owner defines the public `InstallSummary` data returned by `install_model`. Field names, types, visibility, derives, and the historical `install::InstallSummary` path are preserved.

Owner này định nghĩa dữ liệu `InstallSummary` công khai do `install_model` trả về. Tên trường, kiểu, visibility, derives và đường dẫn lịch sử `install::InstallSummary` được giữ nguyên.

# AI adapter source owners

This source tree contains AI adapter policy, framework detection, model installation, registry access, cache, audit and native Python integration.
Cây source này gồm policy adapter AI, nhận diện framework, cài model, truy cập registry, cache, audit và tích hợp Python native.

Each owner exposes only its responsibility through its module facade. Framework detection is best-effort and keeps its current `Option` contract.
Mỗi owner chỉ xuất trách nhiệm của mình qua module facade. Nhận diện framework là best-effort và giữ hợp đồng `Option` hiện tại.

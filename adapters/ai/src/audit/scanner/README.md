# AI artifact scanner

This directory preserves the public audit::scanner module path and exports the three existing scanner functions. It delegates pickle signatures, SafeTensors header boundaries, and weight-file routing to private owners; byte matching is private shared support.

Thư mục này giữ đường dẫn module public audit::scanner và export ba hàm scanner hiện có. Nó chuyển xử lý signature pickle, ranh giới header SafeTensors và định tuyến weight-file đến owner riêng; byte matcher là hỗ trợ dùng chung nội bộ.

The scanners remain heuristic and their findings are advisory. This folder does not claim that a clean scan proves an artifact safe. Owner behavior tests live beside each implementation.

Các scanner vẫn là heuristic và finding chỉ mang tính cảnh báo. Thư mục này không tuyên bố kết quả sạch chứng minh artifact an toàn. Test hành vi nằm cạnh từng implementation owner.

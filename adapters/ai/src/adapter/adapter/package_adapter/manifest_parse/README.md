# AI manifest parser

Revalidates native Python project ownership on every parse before delegating to the shared Python service. Projects without the native lane retain the prior name-only AI manifest behavior.

## Parser manifest AI

Kiểm tra lại quyền sở hữu project Python native ở mỗi lần parse trước khi ủy quyền cho Python service dùng chung. Project không có lane native giữ nguyên hành vi manifest AI chỉ chứa tên.

# AI package age gate

Arms and reports support for the existing Python engine's project-scoped age gate. An AI adapter without the native lane preserves the prior no-op/false response.

## Cổng tuổi package AI

Nạp và báo trạng thái hỗ trợ cổng tuổi theo project của Python engine hiện có. Adapter AI không có lane native giữ nguyên kết quả no-op/false.

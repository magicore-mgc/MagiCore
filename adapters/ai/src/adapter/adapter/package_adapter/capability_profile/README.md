# AI capability profile

Selects the existing static capability list according to whether the adapter owns the native Python lane. Capability values and ordering remain in the capability manifest.

## Chủ sở hữu

Chọn danh sách capability tĩnh hiện có theo việc adapter có sở hữu lane Python native hay không. Giá trị và thứ tự capability vẫn thuộc capability manifest.

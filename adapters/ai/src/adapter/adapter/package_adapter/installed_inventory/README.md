# AI installed inventory

Reads installed package versions from the native Python engine's resolution/lock state. Foreign-lock projects fail closed instead of reporting an empty or guessed inventory.

## Danh sách package đã cài của AI

Đọc version package từ trạng thái resolve/lock của Python engine native. Project dùng lock ngoài bị từ chối rõ ràng, không báo danh sách rỗng hay version suy đoán.

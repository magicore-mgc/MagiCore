# AI add preparation

Delegates native Python additions to the existing embedded engine's resolve-first path. Without a native Python lane it preserves the explicit fail-closed capability error.

## Chuẩn bị add của AI

Ủy quyền việc thêm package Python native cho luồng resolve-first của engine nhúng hiện có. Khi không có lane Python native, giữ nguyên lỗi capability từ chối rõ ràng.

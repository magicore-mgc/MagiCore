# Unclaimed AI capabilities

Keeps empty provider implementations that inherit the shared fail-closed unsupported defaults. Add a behavior here only when the AI core owns and can verify that capability.

## Chủ sở hữu

Giữ các provider rỗng kế thừa mặc định từ chối fail-closed dùng chung. Chỉ thêm behavior khi core AI sở hữu và kiểm chứng được capability đó.

# MAUI project discovery

EN: Finds only regular `.csproj` files containing the existing exact `<UseMaui>true</UseMaui>` marker, sorts candidates, and returns a path only when exactly one qualifies.

VI: Chỉ tìm `.csproj` thường có marker chính xác `<UseMaui>true</UseMaui>`, sắp xếp candidate và chỉ trả path khi đúng một file phù hợp.

# App manifest classification

EN: Classifies a project as App when a parseable config declares `ecosystem = "app"` or contains `[app]`; otherwise it uses the established language detector.

VI: Phân loại App khi config parse được khai báo `ecosystem = "app"` hoặc có `[app]`; nếu không, dùng bộ nhận diện language đã có.

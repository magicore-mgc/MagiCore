# App language identity

EN: Owns the stable eight-variant `AppLanguage` type, display values and canonical ecosystem IDs. React Native maps to `rn`; MAUI maps to `dotnet`; Tauri maps to `rust` for the existing dependency-gate contract.

VI: Sở hữu type `AppLanguage` tám variant, giá trị hiển thị và ecosystem ID chuẩn. React Native map sang `rn`, MAUI sang `dotnet`, Tauri sang `rust` theo contract dependency-gate hiện tại.

# install_maven

Xác minh/import artifact Maven vào CAS dùng chung trước khi materialize m2.

The owner preserves the existing public contract and tier behavior. Its source-level tests are not executed in S192.

Owner giữ nguyên hợp đồng công khai và hành vi tier hiện có. Test source chưa được chạy trong S192.

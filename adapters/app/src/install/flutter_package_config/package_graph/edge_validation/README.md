# Flutter package-graph edge validation

Checks that every resolved/SDK package dependency and every root dependency resolves to a package entry after the complete graph has been assembled. It does not mutate or sort the graph.

## Trách nhiệm

Kiểm tra mọi dependency của package registry/SDK và dependency root đều trỏ tới entry sau khi ráp đủ graph. Owner không sửa hoặc sắp xếp graph.

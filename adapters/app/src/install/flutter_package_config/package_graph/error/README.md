# Package graph errors

Owns typed package-graph failures and the single conversion into the shared `MgError` boundary.

Sở hữu lỗi typed của package graph và một điểm chuyển duy nhất sang boundary `MgError` dùng chung.

`error.rs` keeps source-bearing local variants until the facade maps them. Tests under `test/` protect integrity classification for duplicate package names.

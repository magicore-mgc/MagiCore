# Dart language version floor

Extracts only a safely understood explicit lower bound from a Dart SDK constraint. Unsupported forms produce no inferred version.

## Chủ sở hữu

Chỉ trích xuất lower bound tường minh có thể hiểu an toàn từ constraint Dart SDK. Dạng chưa hỗ trợ không bị tự suy đoán thành phiên bản.

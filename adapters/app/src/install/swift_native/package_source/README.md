# Swift package-source owner

Owns the existing case-sensitive `.zip` classification shared by installation and `Package.resolved` projection. The non-zip branch remains a defensive Git path and does not imply Git install support.

## Tiếng Việt

Sở hữu predicate `.zip` phân biệt hoa thường đang dùng chung trong install và projection `Package.resolved`. Nhánh không phải zip vẫn là guard Git phòng thủ, không đồng nghĩa Git install được hỗ trợ.

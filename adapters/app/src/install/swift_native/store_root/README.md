# Swift store-root owner

Owns the `MGC_SWIFT_STORE_ROOT` override, the `MGC_DATA_DIR/store/swift` default and root creation. The override stays lazy and whitespace-only values retain the existing fallback behavior.

## Tiếng Việt

Sở hữu override `MGC_SWIFT_STORE_ROOT`, default `MGC_DATA_DIR/store/swift` và tạo root. Override được xử lý lazy; giá trị chỉ có khoảng trắng giữ fallback hiện có.

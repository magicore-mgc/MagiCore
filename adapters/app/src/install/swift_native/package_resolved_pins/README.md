# Swift Package.resolved projection owner

Keeps graph order and chooses a registry or Git pin builder based on the shared source classifier. The owner only projects existing graph/lock data; it does not resolve packages or claim Git materialization support.

## Tiếng Việt

Giữ thứ tự graph và chọn builder pin registry/Git theo owner phân loại source dùng chung. Owner chỉ chiếu dữ liệu graph/lock đang có; không resolve package và không tuyên bố Git materialization được hỗ trợ.

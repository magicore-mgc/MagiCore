# Swift Git-pin owner

Maps repository identity, parsed version state, optional lock revision and source location into the existing pin shape. This is lock projection only; it does not make Git transport available.

## Tiếng Việt

Ánh xạ repository identity, state version đã parse, revision lock tùy chọn và source location vào shape pin hiện có. Đây chỉ là projection lock, không mở Git transport.

# Swift Git-checkout guard owner

Routes non-archive Swift inputs to the existing protocol boundary, which currently returns `Unsupported`. No Git child process or unverified checkout fallback is allowed.

## Tiếng Việt

Đưa input Swift không phải archive qua ranh giới protocol hiện tại, đang trả `Unsupported`. Không chạy Git process con và không fallback sang checkout chưa xác minh.

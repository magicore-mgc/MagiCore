# Swift Git-provenance owner

Reads the first exact-name `git-commit:` marker from canonical lock package data. Missing package or marker stays `None`; this owner does not validate or fabricate a revision.

## Tiếng Việt

Đọc marker `git-commit:` đầu tiên theo đúng tên package từ canonical lock. Thiếu package hoặc marker vẫn là `None`; owner không tự xác minh hay bịa revision.

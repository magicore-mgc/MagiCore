# Archive policy / Chính sách archive

Owns the Pub archive directory name, default byte cap, environment-variable parsing, and positive-limit validation. It does not read or write files.

Quản lý tên thư mục archive Pub, giới hạn byte mặc định, parse biến môi trường và chặn giới hạn không dương. Module này không đọc hay ghi file.

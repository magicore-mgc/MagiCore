# Archive path / Đường dẫn archive

Owns SHA-256 digest shape validation, cache-directory symlink/type checks, and normalized archive path derivation. It does not open archive contents.

Quản lý kiểm tra định dạng digest SHA-256, loại/symlink của thư mục cache và chuẩn hóa đường dẫn archive. Module không mở nội dung archive.

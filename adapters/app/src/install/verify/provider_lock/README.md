# Provider lock checks / Kiểm tra lock provider

Contains current provider-lock existence checks for Flutter, Gradle, SwiftPM, and CocoaPods. Parsing and semantic checksum validation remain unimplemented.

Chứa các kiểm tra tồn tại lock hiện có cho Flutter, Gradle, SwiftPM và CocoaPods. Parse và kiểm checksum theo ngữ nghĩa chưa được triển khai.

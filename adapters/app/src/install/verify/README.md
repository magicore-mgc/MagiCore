# App verification facade / Facade xác minh App

Preserves the public verification API and separates provider lock presence checks from package-file SHA-256 verification. Provider lock parsing is not claimed where the implementation currently only checks file presence.

Giữ API xác minh công khai và tách kiểm tra lock provider khỏi xác minh SHA-256 file package. Không tuyên bố parse lock provider ở nơi hiện mới kiểm tra sự tồn tại file.

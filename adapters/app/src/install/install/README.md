# Install coordinator / Điều phối install

Dispatches the requested App ecosystem to the native lane and rejects unsupported or unsafe partial lanes before mutation. Language/offline gates, Flutter transaction/lock policy and Swift protocol/lock policy have separate owners and nearest tests. The stable public `run_install` entry remains available; the same-instance adapter path uses an internal entry that accepts the Swift registry protocol retained during resolve. Calls without that state continue to use the environment fallback.

Điều phối ecosystem App sang lane native và từ chối lane chưa hỗ trợ hoặc chỉ cài một phần trước khi sửa project. Gate language/offline, transaction/policy lock Flutter và protocol/policy lock Swift có owner cùng test gần riêng. Entry public `run_install` được giữ nguyên; luồng adapter cùng instance dùng entry nội bộ nhận protocol registry Swift đã giữ từ bước resolve. Call không có state đó tiếp tục dùng fallback từ môi trường.

# v4 App lock merge / Gộp lock App v4

Converts lane rows losslessly, verifies the on-disk merge base, preserves sibling rows, refuses signed rewrites, finalizes the digest and atomically publishes v4.
Chuyển row lane không mất dữ liệu, xác minh base trên đĩa, giữ row sibling, từ chối ghi đè lock đã ký, chốt digest và publish v4 nguyên tử.

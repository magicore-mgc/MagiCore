# v3 App lock merge / Gộp lock App v3

Loads a readable v3 lock, replaces only the active core's scoped rows/root pins, preserves sibling owners and atomically publishes a changed document.
Đọc lock v3 hợp lệ, chỉ thay row/root pin trong scope của core hiện tại, giữ owner khác và publish nguyên tử khi có thay đổi.

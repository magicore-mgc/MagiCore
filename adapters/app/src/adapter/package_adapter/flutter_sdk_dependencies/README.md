# flutter_sdk_dependencies

## Responsibility

Determine whether Flutter SDK packages contribute implicit dependencies and expand those dependencies for lock replay. Other App languages keep the original manifest unchanged.

## Ghi chú tiếng Việt

Folder này xác định SDK Flutter có dependency ngầm hay không và mở rộng các dependency đó khi replay lock. Ngôn ngữ App khác giữ nguyên manifest đầu vào.

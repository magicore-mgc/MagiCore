# manifest_parse

## Responsibility

Keep `PackageAdapter::parse_manifest` routed through the existing App language manifest dispatcher. This owner does not add parsing or mutation capability.

## Ghi chú tiếng Việt

Folder này giữ route của `PackageAdapter::parse_manifest` qua dispatcher manifest theo ngôn ngữ App hiện có. Owner không tự thêm khả năng parse hay ghi manifest.

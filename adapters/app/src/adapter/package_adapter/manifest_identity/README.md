# manifest_identity

## Responsibility

Map each App language to the manifest identity used by the mutation journal and recovery path. MAUI and Tauri retain their project-root validation behavior.

## Ghi chú tiếng Việt

Folder này ánh xạ từng ngôn ngữ App sang identity manifest mà mutation journal và recovery dùng. MAUI và Tauri giữ nguyên bước xác thực manifest tại project root.

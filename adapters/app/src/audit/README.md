# App audit

## Responsibility

Routes the detected App language to its audit lane. The router, language scanners, aggregate scan plan and parser fixtures have named owners; this module does not add scanner capability.

## Trách nhiệm

Điều phối ngôn ngữ App đã nhận diện tới lane audit tương ứng. Router, scanner theo ngôn ngữ, kế hoạch aggregate và parser fixture có owner riêng; module này không tự thêm capability scanner.

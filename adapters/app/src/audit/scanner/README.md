# App audit scanners

## Responsibility

Provides named Flutter, Kotlin, Swift and CocoaPods entry points and keeps the React Native/Multi manifest aggregator behind the existing scanner facade. Production lanes keep their current native OSV delegates; parser fixtures remain test-only.

## Trách nhiệm

Cung cấp entry point riêng cho Flutter, Kotlin, Swift và CocoaPods; giữ bộ gom manifest React Native/Multi sau facade scanner hiện tại. Lane production tiếp tục dùng OSV native; parser fixture vẫn chỉ dùng khi test.

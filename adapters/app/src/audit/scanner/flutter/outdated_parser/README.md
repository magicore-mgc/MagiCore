# Flutter outdated parser fixture

## Responsibility

Contains the existing `cfg(test)` pub-outdated data types, parser and the six nearest parser regression cases. It is not a production freshness resolver and does not run Flutter.

## Trách nhiệm

Chứa type dữ liệu, parser pub-outdated `cfg(test)` hiện có và sáu case hồi quy gần owner. Đây không phải freshness resolver production và không chạy Flutter.

# OWASP fixture schema

## Responsibility

Defines the private, test-only serde representation for OWASP dependency-check reports. Field visibility is limited to the local Kotlin parser boundary.

## Trách nhiệm

Định nghĩa schema serde private, chỉ dùng trong test cho report OWASP dependency-check. Field chỉ được mở trong boundary parser Kotlin cục bộ.

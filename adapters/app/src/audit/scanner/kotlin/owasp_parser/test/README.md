# OWASP parser tests

## Responsibility

This folder owns eight existing regression cases grouped by report findings, invalid schema, package identity, large payload and concurrent parsing. There is currently no product-level test proving stale-report freshness; add one against the actual scanner in the later test phase.

## Trách nhiệm

Folder sở hữu tám case hồi quy hiện có, chia theo finding report, schema lỗi, package identity, payload lớn và parse đồng thời. Hiện chưa có test product chứng minh freshness của report cũ; cần bổ sung test qua scanner thật trong phase test sau.

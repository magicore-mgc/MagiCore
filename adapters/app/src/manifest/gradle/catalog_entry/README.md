# Catalog entry data owner

This owner defines the public data-only `CatalogEntry` returned by the Gradle version-catalog parser.
Owner này định nghĩa `CatalogEntry` công khai chỉ chứa dữ liệu, được parser version catalog Gradle trả về.

The field names, public visibility, types, and derives are preserved from the prior API. Behavior belongs to the reader or pin-update owners.
Tên field, visibility công khai, kiểu dữ liệu và derive được giữ nguyên từ API cũ. Hành vi thuộc owner reader hoặc cập nhật pin.

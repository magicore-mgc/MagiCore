# Native lock parsers / Parser lock native

Groups parser fixtures that validate SwiftPM `Package.resolved`, CocoaPods `Podfile.lock`, and Dart `pubspec.lock`. Each parser has a separate same-name owner folder.

Nhóm fixture parser kiểm tra SwiftPM `Package.resolved`, CocoaPods `Podfile.lock` và Dart `pubspec.lock`. Mỗi parser có owner folder cùng tên riêng.

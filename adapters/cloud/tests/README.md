# Cloud public integration tests

This directory verifies the public Cloud adapter boundary from outside the crate: framework detection, public exports, capability claims, and factory behavior. Cargo continues to discover the integration.rs target; its 30 ordered wrappers dispatch to focused owners under integration/.

Thư mục này kiểm tra ranh giới public của Cloud adapter từ bên ngoài crate: nhận diện framework, export công khai, capability được claim và factory. Cargo tiếp tục nhận target integration.rs; 30 wrapper giữ thứ tự và gọi implementation tại các owner nhỏ trong integration/.

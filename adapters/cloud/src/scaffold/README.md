# Cloud scaffold

Dispatches to a framework-specific source owner for CDK, Cloudflare, Pulumi or Terraform. The destination directory is created before the selected generator runs, matching current side-effect order.

Điều phối đến owner sinh source riêng cho CDK, Cloudflare, Pulumi hoặc Terraform. Thư mục đích tiếp tục được tạo trước khi chạy generator theo đúng thứ tự side-effect hiện tại.

Existing unit-test registration and generated output bytes remain unchanged.

Đăng ký unit test hiện tại và byte output được giữ nguyên.

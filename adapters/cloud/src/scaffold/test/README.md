# Cloud scaffold tests

This directory covers framework scaffold dispatch and generated project files for CDK, Cloudflare, Pulumi, and Terraform. The production-source refactor preserves these test source files and their registration path.

Thư mục này kiểm tra dispatch scaffold và file dự án được sinh cho CDK, Cloudflare, Pulumi và Terraform. Đợt refactor production-source giữ nguyên các file test và đường đăng ký của chúng.

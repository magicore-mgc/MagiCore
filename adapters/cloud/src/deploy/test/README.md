# Cloud deploy tests

This directory covers the native deploy API's current fail-closed contract. It verifies that unsupported provider execution is reported instead of invoking a provider CLI or inventing a dry-run result.

Thư mục này kiểm tra hợp đồng fail-closed hiện tại của API deploy native. Test xác nhận thao tác provider chưa hỗ trợ được báo lỗi thay vì chạy CLI provider hoặc bịa kết quả dry-run.

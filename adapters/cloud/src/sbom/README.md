# Cloud SBOM bridge

Adapts the shared lockfile/SBOM generator to the Cloud crate's public SBOM entry point.

Nối lockfile/SBOM generator dùng chung vào entry point SBOM public của crate Cloud.

The existing error remains mapped to `MgError::Other` with its original message.

Lỗi hiện tại tiếp tục được ánh xạ sang `MgError::Other` với thông báo gốc.

# Cloud package project metadata owner

Selects the existing Web-backed or Cloud capability table and projects each `CloudType` into the same `ManifestIdentity` fields and paths.

Chọn capability table Web-backed hoặc Cloud hiện có và ánh xạ từng `CloudType` thành đúng các trường/path `ManifestIdentity` như trước.

This owner makes no filesystem changes and adds no capability claim.

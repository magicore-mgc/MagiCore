# Content Store owner

Keeps CDK/Pulumi install on the embedded Web engine; Terraform never falls back to the Terraform CLI as a package manager.

Giữ install CDK/Pulumi qua Web engine nhúng; Terraform không fallback sang Terraform CLI để quản lý package.

This folder has one implementation owner; its module facade only wires exports.

Folder này có một owner implementation; facade module chỉ nối module và export.

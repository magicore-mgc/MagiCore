# Unclaimed Capabilities owner

Keeps empty marker implementations that inherit shared unsupported defaults; this does not claim optimizer, materializer, simulator, device or model-runtime support.

Giữ các impl marker rỗng kế thừa unsupported mặc định dùng chung; không claim optimizer, materializer, simulator, device hoặc model-runtime.

This folder has one implementation owner; its module facade only wires exports.

Folder này có một owner implementation; facade module chỉ nối module và export.

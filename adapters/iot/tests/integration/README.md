# IoT adapter integration-test owners

The Cargo target remains tests/integration.rs with 20 stable ordered wrappers. Implementations are grouped by symlink safety, framework detection/config, adapter contracts, package operations, audit/SBOM, and board registry.

Cargo target vẫn là tests/integration.rs với 20 wrapper ổn định theo thứ tự cũ. Implementation được chia theo symlink, nhận diện/config framework, adapter contract, package operations, audit/SBOM và board registry.

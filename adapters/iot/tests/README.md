# IoT public integration tests

This directory verifies the public IoT adapter boundary: framework detection, adapter factory and capability contracts, fail-closed package operations, audit/SBOM, and board registry APIs. Cargo keeps discovering tests/integration.rs; the 20 ordered wrappers dispatch to focused owners under integration/.

Thư mục này kiểm tra ranh giới public của IoT adapter: nhận diện framework, factory/capability, package operations fail-closed, audit/SBOM và API board registry. Cargo tiếp tục nhận tests/integration.rs; 20 wrapper giữ thứ tự và chuyển sang owner nhỏ trong integration/.

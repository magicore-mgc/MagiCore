# IoT flash tests

EN: Existing nearest tests verify that flashing remains explicitly unsupported for current frameworks and that the directory helper recognizes known serial prefixes, sorts results, and returns empty for a missing directory. They use temporary files only; they do not test command construction, invoke hardware tools, or touch devices.

VI: Test gần nhất hiện có xác minh flash vẫn Unsupported cho các framework hiện tại và helper thư mục nhận diện prefix serial, sắp xếp kết quả, trả rỗng khi thư mục không tồn tại. Test chỉ dùng file tạm; không kiểm tra dựng lệnh, không gọi tool phần cứng và không đụng thiết bị.

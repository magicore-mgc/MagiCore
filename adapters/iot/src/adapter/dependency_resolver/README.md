# Dependency Resolver IoT adapter owner

Preserves explicit unsupported add/remove/update results. Dependency operations are never delegated to pio or west.

Giữ kết quả unsupported rõ ràng cho add/remove/update. Không ủy quyền dependency operation cho pio hoặc west.

The owner preserves the current IoT capability matrix and reuses shared types/errors.

Owner giữ nguyên capability matrix IoT và dùng lại type/error chung.

# Project Detection IoT adapter owner

Maps the existing IoT framework manifest detector to ProjectDetector. Detection rules remain in the framework owner.

Nối detector manifest IoT hiện có vào ProjectDetector. Quy tắc detect vẫn do framework owner sở hữu.

The owner preserves the current IoT capability matrix and reuses shared types/errors.

Owner giữ nguyên capability matrix IoT và dùng lại type/error chung.

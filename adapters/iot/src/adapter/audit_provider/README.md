# Audit Provider IoT adapter owner

Keeps the shared polyglot audit route and the existing unsupported scanner evidence for unscanned dependencies.

Giữ route audit polyglot dùng chung và evidence scanner unsupported hiện có cho dependency chưa quét.

The owner preserves the current IoT capability matrix and reuses shared types/errors.

Owner giữ nguyên capability matrix IoT và dùng lại type/error chung.

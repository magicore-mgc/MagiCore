# Factory IoT adapter owner

Constructs the adapter from the existing framework detector and preserves `None` for a non-IoT project.

Tạo adapter từ framework detector hiện tại và giữ `None` cho project không phải IoT.

The owner preserves the current IoT capability matrix and reuses shared types/errors.

Owner giữ nguyên capability matrix IoT và dùng lại type/error chung.

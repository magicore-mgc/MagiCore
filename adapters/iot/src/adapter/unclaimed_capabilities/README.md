# Unclaimed Capabilities IoT adapter owner

Keeps empty marker impls so shared capability defaults remain fail-closed and IoT does not claim unimplemented behavior.

Giữ impl marker rỗng để default capability dùng chung fail-closed và IoT không claim hành vi chưa implement.

The owner preserves the current IoT capability matrix and reuses shared types/errors.

Owner giữ nguyên capability matrix IoT và dùng lại type/error chung.

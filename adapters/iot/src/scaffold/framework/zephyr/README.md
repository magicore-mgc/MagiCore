# Zephyr scaffold output

Owns the current `west.yml` manifest and MagiCore IoT manifest output for registered Zephyr boards. It does not initialize west, fetch Zephyr or invoke a build.

Sở hữu output `west.yml` và MagiCore IoT manifest hiện có cho board Zephyr đã đăng ký. Không khởi tạo west, tải Zephyr hoặc gọi lệnh build.

# Cargo package-name tests

These tests cover Cargo-compatible Unicode identifier boundaries and the helper's typed rejection behavior. The ESP32 framework test separately verifies that invalid names fail before the project directory is created.

Các test bao phủ ranh giới Unicode identifier tương thích Cargo và lỗi typed khi tên sai. Test framework ESP32 riêng kiểm tra tên sai bị từ chối trước khi tạo thư mục project.

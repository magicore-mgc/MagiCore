# ESP32 Rust scaffold output

Owns the existing Cargo manifest, MagiCore manifest and `src/main.rs` starter output for ESP32 Rust boards. It validates the Cargo package name before filesystem mutation and writes files only; it does not run Cargo or install crates.

Sở hữu output Cargo manifest, MagiCore manifest và `src/main.rs` hiện có cho board ESP32 Rust. Xác thực tên Cargo trước khi ghi filesystem; không chạy Cargo hoặc cài crate.

# Missing publish-time warning

Emits one process-local warning when `[security] allow_missing_time = true` is actually used to accept a package whose registry timestamp is absent or malformed.

Phát một cảnh báo trong process khi cấu hình `allow_missing_time = true` thực sự được dùng để chấp nhận package thiếu hoặc sai timestamp registry.

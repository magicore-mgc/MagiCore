# env_truthy

## Responsibility / Trách nhiệm
Reads a named process environment variable and recognizes the existing trimmed, case-insensitive truthy values.

Đọc biến môi trường theo tên và nhận diện các giá trị truthy hiện hành sau trim, không phân biệt hoa thường.

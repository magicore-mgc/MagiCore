# Downgrade guard pin helpers

## Purpose

Owns reading prior direct pins from the valid lockfile, checking whether a previous root pin still satisfies the requested range, and parsing encoded web root pins.

## Vietnamese

Sở hữu việc đọc pin trực tiếp trước đó từ lockfile hợp lệ, kiểm tra root pin cũ còn thoả range yêu cầu, và parse root pin web đã mã hoá.

# enforce_no_downgrade

Owns valid-lock baseline extraction and comparison against the exact indexed root package returned by the shared resolver. The old baseline comes from the owner-scoped `root_dependencies_by_owner` pins (legacy Web v2 may use `root_dependencies`), then must resolve to a package row in the scoped lock. Package rows are never searched by name to infer a direct pin. Missing or stale root pins remove the baseline for that dependency only; other direct pins remain checked. Duplicate/unknown root identities, missing pinned rows, read/parse failures, invalid direct locked versions, and incomplete or mismatched resolver metadata return local typed errors.

Sở hữu trích baseline từ lock hợp lệ và so sánh với package root chính xác có index từ resolver dùng chung. Baseline cũ lấy từ pin `root_dependencies_by_owner` đúng owner (lock Web v2 cũ có thể dùng `root_dependencies`), rồi phải trỏ tới package row trong lock đã scope. Không tìm package row theo tên để suy ra pin direct. Root pin thiếu/cũ chỉ làm mất baseline của dependency đó; các pin direct khác vẫn được kiểm tra. Root identity trùng/không nhận diện, package row bị thiếu, lỗi đọc/parse, version direct không hợp lệ, metadata resolver thiếu hoặc sai đều trả lỗi typed cục bộ.

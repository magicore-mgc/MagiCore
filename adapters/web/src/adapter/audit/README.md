# Audit provider / Provider audit

Owns aggregation of npm, Rust, Python, Go, Java, .NET and optional WASM-provenance scanners into the web audit report.

Sở hữu tổng hợp scanner npm, Rust, Python, Go, Java, .NET và WASM provenance tùy chọn thành báo cáo audit web. Scanner-specific implementations remain in shared audit and web service owners.

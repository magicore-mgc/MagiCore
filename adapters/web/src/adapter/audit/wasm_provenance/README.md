# WASM provenance / Nguồn gốc WASM

Owns bounded discovery of project `.wasm` files and the existing magic-header/readability report. This scanner reports binary provenance only; dependency vulnerability findings remain in ecosystem sidecar scanners.

Sở hữu tìm `.wasm` có giới hạn và báo cáo header/khả năng đọc hiện tại. Scanner này chỉ xác nhận binary; vulnerability dependency vẫn thuộc scanner hệ sinh thái.

# Construction / Khởi tạo

Owns validated registry-chain constructors and adapter initialization. Keeps registry URL guards and token-to-endpoint binding unchanged.

Sở hữu constructor registry-chain đã kiểm tra và khởi tạo adapter. Giữ nguyên guard URL registry và ràng buộc token/endpoint. Existing constructor contract tests remain registered under `src/test/` until the test phase.

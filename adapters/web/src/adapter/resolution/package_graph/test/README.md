# Package graph tests

Nearest tests for exact direct-root propagation into Web install graph records. They exercise root selection identity and the fail-closed missing-root path without requiring a registry or filesystem fixture.

Test gần nhất cho việc truyền identity root trực tiếp vào graph cài Web. Test bao phủ chọn đúng root và nhánh fail-closed khi thiếu root, không cần registry hoặc fixture filesystem.

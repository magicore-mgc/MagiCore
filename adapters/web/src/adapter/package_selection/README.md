# Package selection / Chọn phiên bản package

Owns version-list ordering, npm dist-tag pinning, add-range inference, age-gated latest selection, and saved-range preference.

Sở hữu sắp thứ tự phiên bản, pin npm dist-tag, suy ra range cho add, chọn latest có age-gate và giữ range khi update. Registry and provider policy remain delegated to their existing owners. Tests remain at `src/test/` until the verification phase.

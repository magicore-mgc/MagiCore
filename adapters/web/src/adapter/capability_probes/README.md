# Capability probes / Probe capability

Owns the existing scaffold, materializer, and lifecycle capability evidence probes. This module records current capabilities only; concrete behavior remains in their service owners.

Sở hữu probe bằng chứng scaffold, materializer và lifecycle hiện có. Module chỉ khai báo bằng chứng capability; behavior cụ thể vẫn do service owner xử lý.

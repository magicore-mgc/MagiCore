# Package operations / Thao tác package

Owns the PackageAdapter contract: manifest identity/parsing, add preparation, list, age-gate configuration, dedupe preference, and audit fix.

Sở hữu contract PackageAdapter: định danh/parse manifest, chuẩn bị add, list, cấu hình age-gate, dedupe và audit fix. This is composition only; existing services retain their behavior and tests are deferred.

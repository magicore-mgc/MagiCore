# Cached metadata reuse policy

Returns cached metadata only when it is fresh, or when a recorded retry cooldown applies and the existing maximum-stale policy still accepts it.

## Chính sách tái sử dụng metadata cache

Chỉ trả metadata đã cache khi còn mới, hoặc khi retry đang cooldown và chính sách giới hạn tuổi stale hiện tại vẫn cho phép.

# Metadata cache lookup

Applies the existing age-gate bypass before reading the shared metadata cache. Cache read errors continue through the existing DependencyError contract.

## Tra cứu cache metadata

Áp dụng quy tắc bỏ qua cache hiện có khi age gate bật trước khi đọc cache dùng chung. Lỗi đọc cache tiếp tục dùng hợp đồng DependencyError hiện tại.

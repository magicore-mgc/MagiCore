# Conditional metadata refresh

Owns ETag-based conditional requests, 304 reuse, refreshed metadata writes, and the existing too-old stale rejection or retry-cooldown write after request failure.

## Refresh metadata có điều kiện

Sở hữu request có ETag, tái sử dụng khi 304, ghi metadata mới, và giữ nguyên từ chối stale quá cũ hoặc ghi cooldown retry khi request lỗi.

# Registry fetch with stale fallback

Owns full metadata fetches, successful record persistence, and reuse of a still-usable stale record after network failure. It retains the existing DependencyError message when no fallback is permitted.

## Fetch registry và fallback stale

Sở hữu fetch metadata đầy đủ, lưu record thành công, và dùng record stale còn hợp lệ khi mạng lỗi. Giữ nguyên DependencyError hiện có khi không được phép fallback.

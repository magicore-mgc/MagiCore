# Fetch-result contract owner

EN: Owns `TarballPayload` and `TarballFetchResult`. The cached-path variant retains its supplied byte length without reading the path, and the public `crate::profile::*` route remains stable.

VI: Quản lý `TarballPayload` và `TarballFetchResult`. Nhánh cached-path giữ nguyên độ dài byte được truyền vào mà không đọc file; route công khai `crate::profile::*` không đổi.

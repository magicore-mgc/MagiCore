# Web update version preference

## Purpose

Owns latest-version selection (stable dist-tag first, then max stable, then max any) and range-style preservation (^, ~, open, exact) for `mgc update`.

## Vietnamese

Owner chọn version mới nhất (ưu tiên dist-tag stable, rồi max stable, rồi max bất kỳ) và giữ kiểu range (^, ~, mở, chính xác) cho `mgc update`.

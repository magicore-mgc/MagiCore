# error

Defines failures owned by the response-body stream: transport read, staging-file create/write/flush, and byte-count overflow. Each variant keeps its underlying source for diagnostics and retry classification by the caller.

Định nghĩa lỗi riêng của luồng đọc body: đọc transport, tạo/ghi/flush file staging và tràn bộ đếm byte. Mỗi variant giữ source để tầng gọi chẩn đoán và phân loại retry.

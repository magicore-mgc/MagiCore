# body_stream tests

Focused tests cover small in-memory results, unknown/understated lengths crossing the threshold, stream-error and cancellation cleanup, and preservation of a pre-existing destination. These tests are authored but not run while the machine-wide storage use exceeds the requested 80 GB limit.

Test tập trung vào kết quả nhỏ trong RAM, header thiếu/khai thấp nhưng body vượt ngưỡng, dọn file dở dang khi stream lỗi/hủy và giữ nguyên file đích đã tồn tại. Test đã được viết nhưng chưa chạy vì dung lượng máy đang vượt giới hạn 80 GB đã yêu cầu.

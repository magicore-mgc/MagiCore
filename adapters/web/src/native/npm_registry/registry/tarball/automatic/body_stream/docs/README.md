# body_stream work records

This directory tracks the active source change for automatic registry response-body handling. The source-of-truth checklist is `Checklist.md`; `ProgressReport.md` records evidence and limits. Runtime checks stay open until the machine storage constraint is met.

Thư mục này theo dõi thay đổi source đang làm cho việc đọc body response registry. `Checklist.md` là checklist nguồn; `ProgressReport.md` ghi bằng chứng và giới hạn. Kiểm tra runtime vẫn mở cho đến khi đáp ứng giới hạn dung lượng máy.

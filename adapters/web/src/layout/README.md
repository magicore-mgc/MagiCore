# Web layout facade

## Purpose

Facade only: re-exports `create_symlink` from the `install/link_tree/symlink/` owner so `crate::layout::create_symlink` callers stay stable.

## Vietnamese

Chỉ là facade: re-export `create_symlink` từ owner `install/link_tree/symlink/` để caller `crate::layout::create_symlink` ổn định.

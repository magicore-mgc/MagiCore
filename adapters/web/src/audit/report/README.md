Projects source/query outcomes to the existing `AuditReport` contract. It owns clean-zero, JSR-only Partial, and completed npm/JSR coverage status while preserving audited/skipped counts and the current reason strings.

Chuyển kết quả source/query sang hợp đồng `AuditReport` hiện có. Owner này sở hữu clean-zero, Partial khi chỉ có JSR và trạng thái coverage npm/JSR hoàn tất; giữ nguyên số audited/skipped và reason string hiện tại.

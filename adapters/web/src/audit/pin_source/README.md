Selects Web audit pins only from the verified v4 owner or the checked legacy `mgc.lock` reader. It owns the rival-lock remediation gate and translates its local typed failure back into the existing `MgError` boundary. The lockfile remains the sole operational source; rival lockfiles are never parsed here.

Chọn pin audit Web từ owner v4 đã xác minh hoặc reader legacy `mgc.lock` đã kiểm tra. Owner này sở hữu gate remediation lockfile đối thủ và chuyển lỗi typed cục bộ về ranh giới `MgError` hiện có. Lockfile vẫn là nguồn vận hành duy nhất; không parse lockfile đối thủ ở đây.

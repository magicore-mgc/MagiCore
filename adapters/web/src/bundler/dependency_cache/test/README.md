# Dependency cache tests

These tests pin session-cache hits and reject invalid package names before filesystem resolution. Runtime bundling is covered in the sibling `build` owner and the existing CLI route integration test.

Các test này ghim cache hit theo session và chặn tên package sai trước khi phân giải filesystem. Runtime bundling được kiểm ở owner `build` bên cạnh và integration test route CLI hiện có.

# Dependency name validation tests

These cases pin accepted plain/scoped/subpath shapes and reject traversal, backslashes, device/ADS syntax, control bytes, malformed segments and host-path prefixes.

Các case ghim dạng package thường/scoped/subpath được nhận và từ chối traversal, backslash, device/ADS, control byte, segment lỗi và prefix path của host.

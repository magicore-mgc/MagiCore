# Package entry orchestration tests

These cases exercise only the resolver facade's missing-package and invalid-name outcomes. Manifest selection and path confinement live beside `manifest_entry`; package identifier splitting and scoped/unscoped subpaths live beside `package_selector`.

Các case này chỉ kiểm kết quả missing-package và tên sai của resolver facade. Chọn manifest/giới hạn path nằm cạnh `manifest_entry`; tách identifier và subpath scoped/thường nằm cạnh `package_selector`.

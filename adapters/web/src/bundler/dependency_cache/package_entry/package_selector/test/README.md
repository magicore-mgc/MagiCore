# Package selector tests

These tests cover plain/scoped splitting, direct file subpaths, package-root symlink compatibility and subpath containment. The authored Rust cases remain NOT_RUN until the repository source-first phase closes.

Các test bao phủ tách tên thường/scoped, subpath file trực tiếp, tương thích symlink package-root và containment subpath. Test Rust đã viết vẫn NOT_RUN đến khi phase source-first của repository khép lại.

# Manifest entry tests

Cases cover precedence, fallback, safe relative forms and rejection of absolute, cross-platform or escaping symlink entries. These are authored source tests and remain NOT_RUN in the source-first phase.

Các case kiểm thứ tự ưu tiên, fallback, relative path an toàn và từ chối entry absolute/liên OS/symlink thoát package. Test đã được viết nhưng vẫn NOT_RUN trong phase source-first.

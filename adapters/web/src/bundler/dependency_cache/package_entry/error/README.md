# Package-entry errors

Owns the typed rejection and filesystem-failure categories used while resolving installed package entry files. Error text intentionally avoids exposing local filesystem paths to the HTTP response.

Sở hữu loại lỗi typed cho request entry bị từ chối và lỗi filesystem khi resolve file package đã cài. Nội dung lỗi không để lộ path filesystem local ra HTTP response.

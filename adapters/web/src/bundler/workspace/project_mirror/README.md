# Bundler project mirror

## Purpose

Owns mirroring the project into a build workspace (hard link, falling back to copy) with the historical skip policy (`node_modules`, `.magicore`, `dist`, `build`, `.next`, `out`) and creating the platform-native `node_modules` directory link.

## Vietnamese

Sở hữu việc mirror project vào workspace build (hard link, fallback copy) với policy bỏ qua hiện hành (`node_modules`, `.magicore`, `dist`, `build`, `.next`, `out`) và tạo link thư mục `node_modules` theo nền tảng.

# Dev-server path privacy

## Purpose

Owns which paths the dev server may serve: only the public `.well-known` locations are allowed, and any other dot-component marks the path private (dotfiles are never exposed).

## Vietnamese

Sở hữu việc path nào dev server được phục vụ: chỉ vị trí `.well-known` công khai được cho phép, mọi component bắt đầu bằng dấu chấm khác đều đánh dấu path là private (không bao giờ lộ dotfile).

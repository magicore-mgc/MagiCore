# Dependency response-payload tests

These nearest tests pin JavaScript literal encoding and the fixed CSS comment so request or package data cannot become executable source. They are authored and NOT_RUN in the source-first phase.

Các test gần owner ghim cách encode JavaScript literal và comment CSS cố định để dữ liệu request/package không thành source thực thi. Test đã viết nhưng NOT_RUN trong phase source-first.

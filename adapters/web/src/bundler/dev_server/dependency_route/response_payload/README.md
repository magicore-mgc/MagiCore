# Dependency response payload

Owns the pure JavaScript payloads added by the dependency route. CSS and package names are serialized as JavaScript string data, and request-controlled names never appear in comments or executable syntax.

Sở hữu các JavaScript payload thuần mà dependency route trả về. CSS và tên package được serialize thành string data; tên do request điều khiển không xuất hiện trong comment hoặc cú pháp thực thi.

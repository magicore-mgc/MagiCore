# Compile options tests

Pins compiler-version drift, project/source cache-key isolation, and absent/unreadable tsconfig behavior. `mod.rs` only wires the focused test files; `support.rs` holds the shared success helper.

Ghim sai lệch compiler-version, tách biệt cache key project/source, và behavior tsconfig vắng/không đọc được. `mod.rs` chỉ nối các file test theo trách nhiệm; `support.rs` giữ helper thành công dùng chung.

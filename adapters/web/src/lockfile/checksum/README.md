# Checksum owner / Owner checksum

EN: Owns the Web integrity environment gates, buffered and reader-based SHA-512 encoding, and once-per-lock missing-checksum warning. It does not read or mutate the lockfile.
VI: Quản lý cờ integrity của Web, mã hóa SHA-512 cho buffer và reader, cùng cảnh báo thiếu checksum một lần mỗi lock; không đọc hay sửa lockfile.

Environment names, warning text, empty-lock behavior and per-project de-duplication stay unchanged. Runtime is not verified in S169.

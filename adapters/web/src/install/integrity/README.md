# Web install integrity / Integrity cài đặt Web

This owner applies the shared Subresource Integrity policy to in-memory tarballs and bounded-memory readers. It does not select the registry or decide which cache is authoritative. Its tests are registered beside the implementation under `test/`.

Owner này áp dụng cùng chính sách Subresource Integrity cho tarball trong RAM và reader có bộ nhớ giới hạn. Module không chọn registry và không quyết định cache nào có thẩm quyền. Test được đăng ký cạnh implementation dưới `test/`.

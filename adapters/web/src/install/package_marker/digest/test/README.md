# SHA-256 helper tests / Test hàm SHA-256

Owns tests for byte hashing, streamed file hashing, and reader hashing. Detailed cases are split into named subfolders under this test owner.

Sở hữu test hash bytes, đọc file dạng luồng và hash reader. Các ca cụ thể được tách thành thư mục con có tên trong owner test này.

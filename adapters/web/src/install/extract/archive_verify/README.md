# Archive verification / Xác minh archive

Streams the archive, rejects unsupported entries, compares every cached file, validates the complete tree signature, then imports and claims CAS blobs.

Đọc archive theo stream, từ chối entry không hỗ trợ, so sánh từng file cache, xác minh chữ ký toàn cây rồi mới import và claim blob CAS.

# Opened file identity / Định danh file đã mở

Owns Unix device/inode and Windows volume/file-index identities, safe path containment, no-follow/reparse-point opening, and opened-handle checks. Platform-specific code stays under cfg gates.

Quản lý identity device/inode Unix, volume/file-index Windows, containment path, mở không theo symlink/reparse và kiểm tra handle đã mở. Code theo nền tảng nằm dưới cfg tương ứng.

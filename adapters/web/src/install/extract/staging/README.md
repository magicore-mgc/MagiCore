# Extraction staging / Staging extraction

Owns unique temporary-root names and bounded concurrent publication. A winning root is content-verified; stale staging and failed publication retain their existing cleanup rules.

Quản lý tên temporary-root duy nhất và publish đồng thời có giới hạn. Root thắng được xác minh nội dung; staging cũ và lỗi publish giữ nguyên quy tắc dọn.

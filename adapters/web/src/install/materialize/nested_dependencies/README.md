# Nested Dependencies

Owns the Web installer nested dependencies operation and its nearest behavioral tests. This folder keeps the existing materialization semantics and public routes; it does not add a new install policy.

Thư mục sở hữu thao tác nested dependencies của Web installer cùng test gần nhất. Cấu trúc này giữ nguyên ngữ nghĩa materialize và đường API hiện có, không thêm policy install mới.

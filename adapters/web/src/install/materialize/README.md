# Web dependency materialization

This folder is the compatibility owner for Web dependency materialization. `mod.rs` only wires responsibility owners and preserves the existing `crate::install::materialize::*` paths. Behavior is separated into extracted-root lookup, graph selection, filesystem cleanup, virtual-store paths, strict layout, package-root resolution, and nested dependency layout. The install transaction, marker checks, link mode, existing `MgError` contract and diagnostic text, and lifecycle recording remain unchanged; a typed local error migration is a separate task. Focused tests live beside each owner; shared fixtures are under `test/`.

Thư mục này là owner tương thích cho materialize dependency Web. `mod.rs` chỉ nối các owner và giữ nguyên đường dẫn `crate::install::materialize::*`. Behavior được tách theo tra cứu extracted-root, chọn graph, dọn filesystem, path virtual-store, strict layout, tìm package-root và dependency lồng. Transaction install, marker check, link mode, contract `MgError`, diagnostic hiện tại và lifecycle recording không đổi; chuyển sang typed error riêng là task riêng. Test tập trung nằm cạnh từng owner; fixture dùng chung ở `test/`.

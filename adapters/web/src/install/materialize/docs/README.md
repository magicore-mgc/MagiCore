# Materialization tracking records

This folder keeps the materialization owner's current progress and task checklist. It records source-only evidence separately from executable verification so that authored tests are not mistaken for passing tests.

Thư mục này lưu tiến độ hiện tại và checklist của owner materialization. Bằng chứng rà source được ghi riêng với kiểm chứng thực thi để test mới viết không bị hiểu nhầm là đã chạy đạt.

# error

Owns typed filesystem and concurrent-publication failures for staging. Each I/O variant retains its source; conversion to the existing `MgError::Store` occurs only at the compatibility boundary.

# error / lỗi staging

Quản lý lỗi filesystem và publish đồng thời có kiểu cho staging. Mỗi lỗi I/O giữ source; chỉ chuyển sang `MgError::Store` tại ranh giới tương thích hiện có.

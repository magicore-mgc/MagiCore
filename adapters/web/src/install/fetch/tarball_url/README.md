# tarball_url

Selects an explicit package tarball URL only when existing transport and registry-domain checks accept it; otherwise it constructs the registry fallback URL. It owns URL policy delegation and formatting, not package fetching.

# tarball_url / URL tarball

Chỉ chọn URL tarball tường minh khi các kiểm tra transport và domain registry hiện có chấp nhận; nếu không thì tạo URL fallback của registry. Owner này quản lý việc gọi chính sách URL và định dạng URL, không tải package.

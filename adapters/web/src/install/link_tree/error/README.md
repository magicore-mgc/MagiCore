# Link-tree errors

Owns operation-specific `LinkTreeError` classification and retains error sources while converting once to the shared `MgError` boundary. Its Display text matches the existing public diagnostic.

Sở hữu phân loại `LinkTreeError` theo operation, giữ source lỗi rồi convert một lần tại ranh giới `MgError` dùng chung. Display giữ nguyên diagnostic public hiện tại.

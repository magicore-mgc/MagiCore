# Strict package link tree

Owns the stable Web package-link API and coordinates mode, bounded pool, package entry, tree traversal, backing files and typed failures. Public exports keep their existing `crate::install::link_tree::*` paths.

Sở hữu API Web package-link ổn định, điều phối mode, pool giới hạn, entry package, duyệt cây, backing file và lỗi typed. Public export giữ path `crate::install::link_tree::*` hiện tại.

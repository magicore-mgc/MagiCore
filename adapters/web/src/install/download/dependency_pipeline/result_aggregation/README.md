# Pipeline result aggregation

Collects completed package results in completion order, sums downloaded bytes, retains extraction roots and shared-cache persistence handles, and returns the first pipeline error using the existing behavior.

Gom kết quả package theo thứ tự hoàn tất, cộng byte đã tải, giữ extraction root và handle ghi shared-cache, rồi trả lỗi pipeline đầu tiên theo hành vi hiện tại.

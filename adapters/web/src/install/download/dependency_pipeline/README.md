# Dependency download pipeline

Owns the Web graph-to-download-to-extraction orchestration. Extract semaphore and blocking-task join failures have local typed errors. It keeps cache/registry selection, package lock scope, integrity verification, extract scheduling, profile events and final return contract in the existing order.

Quản lý điều phối graph → download → extraction của Web. Giữ nguyên thứ tự chọn cache/registry, khóa package, xác minh integrity, lịch extract, profile và contract kết quả.

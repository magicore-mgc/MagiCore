# Prefetch errors

This owner classifies semaphore closure and task-join failures locally. Conversion at the existing public boundary keeps the established `MgError::Other` messages and shared renderer path.

Owner này phân loại lỗi semaphore đóng và task join tại chỗ. Chuyển đổi ở boundary công khai hiện tại giữ nguyên thông điệp `MgError::Other` và đường renderer dùng chung.

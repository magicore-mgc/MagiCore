# engine

Game engine facade that preserves current configuration and filesystem detection behavior.

Facade game engine giữ nguyên hành vi nhận diện config và filesystem hiện tại.

The supported enum, marker detector and project identity check have separate owners. No framework support is inferred beyond the existing implementation.

Enum, detector marker và kiểm tra identity project có owner riêng. Không suy diễn hỗ trợ framework vượt quá implementation hiện có.

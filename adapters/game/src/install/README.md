# Game install capability / Khả năng install Game

This owner describes the current fail-closed install response and compatibility summary type. It does not invoke Cargo, Godot, Unity, Unreal, or another package manager.

Owner này định nghĩa phản hồi install fail-closed hiện tại và kiểu summary tương thích. Nó không chạy Cargo, Godot, Unity, Unreal hoặc package manager khác.

Tests are in [`test/`](test/README.md); errors use the shared `MgError`/`MgResult`.

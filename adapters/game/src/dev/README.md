# Game development commands / Lệnh phát triển Game

Owns the engine-specific development command description. The command is data returned to the shared CLI process launcher; this module does not launch child processes itself.

Phụ trách mô tả lệnh phát triển theo engine. Module trả dữ liệu lệnh cho bộ chạy process chung của CLI; không tự khởi chạy process con.

Tests are in [`test/`](test/README.md); errors reuse `MgError`/`MgResult`.

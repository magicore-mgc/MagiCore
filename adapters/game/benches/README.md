# Game performance benchmarks / Benchmark hiệu năng Game

`perf_bench.rs` currently times small synthetic loops and is not evidence of real cache performance. Keep benchmark claims limited to that code until a representative cache/install workload is implemented and run.

`perf_bench.rs` hiện chỉ đo vòng lặp tổng hợp ngắn, chưa chứng minh hiệu năng cache thực tế. Không diễn giải kết quả thành benchmark cache/install thật cho tới khi có workload đại diện và được chạy.

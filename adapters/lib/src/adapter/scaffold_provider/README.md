# scaffold_provider

## Responsibility

ScaffoldProvider capability evidence for the Lib core.

## Ghi chú tiếng Việt

Folder này chỉ sở hữu phần scaffoldprovider capability evidence for the lib core. trong adapter đa ngôn ngữ. Mọi lỗi tiếp tục dùng `MgError`/`MgResult` chung; không tạo lớp lỗi song song. Các test hiện có giữ nguyên trong `src/test/` và sẽ được sắp xếp ở phase test sau khi refactor source toàn repo hoàn tất.

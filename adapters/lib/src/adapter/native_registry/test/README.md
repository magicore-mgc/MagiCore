# Native registry tests

`metadata.rs` verifies ecosystem tags and registry identifiers for every native lane and both operations. It explicitly guards the existing Rust project-resolve versus single-package-add distinction. Protocol transport and artifact behavior remain under the resolver protocol and Lib native-engine suites.

## Phạm vi

`metadata.rs` kiểm tra ecosystem tag và registry identity của mọi native lane trong cả hai thao tác, đồng thời khóa khác biệt Rust giữa resolve dự án và add package đơn. Transport protocol và artifact behavior vẫn thuộc resolver protocol suite và Lib native-engine suite.

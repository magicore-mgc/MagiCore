# construction

## Responsibility

Fallible LibAdapter builders and the stable language identity getter.

## Ghi chú tiếng Việt

Folder này chỉ sở hữu phần fallible libadapter builders and the stable language identity getter. trong adapter đa ngôn ngữ. Mọi lỗi tiếp tục dùng `MgError`/`MgResult` chung; không tạo lớp lỗi song song. Các test hiện có giữ nguyên trong `src/test/` và sẽ được sắp xếp ở phase test sau khi refactor source toàn repo hoàn tất.

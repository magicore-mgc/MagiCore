# manifest_identity

## Responsibility

Map a detected Lib language and Java manifest kind to the stable public `ManifestIdentity` returned by `PackageAdapter`.

## Ghi chú tiếng Việt

Folder này ánh xạ ngôn ngữ Lib và loại manifest Java sang `ManifestIdentity` công khai ổn định. Không dùng identity để suy ra quyền sửa manifest hoặc mức hỗ trợ lifecycle.

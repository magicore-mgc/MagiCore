# web_preferences

## Responsibility

Forward package dedupe and existing-version preferences to the embedded Web adapter when one is present; native toolchain lanes remain unaffected.

## Ghi chú tiếng Việt

Folder này chuyển tiếp tùy chọn dedupe và phiên bản đang có sang Web adapter nhúng nếu tồn tại; các lane toolchain native không bị thay đổi.

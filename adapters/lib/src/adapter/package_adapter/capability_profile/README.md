# capability_profile

## Responsibility

Own the public capability arrays and choose the capability profile for a Lib language/ownership lane. This module is the source for `LibAdapter::CAPABILITIES*`; it must keep claims aligned with implemented behavior.

## Ghi chú tiếng Việt

Folder này sở hữu các mảng capability công khai và chọn profile tương ứng với ngôn ngữ/trạng thái sở hữu package. Mọi claim phải phản ánh hành vi đã triển khai; không nâng claim chỉ vì có parser hoặc detector.

# manifest_parse

## Responsibility

Dispatch read-only manifest parsing to the native Rust, Python, Go, Java/Maven, and .NET parsers, or to the embedded Web adapter for TypeScript.

## Ghi chú tiếng Việt

Folder này điều phối parse manifest chỉ đọc sang parser native của Rust, Python, Go, Java/Maven, .NET hoặc Web adapter nhúng cho TypeScript. Không biến khả năng parse thành quyền ghi manifest.

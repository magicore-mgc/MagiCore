# add_preparation

## Responsibility

Resolve and prepare dependency additions through the native resolve-first lane. Unsupported language lanes fail closed instead of fabricating a selected version.

## Ghi chú tiếng Việt

Folder này resolve và chuẩn bị thao tác thêm dependency qua lane native resolve-first. Ngôn ngữ chưa có lane được hỗ trợ phải fail-closed, không tạo phiên bản giả.

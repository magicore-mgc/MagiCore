# dotnet_target_framework

## Responsibility

Safe .NET target-framework selection from root csproj files.

## Ghi chú tiếng Việt

Folder này chỉ sở hữu phần safe .net target-framework selection from root csproj files. trong adapter đa ngôn ngữ. Mọi lỗi tiếp tục dùng `MgError`/`MgResult` chung; không tạo lớp lỗi song song. Các test hiện có giữ nguyên trong `src/test/` và sẽ được sắp xếp ở phase test sau khi refactor source toàn repo hoàn tất.

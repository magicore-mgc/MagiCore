# PyPI client errors

EN: Owns typed request, status, metadata, version-selection and body-read failures. Conversion to the existing `MgError::Other(String)` API happens once at the public trait boundary.

VI: Sở hữu lỗi có kiểu cho request, status, metadata, chọn version và đọc body. Chuyển sang API `MgError::Other(String)` hiện có đúng một lần tại ranh giới trait công khai.

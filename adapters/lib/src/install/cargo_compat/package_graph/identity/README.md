# Cargo package identity

## Purpose

Owns the `name@version` package id used across the Cargo-compat lane and validation of Cargo dependency edge markers (`optional:` with a valid package name, `target:` with a non-empty cfg).

## Vietnamese

Sở hữu id package `name@version` dùng trong lane tương thích Cargo và validate marker edge dependency Cargo (`optional:` với tên package hợp lệ, `target:` với cfg không rỗng).

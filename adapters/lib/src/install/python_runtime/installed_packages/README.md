# Python installed packages

Lists only Python lock entries owned by the active core after their runtime materializations pass verification.
`error.rs` owns lock-inspection and lock/materialization consistency failures before they cross back to the adapter facade.

## Package Python đã cài

Chỉ liệt kê entry Python thuộc core hiện tại sau khi materialization runtime được xác minh.
`error.rs` sở hữu lỗi đọc lock và sai khác giữa lock với materialization trước khi trả về facade adapter.

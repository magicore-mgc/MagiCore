# Python path entries

Reads the project lock, checks the owning core and manifest pins, then verifies the cached wheel and importable site directory before returning runtime paths.

## Đường dẫn Python

Đọc lock project, kiểm tra core sở hữu và pin manifest, sau đó xác minh wheel cache cùng thư mục site import được trước khi trả đường dẫn runtime.

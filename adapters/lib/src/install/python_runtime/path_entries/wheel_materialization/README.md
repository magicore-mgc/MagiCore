# Python wheel materialization

Checks locked SHA-256 data, selects the digest-addressed cache entry, validates the regular-file boundary, and verifies the wheel's importable site tree.
`error.rs` owns integrity, host-compatibility, and missing-materialization outcomes.

## Materialization wheel Python

Kiểm tra SHA-256 trong lock, chọn entry cache theo digest, rào file thường và xác minh site tree import được từ wheel.
`error.rs` sở hữu lỗi integrity, không tương thích host và thiếu materialization.

# Lib empty-graph install / Install Lib với graph rỗng

EN: Owns the native non-TypeScript empty-graph early return. Offline Rust validates a dependency-free Cargo manifest but writes neither lock; online installs publish the selected MagiCore lock, and Rust also writes the canonical Cargo lock. This owner does not initialize a registry, content store or network probe.

VI: Sở hữu nhánh return sớm của graph rỗng cho lane native không phải TypeScript. Rust offline xác minh Cargo manifest không có dependency nhưng không ghi lock; install online ghi MagiCore lock đã chọn và Rust còn ghi Cargo lock chuẩn. Owner không khởi tạo registry, content store hoặc dò mạng.

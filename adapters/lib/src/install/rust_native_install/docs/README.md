# Rust native install tracking / Theo dõi install Rust native

This folder keeps the owner-local progress report and checklist. It records source-only work separately from tests that have actually run.

Thư mục này giữ báo cáo tiến độ và checklist riêng của owner. Nó phân biệt phần source đã rà với test thực sự đã chạy.

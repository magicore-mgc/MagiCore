# Rust native install tests

This folder exposes shared Rust archive fixtures to the archive-cache and offline-install test owners. Behavior tests live with their implementation modules; these fixtures do not invoke Cargo or substitute for running tests.

## Test install native Rust

Folder này cung cấp fixture archive Rust dùng chung cho test owner cache và install offline. Test hành vi nằm cùng module implementation; fixture không gọi Cargo và không thay thế việc chạy test.

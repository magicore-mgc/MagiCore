# Online install tests / Test install online

This test runs the product install owner against a local mock registry and temporary Cargo/CAS directories. It verifies download, registry SHA-256 validation, CAS import, Cargo materialization and source-checksum creation without contacting an external registry.

Test chạy owner install sản phẩm với registry giả lập cục bộ và thư mục Cargo/CAS tạm. Test xác minh tải package, kiểm SHA-256 registry, import CAS, materialize Cargo và tạo source-checksum mà không gọi registry bên ngoài.

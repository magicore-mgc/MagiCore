Test-only process environment override with exact `OsString`/absence restoration on normal return and unwind. Every override borrows an explicit target-wide mutex guard, serializing the Lib Rust, Maven, NuGet and restoration tests in this integration executable.

Override environment chỉ dùng trong test, khôi phục đúng `OsString`/trạng thái vắng mặt khi return hoặc unwind. Mỗi override mượn mutex guard tường minh của test target để tuần tự hóa các test Rust, Maven, NuGet và test khôi phục trong executable này.

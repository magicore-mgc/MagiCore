# lib

Library adapter for Rust (Cargo), Python (PyPI) and TypeScript; pip is never invoked.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Adapter thư viện Rust (Cargo), Python (PyPI) và TypeScript; không bao giờ gọi pip. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

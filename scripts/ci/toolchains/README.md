# Shared CI toolchains / Toolchain CI dùng chung

This tree owns verified setup operations shared by multiple GitHub workflows. Keep an operation here only when the workflows use the same inputs, trust checks and failure policy; OS-specific setup with a different provenance contract stays with its workflow owner.

Cây này sở hữu thao tác setup đã xác minh được nhiều GitHub workflow dùng chung. Chỉ đặt thao tác ở đây khi các workflow dùng cùng input, kiểm tra tin cậy và chính sách lỗi; setup theo OS có contract nguồn gốc khác nhau giữ tại owner riêng.

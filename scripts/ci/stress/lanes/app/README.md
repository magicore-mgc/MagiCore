# App offline Dart lane / Lane Dart offline cho App

`verify_dart_offline_import.sh` finds the Dart executable installed with Flutter, exports it for the App native-install E2E and imports a package from the offline replay. The App-only Cargo feature and ignored-test selection remain explicit.

`verify_dart_offline_import.sh` tìm Dart executable đi kèm Flutter, export cho E2E App native-install rồi import package từ offline replay. Feature Cargo chỉ bật App và chọn ignored test vẫn được ghi rõ.

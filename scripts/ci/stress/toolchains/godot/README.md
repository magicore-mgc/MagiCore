# Godot headless runtime setup / Cài Godot headless runtime

`install_unix.sh` downloads the Linux/macOS release selected by `RUNNER_OS`, verifies SHA-512, locates the executable and adds a `godot` launcher to the workflow PATH. `install_windows.ps1` verifies and exposes the Windows executable.

`install_unix.sh` tải bản Linux/macOS theo `RUNNER_OS`, xác minh SHA-512, tìm executable và thêm launcher `godot` vào PATH workflow. `install_windows.ps1` xác minh và đưa executable Windows vào PATH.

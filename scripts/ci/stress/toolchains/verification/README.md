# Complete runtime verification / Xác minh đủ runtime

`verify_all.sh` fails when any required compiler/runtime is missing and checks the pinned versions after the OS-specific setup steps. It is an assertion step, not an installer.

`verify_all.sh` fail nếu thiếu compiler/runtime bắt buộc và kiểm tra version đã ghim sau các bước setup theo OS. Đây là bước assertion, không phải installer.

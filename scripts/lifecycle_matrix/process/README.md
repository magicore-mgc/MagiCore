# Process capture / Thu output process

`process.py` applies the existing stable UTF-8 capture defaults. Spawn errors and timeouts remain visible to the caller policy; no external package manager is invoked here.

`process.py` giữ mặc định giải mã UTF-8 ổn định. Lỗi spawn/timeout được xử lý tại policy của caller; module không gọi package manager ngoài.

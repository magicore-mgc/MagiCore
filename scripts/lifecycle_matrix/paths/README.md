# Paths / Đường dẫn

`paths.py` derives repository and scripts roots from its stable package location. The lifecycle ledger path keeps the same effective checkout-relative destination. Path/layout errors remain visible.

`paths.py` xác định root repo/scripts từ vị trí package; ledger giữ nguyên đích tương đối checkout. Lỗi layout/path được để lộ.

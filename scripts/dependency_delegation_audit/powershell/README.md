# PowerShell scanner / Scanner PowerShell

`powershell.py` masks comments and quoted examples before classifying covered native process APIs. Unsupported indirect aliases remain documented coverage limits.

`powershell.py` mask comment/ví dụ chuỗi trước khi phân loại process API đã hỗ trợ; alias gián tiếp chưa hỗ trợ vẫn là giới hạn coverage.

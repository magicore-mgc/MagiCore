# mgc-cache

The shared package-cache contract used across adapters, so caches are addressed the same way regardless of ecosystem.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Hợp đồng cache package dùng chung giữa các adapter để cache được định địa chỉ giống nhau bất kể ecosystem. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

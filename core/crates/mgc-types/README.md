# mgc-types

Core-independent domain types every crate compiles against: adapter traits, capabilities, ecosystem, typed errors, manifests, packages/versions, patches, publish and secret censoring.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Type miền độc lập core mà mọi crate biên dịch dựa vào: trait adapter, capabilities, ecosystem, lỗi typed, manifest, package/version, patch, publish và che bí mật. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

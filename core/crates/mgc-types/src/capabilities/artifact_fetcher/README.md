# Artifact fetch capability / Capability tải artifact

Owns artifact-fetch probing and the default fetch contract.

Sở hữu probe tải artifact và hợp đồng fetch mặc định.

**Contract / Hợp đồng:** The default reports Unsupported until an adapter provides native support.

Mặc định trả Unsupported cho tới khi adapter có hỗ trợ native.

# Project detector capability / Capability nhận diện dự án

Owns the required can_handle method used to identify a project root.

Sở hữu method can_handle bắt buộc để nhận diện project root.

**Contract / Hợp đồng:** This trait has no default probe; its nearest-owner test covers the required method.

Trait này không có probe mặc định; test gần owner kiểm tra method bắt buộc.

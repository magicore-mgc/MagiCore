# Capability wire contract / Hợp đồng wire Capability

Owns the 14-value serialized capability enum, declaration order, wire names and display mapping.

Sở hữu enum capability 14 giá trị được serialize, thứ tự khai báo, wire name và ánh xạ hiển thị.

**Contract / Hợp đồng:** No capability is added or renamed in this structural batch.

Batch tách cấu trúc này không thêm hoặc đổi tên capability.

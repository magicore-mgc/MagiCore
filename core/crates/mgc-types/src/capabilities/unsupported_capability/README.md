# Unsupported error constructor / Hàm tạo lỗi Unsupported

Owns the existing fail-closed MgError constructor and its message fields.

Sở hữu hàm tạo MgError fail-closed hiện tại cùng các trường thông báo.

**Contract / Hợp đồng:** The shared MgError type and error rendering remain owned by mgc-types::error.

Kiểu MgError dùng chung và việc render lỗi vẫn do mgc-types::error sở hữu.

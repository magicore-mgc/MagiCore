# Core identity contract / Hợp đồng định danh core

Owns the dyn-compatible identity trait inherited by every adapter capability.

Sở hữu trait định danh tương thích dyn mà mọi capability adapter kế thừa.

**Contract / Hợp đồng:** Identity method signatures and Ecosystem mapping remain unchanged.

Chữ ký method định danh và ánh xạ Ecosystem được giữ nguyên.

# Capability test support / Hỗ trợ test capability

Provides a cfg(test)-only adapter fixture and exact Unsupported-error assertions shared by nearest-owner tests.

Cung cấp fixture adapter chỉ bật khi test và assertion lỗi Unsupported dùng chung cho test gần owner.

**Contract / Hợp đồng:** This module is not compiled into production builds and does not model real adapter claims.

Module này không được biên dịch vào build production và không mô phỏng claim adapter thật.

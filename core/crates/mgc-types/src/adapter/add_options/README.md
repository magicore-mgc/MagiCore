# Add Options adapter owner

Options for the add operation, shared by every adapter core.

Tùy chọn thao tác add dùng chung cho mọi adapter core.

Public types keep their existing field names, serde attributes and API paths. Errors reuse the shared `mgc-types` result contract where needed.

Type public giữ nguyên tên field, serde attribute và API path. Nơi cần lỗi tiếp tục dùng result contract chung của `mgc-types`.

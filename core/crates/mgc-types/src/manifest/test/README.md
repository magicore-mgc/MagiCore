# Manifest tests

This folder holds the nearest-owner tests for the shared Manifest model. The cases were moved from the crate integration suite with their names and assertions preserved; the integration suite now checks only the public exports.

Thư mục này chứa test sát nhất cho model Manifest dùng chung. Các case được chuyển từ integration suite, giữ nguyên tên và assertion; integration suite hiện chỉ kiểm tra public export.

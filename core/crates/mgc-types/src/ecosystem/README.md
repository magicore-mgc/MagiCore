# Ecosystem owner

Owns the nine-variant ecosystem identifier, the existing lowercase string mapping and the `clo` alias for Cloud. Unknown values continue to return `None`; formatting continues to use the existing lowercase names.

Sở hữu định danh ecosystem chín biến thể, ánh xạ chuỗi chữ thường và alias `clo` cho Cloud. Giá trị lạ vẫn trả `None`; formatter vẫn dùng tên chữ thường hiện tại.

The owner only defines and converts the shared identifier. It does not detect project files, select an adapter or enforce a capability.

Owner chỉ định nghĩa và chuyển đổi identifier dùng chung. Nó không phát hiện file dự án, chọn adapter hoặc thực thi capability.

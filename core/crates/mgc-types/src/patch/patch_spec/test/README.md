# Patch-spec tests

This folder tests configuration-time `PatchSpec` serialization and its default `PatchKind` behavior. It does not apply patches or run an external patch utility.

Thư mục này kiểm tra serialization `PatchSpec` cấu hình và hành vi `PatchKind` mặc định. Nó không áp dụng patch hoặc chạy công cụ patch bên ngoài.

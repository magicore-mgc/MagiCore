# JSONC trailing-comma cleanup

Removes a comma only when the next JSON-whitespace-skipping character is a closing array or object token. Legal member separators and commas inside strings remain unchanged.

Chỉ bỏ dấu phẩy khi ký tự kế tiếp sau JSON whitespace là dấu đóng array hoặc object. Dấu phân cách member hợp lệ và dấu phẩy bên trong string được giữ nguyên.

# Shared error enum tests

These tests pin the current shared error display strings, transparent source chain and generated `From` conversions. They do not claim that all call sites classify errors correctly.

Các test này ghim chuỗi hiển thị, source chain transparent và chuyển đổi `From` hiện tại của enum lỗi dùng chung. Chúng không khẳng định mọi call site đã phân loại lỗi đúng.

# MgResult owner

Owns the public alias `MgResult<T> = Result<T, MgError>`. Keeping the alias separate preserves the existing shared signature without adding error policy.

Sở hữu alias public `MgResult<T> = Result<T, MgError>`. Tách alias giúp giữ chữ ký dùng chung hiện tại mà không thêm policy xử lý lỗi.

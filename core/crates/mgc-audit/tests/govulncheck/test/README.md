# Go scanner integration tests

## Purpose

Contains the original root-level test functions grouped by output, validation, severity, payload size, audit fallback, and go.mod parsing. The root target uses include! so test names and the Cargo target stay stable.

## Phạm vi

Chứa các test gốc được nhóm theo output, validation, severity, payload, audit fallback và parser go.mod. Root target dùng include! để giữ tên test và Cargo target.

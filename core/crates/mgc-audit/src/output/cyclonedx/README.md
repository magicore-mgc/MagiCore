# CycloneDX output owners

This folder keeps the public `output::cyclonedx` API while separating report rendering, serializable types, purl rules, severity projection, and deterministic serial generation. The serial digest identifies repeatable output; it is not used for integrity or trust.

Folder này giữ API public `output::cyclonedx` và tách render report, type serialize, quy tắc purl, severity và serial xác định. Digest serial chỉ định danh output tái lập, không dùng làm integrity hay trust.

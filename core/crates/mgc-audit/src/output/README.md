# Audit report output formats

This folder exposes machine-readable audit output through stable module paths. Each format owns its schema and renderer; adapters and CLI routes consume the shared report contract. Format-specific behavior tests remain in the audit and product integration suites.

Folder này export các định dạng audit cho máy qua module path ổn định. Mỗi format sở hữu schema và renderer; adapter và CLI dùng chung report contract. Test hành vi từng format nằm trong audit suite và product integration suite.

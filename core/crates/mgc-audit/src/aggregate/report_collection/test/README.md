# Report collection tests

This folder tests the private report-fold owner directly: package totals, partial scan counts/reasons, and the availability flag used by verdict resolution. These are lib unit tests registered by a path declaration in report_collection.rs; test bodies stay out of production source.

## Bản tiếng Việt

Folder này kiểm tra trực tiếp owner gom report nội bộ: tổng package, số lượt scan/lý do của kết quả Partial và cờ Available dùng khi phân xử verdict. Đây là lib unit test được đăng ký qua path trong report_collection.rs; body không nằm trong source production.

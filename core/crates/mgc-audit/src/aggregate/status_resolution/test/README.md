# Status resolution tests

This folder covers the verdict decision table directly: failure over missing tools, empty input, and available-plus-unsupported partial coverage. The unit test module is registered by a path declaration in status_resolution.rs and is not inline.

## Bản tiếng Việt

Folder này kiểm tra trực tiếp bảng phân xử verdict: Failed ưu tiên hơn tool thiếu, đầu vào rỗng và trường hợp Available cộng ecosystem chưa hỗ trợ. Module unit test được đăng ký qua path trong status_resolution.rs, không viết body inline.

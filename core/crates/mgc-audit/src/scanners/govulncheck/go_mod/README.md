# Go module requirement parser

## Purpose

Reads pinned direct and indirect require entries from go.mod and records unsupported directives or unpinned lines as skipped.

## Phạm vi

Đọc entry require có pin trực tiếp/gián tiếp từ go.mod và ghi directive không hỗ trợ hoặc dòng thiếu pin vào danh sách skipped.

# Go vulnerability scanner

## Purpose

Stable public module for the Go scanner and govulncheck stream compatibility parser. The active audit path uses the shared OSV client for direct go.mod require pins; it does not spawn govulncheck and reports limited coverage as Partial.

## Phạm vi

Module công khai ổn định cho scanner Go và parser tương thích stream govulncheck. Audit hiện tại dùng OSV client chung cho pin require trực tiếp trong go.mod; không spawn govulncheck và ghi rõ coverage giới hạn là Partial.

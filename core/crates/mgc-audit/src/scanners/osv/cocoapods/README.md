# CocoaPods report policy

Owns the current honest unsupported-advisory result while retaining parsed inventory counts and skipped-entry context. The package parser and bounded file read remain in their dedicated owners.

## Phạm vi

Folder này sở hữu report trung thực về advisory chưa hỗ trợ, đồng thời giữ số package đã kiểm kê và ngữ cảnh entry bị skip. Parser và đọc file giới hạn dung lượng ở các owner riêng.

# Swift lockfile types

Owns the private Serde structures for Package.resolved v1 and v2. These are data-transfer types only; parsing decisions live in `read_swift_resolved/`.

## Phạm vi

Folder này sở hữu các cấu trúc Serde nội bộ cho Package.resolved v1 và v2. Đây chỉ là type truyền dữ liệu; quyết định parse nằm trong `read_swift_resolved/`.

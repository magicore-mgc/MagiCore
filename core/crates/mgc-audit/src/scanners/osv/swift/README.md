# Swift report aggregation

Owns the distinction between clean empty input, skipped-only partial results, and queried pins with skipped entries. This is the Swift lane's report policy; filesystem lookup and Package.resolved parsing stay in their dedicated owners.

## Phạm vi

Folder này sở hữu chính sách report cho input rỗng, chỉ có pin bị bỏ qua, và pin đã query kèm mục bị skip. Tìm file và parse Package.resolved vẫn ở owner riêng.

# Multi-lock pin collection

Collects every sorted solution project lockfile plus the root lockfile, deduplicates package identities across files, and records missing/unresolvable project inputs as skipped work.

Gom lockfile của mọi solution project đã sắp xếp cùng lock root, khử trùng identity package giữa các file, và ghi nhận project thiếu/không resolve được là phần việc bị skip.

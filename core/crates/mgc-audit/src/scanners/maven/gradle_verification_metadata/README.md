# Gradle verification-metadata parser

EN: Owns the line-shaped group/name/version projection and its current bounded skip diagnostics. This is not a general XML parser and does not resolve Gradle dependency graphs.

VI: Sở hữu việc chiếu group/name/version theo cấu trúc dòng hiện tại và diagnostic skip có giới hạn. Đây không phải XML parser tổng quát và không resolve dependency graph của Gradle.

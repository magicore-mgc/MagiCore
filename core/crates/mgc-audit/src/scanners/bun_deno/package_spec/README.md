# Package spec splitter

English: Splits `name@version` at the final `@` so scoped npm package names remain intact. Missing name/version returns `None`; this pure helper has no error boundary or I/O.

Tiếng Việt: Tách `name@version` tại `@` cuối để giữ nguyên tên npm có scope. Thiếu tên/version trả `None`; helper thuần này không có I/O hay boundary lỗi.

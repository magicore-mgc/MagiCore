# Terraform provider-state owner

EN: Owns provider header recognition, state reset/count, block closure and end-of-file finalization. Malformed-header text is supplied by the local Terraform parser error.

VI: Quản lý nhận diện header provider, reset/count state, đóng block và hoàn tất cuối file. Nội dung lỗi header malformed do error parser Terraform cục bộ cung cấp.

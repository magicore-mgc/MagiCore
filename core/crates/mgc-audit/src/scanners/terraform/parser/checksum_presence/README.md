# Terraform checksum-key owner

EN: Owns the existing narrow rule: a trimmed line beginning with hashes or checksums and containing an opening bracket marks the current provider as having checksum data. It does not validate checksum values.

VI: Quản lý rule hẹp hiện tại: dòng đã trim bắt đầu bằng hashes hoặc checksums và có dấu ngoặc mở sẽ đánh dấu provider hiện tại có checksum data. Owner này không xác thực giá trị checksum.

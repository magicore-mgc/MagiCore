# Terraform provider-lock scanner

EN: Keeps the public Terraform scanner routes and delegates bounded file access, line parsing, provider-state transitions, checksum-key detection, report projection, parser state and local parse errors to focused owners. It intentionally preserves the existing conservative parser; it is not a general HCL parser.

VI: Giữ các route scanner Terraform public và chuyển việc đọc file có giới hạn, parse theo dòng, chuyển trạng thái provider, nhận diện checksum key, tạo report, parser state và lỗi parse cục bộ cho các owner riêng. Cố ý giữ parser bảo thủ hiện tại; đây không phải parser HCL tổng quát.

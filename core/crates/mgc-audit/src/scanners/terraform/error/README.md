# Terraform parser error owner

EN: Owns the malformed provider-header category and its exact legacy diagnostic text. The public facade maps it to the existing shared MgError::Other variant.

VI: Quản lý nhóm lỗi provider header malformed và nội dung diagnostic cũ chính xác. Facade public ánh xạ về biến thể MgError::Other dùng chung.

# GitHub Actions report projection

EN: Maps workflow findings into the shared AuditReport/Vulnerability contract. It owns titles, policy classification, severity, evidence labels and the audited-file count; it does not discover files or interpret YAML.

VI: Chuyển workflow finding sang hợp đồng AuditReport/Vulnerability dùng chung. Owner này quản lý title, policy classification, severity, nhãn evidence và số file audit; không tìm file và không diễn giải YAML.

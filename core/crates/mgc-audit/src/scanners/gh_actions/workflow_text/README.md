# Workflow text scanner owner

EN: Owns the conservative line-oriented YAML-subset scan and delegates each policy rule to its nearest owner. It preserves finding order and scanner behavior; it is not a general YAML parser.

VI: Quản lý việc quét tập con YAML bảo thủ theo dòng và chuyển từng policy rule cho owner gần nhất. Folder giữ nguyên thứ tự finding và hành vi scanner; đây không phải parser YAML tổng quát.

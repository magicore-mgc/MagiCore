# Cargo.lock package record owner

EN: Validates the required package name/version fields and reads a string source. Missing or non-string source remains equivalent to a local/workspace package, matching the previous parser contract.

VI: Xác thực field name/version bắt buộc và đọc source dạng chuỗi. Source thiếu hoặc không phải chuỗi vẫn được xem như package local/workspace, đúng contract parser trước đây.

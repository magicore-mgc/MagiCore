# Cargo.lock parser

EN: Coordinates TOML document validation, required package fields, crates.io source policy and stable pin projection. Parser-specific errors are owned here; filesystem and OSV failures stay in their shared owners.

VI: Điều phối xác thực TOML, field package bắt buộc, chính sách source crates.io và projection pin ổn định. Lỗi đặc thù parser thuộc owner này; lỗi filesystem/OSV vẫn ở owner dùng chung.

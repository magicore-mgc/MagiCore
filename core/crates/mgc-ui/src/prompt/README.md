# Prompt owner

Owns the stable public interactive prompt API and delegates each interaction to a same-name child owner.
Sở hữu API prompt tương tác công khai ổn định và giao từng thao tác cho child owner cùng tên.

The shared style owner formats the prompt label; each operation keeps its current dialoguer settings and anyhow result.
Owner style dùng chung định dạng label; mỗi thao tác giữ cấu hình dialoguer và anyhow result hiện tại.

# Reflink public-dispatch tests

Tests the public wrapper independently from each platform implementation. They check the API's platform-specific error classification. The registered test body lives in `reflink.rs`.

# Test dispatch public của reflink

Kiểm tra wrapper public tách biệt với từng implementation OS và xác nhận phân loại lỗi theo nền tảng. Nội dung test được đăng ký tại `reflink.rs`.

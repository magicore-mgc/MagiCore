# Reflink error owner

Owns `ReflinkError`, its stable English Display messages, and `Error::source()` for both wrapped `io::Error` variants. It does not choose retries or filesystem fallback policy.

# Owner lỗi reflink

Sở hữu `ReflinkError`, thông báo Display tiếng Anh ổn định và `Error::source()` cho cả hai variant bọc `io::Error`. Owner này không quyết định retry hay policy fallback filesystem.

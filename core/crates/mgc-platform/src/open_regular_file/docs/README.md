# Open Regular File Tracking

**Purpose:** Keep the local plan, progress and deferred verification state for the shared file-opening owner.

**Mục đích:** Lưu kế hoạch, tiến độ và trạng thái xác minh đang chờ của owner mở file dùng chung.

These local workflow records complement the repository S297 ledger and do not replace it.

Các ghi chép workflow local bổ sung cho ledger S297 toàn dự án, không thay thế ledger đó.

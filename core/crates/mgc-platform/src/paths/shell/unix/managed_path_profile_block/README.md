# Managed Unix PATH marker block

Renders shell-specific quoted PATH entries and replaces exactly one well-formed MagiCore marker pair. Duplicate or malformed markers remain fail-closed. Unit tests are registered under this owner; API-level tests remain in the crate integration suite.

## Vietnamese

Owner này render PATH theo cú pháp shell và chỉ thay đúng một cặp marker MagiCore hợp lệ. Marker thiếu hoặc trùng tiếp tục bị từ chối. Unit test nằm cạnh owner; test API vẫn ở integration suite của crate.

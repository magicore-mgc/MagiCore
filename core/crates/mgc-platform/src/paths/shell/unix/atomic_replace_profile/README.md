# Atomic Unix profile replacement

Owns the synced temporary-file write, same-directory rename, mode preservation and temporary-name generation for profile updates. Existing cleanup and error behavior are retained.

## Vietnamese

Owner này ghi file tạm có sync, rename cùng thư mục, giữ mode cũ và tạo tên file tạm cho profile. Giữ nguyên dọn file tạm và hành vi lỗi hiện tại.

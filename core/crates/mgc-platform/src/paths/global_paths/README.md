# User-global paths

## Purpose

Owns `GlobalPaths`: the machine-wide MagiCore data layout under `MGC_DATA_DIR`, including the identity attestation root. `MAGICORE_STORE_ROOT` still overrides only `store`, matching the CAS override used by `mgc-store`.

## Phạm vi

Owner này sở hữu `GlobalPaths`: layout dữ liệu MagiCore toàn máy dưới `MGC_DATA_DIR`, gồm root chứng thực identity. `MAGICORE_STORE_ROOT` vẫn chỉ override `store`, khớp override CAS của `mgc-store`.

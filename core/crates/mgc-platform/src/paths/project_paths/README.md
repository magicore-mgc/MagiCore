# Project-local paths

## Purpose

Owns the `ProjectPaths` layout rooted at `<project>/.magicore/` (store, cache, logs, locks, dlx, advisories, patches, quarantine, registry, lock signatures) and its `ensure_dirs`/`patches_dir` helpers. Path construction is unchanged from the previous flat module.

## Phạm vi

Owner này sở hữu layout `ProjectPaths` gốc `<project>/.magicore/` (store, cache, logs, locks, dlx, advisories, patches, quarantine, registry, lock signatures) cùng `ensure_dirs`/`patches_dir`. Cách dựng path không đổi so với module phẳng trước đó.

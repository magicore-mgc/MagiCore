# Search registry clients

## Purpose

Owns per-registry search clients (npm, crates, PyPI, Go) behind one shared surface for every core; each client performs its own request shaping and response mapping.

## Vietnamese

Owner client tìm kiếm theo registry (npm, crates, PyPI, Go) sau một bề mặt dùng chung cho mọi core; mỗi client tự dựng request và map response.

# mgc-search

Multi-registry search (npm, crates.io, pkg.go.dev, PyPI) with ranking, caching and preference learning.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Tìm kiếm đa registry (npm, crates.io, pkg.go.dev, PyPI) với xếp hạng, cache và học sở thích user. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

# request

Owns npm Bulk Advisory endpoint construction and deterministic request-body grouping. Every unique locked version is retained under its package name, sorted and deduplicated.

Sở hữu việc dựng endpoint npm Bulk Advisory và nhóm request ổn định. Mọi version lock duy nhất được giữ theo tên package, sắp xếp rồi loại trùng.

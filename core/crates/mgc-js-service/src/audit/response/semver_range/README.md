# semver_range

Applies strict audit-only validation to every range alternative. A range that cannot be interpreted is rejected instead of silently matching no versions.

Áp dụng kiểm tra nghiêm ngặt riêng cho audit trên từng alternative của range. Range không diễn giải được sẽ bị từ chối thay vì âm thầm khớp rỗng.

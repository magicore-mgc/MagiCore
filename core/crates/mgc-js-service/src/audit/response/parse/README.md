# parse

Validates the top-level package map and advisory arrays, then delegates each record to finding projection. Malformed data stays an error and cannot be reported as an empty clean result.

Kiểm tra map package và mảng advisory cấp cao, rồi giao từng record cho phần dựng finding. Dữ liệu lỗi luôn thành lỗi, không bị báo nhầm thành kết quả sạch rỗng.

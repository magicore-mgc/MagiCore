# audit owner records

This directory tracks source changes to the shared JS/NPM advisory audit owner. Its checklist is the owner record; the progress report separates static evidence from runtime verification.

Thư mục này theo dõi thay đổi source của owner audit advisory JS/NPM dùng chung. Checklist là hồ sơ công việc; progress report tách bằng chứng source-static khỏi kiểm chứng runtime.

# trust

Owns the registry-relative tarball host trust predicate. Existing loopback, same-host, npmjs subdomain, Yarn registry, and explicit host allowlist behavior remains unchanged.

Sở hữu predicate trust host tarball theo registry. Quy tắc loopback, cùng host, subdomain npmjs, Yarn registry và allowlist host tường minh được giữ nguyên.

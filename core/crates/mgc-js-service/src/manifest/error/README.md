# Manifest errors / Lỗi manifest

Owns typed failures for package.json policy and atomic-write operations. It retains underlying IO/JSON/atomic causes and maps workspace-source replacement to the existing structured `MgError::Unsupported` contract.

Sở hữu lỗi typed cho policy package.json và thao tác atomic-write. Owner giữ nguyên nguyên nhân IO/JSON/atomic và ánh xạ việc thay nguồn workspace về contract `MgError::Unsupported` có cấu trúc hiện tại.

Display text is kept stable for callers. Error classification is local; retry decisions remain with the operation owner and no string matching is introduced.

Text hiển thị được giữ ổn định cho caller. Phân loại lỗi nằm cục bộ; quyết định retry thuộc owner thao tác và không thêm điều khiển bằng so khớp chuỗi.

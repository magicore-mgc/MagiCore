# Project-path owner

Owns project-relative component validation. Unix traversal remains anchored by an opened root and no-follow directory handles; non-Unix retains canonical-root and component checks.

Sở hữu kiểm tra path tương đối project. Unix neo traversal bằng root handle và directory handle không theo symlink; non-Unix giữ canonical root cùng kiểm tra từng thành phần.

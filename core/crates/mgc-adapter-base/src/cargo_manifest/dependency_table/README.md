# Cargo root dependency-table mutation

Owns selective updates to Cargo's root `dependencies` and `dev-dependencies` tables while preserving unrelated Cargo options and refusing unrepresentable dependency sources.

Sở hữu cập nhật có chọn lọc `dependencies` và `dev-dependencies` root; giữ option Cargo khác và từ chối source dependency không thể biểu diễn.

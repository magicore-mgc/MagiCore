# mgc-adapter-base

What every native adapter shares: cargo manifest parse/write, safe project-manifest read/replace primitives and the adapter helper contract.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Nền tảng dùng chung cho mọi adapter native: parse/ghi manifest cargo, primitive đọc/thay manifest project an toàn và hợp đồng helper adapter. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

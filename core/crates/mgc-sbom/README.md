# mgc-sbom

CycloneDX and SPDX SBOM generation plus the generator contract used by adapters.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Sinh SBOM theo CycloneDX và SPDX cùng hợp đồng generator dùng cho adapter. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

# mgc-crypto

Supply-chain cryptography: BLAKE3 hashing, Ed25519 signing/verification and keyring management for lockfile signatures and trust anchors.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Mật mã chuỗi cung ứng: hash BLAKE3, ký/xác minh Ed25519 và quản lý keyring dùng cho chữ ký lockfile và trust anchor. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

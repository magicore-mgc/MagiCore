# Ed25519 signature verification / Xác minh chữ ký Ed25519

Owns byte-message and UTF-8 string verification through `ring`; all verification failures map to the stable public `CryptoError::VerificationFailed` variant.

Sở hữu verify message byte và chuỗi UTF-8 qua `ring`; mọi lỗi verify ánh xạ về variant public ổn định `CryptoError::VerificationFailed`.

# SIMD capability value / Giá trị capability SIMD

Owns `SimdCapability`, its stable names, existing display multipliers and serde derives. Multipliers are retained compatibility values and have not been benchmark-validated.

Sở hữu `SimdCapability`, tên ổn định, multiplier hiển thị hiện tại và derive serde. Multiplier được giữ để tương thích và chưa được xác thực bằng benchmark.

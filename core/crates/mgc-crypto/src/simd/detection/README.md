# SIMD feature detection / Phát hiện feature SIMD

Owns runtime CPU feature detection behind the existing architecture cfg gates and priority order. It reports capability; it does not execute target-specific SIMD kernels.

Sở hữu phát hiện feature CPU runtime sau các cfg kiến trúc và thứ tự ưu tiên hiện tại. Module báo capability, không chạy kernel SIMD target-specific.

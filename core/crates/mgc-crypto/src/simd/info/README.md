# SIMD info rendering / Dựng thông tin SIMD

Owns the existing user-readable summary format and composes it from detection plus the capability value. The rendered multiplier remains an unmeasured legacy estimate.

Sở hữu format tổng hợp dễ đọc hiện tại và ghép từ kết quả detection cùng value capability. Multiplier hiển thị vẫn là ước lượng legacy chưa đo.

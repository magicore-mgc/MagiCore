# Keyring storage

Coordinates secure reads, path and existing-file guards, atomic replacement and temporary-file cleanup. Unix, Windows and fallback branches remain explicit in the read/replace owners; error display maps to the established public CryptoError.

Điều phối đọc bảo mật, kiểm tra path/file hiện có, atomic replace và cleanup temporary. Nhánh Unix, Windows và fallback được giữ tường minh trong owner read/replace; error display map về CryptoError public hiện tại.

# Keyring path guard

Owns canonical destination containment under the configured home directory. It rejects an outside-home destination and compares canonical home spelling so a symlink-resolved home remains the same allowed location.

Sở hữu containment đích canonical bên trong home cấu hình. Từ chối đích ngoài home và so canonical home để home đi qua symlink vẫn là cùng vị trí được phép.

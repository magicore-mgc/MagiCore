# KeyPair owner

Owns the public serialized `KeyPair` shape, cryptographic generation, public-key fingerprint and conversion to `Ed25519Signer`. Private bytes remain redacted in `Debug` output.

Sở hữu shape `KeyPair` serialize public, tạo key mật mã, fingerprint public key và chuyển thành `Ed25519Signer`. Byte private tiếp tục bị che trong `Debug`.

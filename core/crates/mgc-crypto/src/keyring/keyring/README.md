# Keyring API owner

Owns the public `Keyring` state, key insertion/selection, default path and save/load orchestration. File validation and publication are delegated to `storage/`; public method signatures and JSON shape remain stable.

Sở hữu state `Keyring` public, thêm/chọn key, default path và điều phối save/load. Kiểm tra/publish file giao cho `storage/`; giữ signature method public và JSON shape.

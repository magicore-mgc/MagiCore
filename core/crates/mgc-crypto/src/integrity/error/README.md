# Integrity local errors / Lỗi integrity local

Typed errors classify malformed SRI, unsupported/unknown algorithms, digest mismatch, wrapped crypto failures and file I/O. Conversion preserves established public `CryptoError` messages and source chains; this owner does not retry.

Lỗi typed phân loại SRI sai, thuật toán không hỗ trợ/không biết, digest mismatch, lỗi crypto được bọc và I/O file. Chuyển đổi giữ message `CryptoError` public và source chain; owner này không retry.

# mgc-registry-server

The private registry server: npm and OCI (`/v2`) endpoints, private-only policy, auth, rate limiting, upstream proxying and S3 storage.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Server registry riêng: endpoint npm và OCI (`/v2`), chính sách chỉ private, auth, rate limit, proxy upstream và storage S3. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

# Blob Upload tests

## Purpose

This folder holds the pre-existing OCI regression case moved next to the `blob_upload` implementation. The test source and assertions are preserved.

## Mục đích

Thư mục chứa hồi quy OCI có sẵn được chuyển sát implementation `blob_upload`. Giữ nguyên source test và assertion.

`mod.rs` registers the test file. No test is run during the structural-first phase.

`mod.rs` đăng ký file test. Pha này chỉ tái cấu trúc, chưa chạy test.

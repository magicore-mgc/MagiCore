# PyPI legacy upload owner

Owns Twine-compatible multipart extraction, pre-read auth, digest verification, blob storage and trusted-publisher attestation persistence. Local typed errors preserve multipart/store/signing sources and map to the same response statuses.

Sở hữu đọc multipart tương thích Twine, auth trước khi đọc, kiểm digest, lưu blob và lưu attestation trusted-publisher. Error type giữ source multipart/store/signing và ánh xạ cùng response status.

# PyPI registry routes

This module is the compatibility facade for the public `pypi::routes()` API. It separates route registration from simple-index rendering, file download and trusted legacy upload while retaining all existing `/pypi` paths.

Module này là facade tương thích của API công khai `pypi::routes()`. Nó tách đăng ký route khỏi render simple-index, tải file và upload legacy có trusted-publisher, đồng thời giữ nguyên các path `/pypi`.

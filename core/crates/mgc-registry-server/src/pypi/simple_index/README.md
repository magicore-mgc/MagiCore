# PyPI simple-index owner

Owns package authorization/list retrieval and PEP 503 HTML response rendering, including HTML escaping and URL-segment encoding. Local errors preserve store sources and map to the same HTTP status responses.

Sở hữu xác thực/list package và render HTML PEP 503, gồm escape HTML và mã hóa URL segment. Lỗi cục bộ giữ source của store và ánh xạ cùng HTTP status như hiện tại.

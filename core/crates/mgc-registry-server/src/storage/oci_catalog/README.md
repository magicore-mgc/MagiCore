# Oci Catalog

Lists OCI manifest tags and repositories from the existing registry metadata.

**Ownership:** `list_oci_tags, list_oci_repos`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

---

# Oci Catalog — Tiếng Việt

Liệt kê tag manifest OCI và repository từ metadata registry hiện có.

**Phạm vi sở hữu:** `list_oci_tags, list_oci_repos`. Module giữ nguyên contract storage hiện có và không chuyển thao tác registry sang package manager bên ngoài.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

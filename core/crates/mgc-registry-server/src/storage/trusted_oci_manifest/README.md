# Trusted Oci Manifest

Stores a trusted OCI manifest with its existing attestation linkage.

**Ownership:** `put_trusted_oci_manifest`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

# Trusted Oci Manifest — Tiếng Việt

Lưu trusted OCI manifest cùng liên kết attestation hiện có.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

# Runtime Configuration

Applies upstream and blob-backend configuration to an existing registry store.

**Ownership:** `set_upstream, set_backend`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

---

# Runtime Configuration — Tiếng Việt

Áp dụng cấu hình upstream và blob backend cho registry store hiện có.

**Phạm vi sở hữu:** `set_upstream, set_backend`. Module giữ nguyên contract storage hiện có và không chuyển thao tác registry sang package manager bên ngoài.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

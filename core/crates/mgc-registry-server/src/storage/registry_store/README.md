# Registry store

Owns `RegistryStore` state and construction. The database pool, blob root, upstream configuration, blob backend, and upload locks have one owner. The constructor preserves the current initialization and migration sequence.

# Registry store — Tiếng Việt

Sở hữu trạng thái và khởi tạo `RegistryStore`. Database pool, thư mục blob, cấu hình upstream, blob backend và upload lock có một owner. Constructor giữ nguyên thứ tự khởi tạo và migration hiện tại.

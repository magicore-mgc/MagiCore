# Trusted Attestation Write

Owns trusted attestation insertion and the transaction helper used by trusted package writes.

**Owned API:** `append_trusted_attestation, append_trusted_attestation_tx`. Existing call paths and database behavior stay unchanged. Registered crate integration tests remain in `tests/` and are described as such.

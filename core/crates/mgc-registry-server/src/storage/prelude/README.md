# Storage prelude

This is the narrow internal dependency prelude shared by storage owner modules. It exposes only common Rust traits and storage types within `crate::storage`; it contains no storage behavior or public registry API.

# Storage prelude — Tiếng Việt

Đây là prelude dependency nội bộ gọn dùng chung giữa các owner storage. Nó chỉ đưa trait và type storage chung vào phạm vi `crate::storage`; không chứa behavior lưu trữ hay API registry công khai.

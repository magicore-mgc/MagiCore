# Trusted Package

Stores packages with trusted provenance while preserving the existing transaction and publisher checks.

**Ownership:** `put_trusted_package`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

# Trusted Package — Tiếng Việt

Lưu package kèm provenance tin cậy, giữ nguyên transaction và kiểm tra publisher.

**Phạm vi sở hữu:** `put_trusted_package`. Module giữ nguyên contract storage hiện có và không chuyển thao tác registry sang package manager bên ngoài.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

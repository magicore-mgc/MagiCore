# Digest Path

Validates and converts digest encodings into safe storage path fragments.

**Ownership:** `digest_hex_path`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

# Digest Path — Tiếng Việt

Kiểm tra và chuyển digest thành các đoạn path lưu trữ an toàn.

**Phạm vi sở hữu:** `digest_hex_path`. Module giữ nguyên contract storage hiện có và không chuyển thao tác registry sang package manager bên ngoài.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

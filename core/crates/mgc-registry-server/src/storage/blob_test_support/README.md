# Blob Test Support

Preserves the existing database path lookup methods used by registry storage integration tests.

**Owned API:** `blob_path_for_test, oci_blob_path_for_test`. Existing call paths and database behavior stay unchanged. Registered crate integration tests remain in `tests/` and are described as such.

# Blob Test Support — Tiếng Việt

Giữ các method tra path từ database đang được integration test registry sử dụng.

**API sở hữu:** `blob_path_for_test, oci_blob_path_for_test`. Đường gọi và hành vi database hiện tại được giữ nguyên. Test integration của crate tiếp tục ở `tests/`.

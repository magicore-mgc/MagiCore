# Package Mutation

Owns package writes and deletion operations.

**Owned API:** `put_package, delete_package, delete_package_version`. Existing call paths and database behavior stay unchanged. Registered crate integration tests remain in `tests/` and are described as such.

# Package Mutation — Tiếng Việt

Sở hữu thao tác ghi và xóa package.

**API sở hữu:** `put_package, delete_package, delete_package_version`. Đường gọi và hành vi database hiện tại được giữ nguyên. Test integration của crate tiếp tục ở `tests/`.

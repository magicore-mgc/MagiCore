# Oci Upload Error

Defines typed outcomes for resumable OCI upload append operations.

**Ownership:** `OciUploadAppendError`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

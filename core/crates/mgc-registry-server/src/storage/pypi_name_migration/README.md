# Pypi Name Migration

Canonicalizes legacy PyPI project identities transactionally and keeps the one-time migration marker.

**Ownership:** `migrate_pypi_project_names`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

---

# Pypi Name Migration — Tiếng Việt

Chuẩn hóa định danh project PyPI cũ trong một transaction và giữ marker migration một lần.

**Phạm vi sở hữu:** `migrate_pypi_project_names`. Module giữ nguyên contract storage hiện có và không chuyển thao tác registry sang package manager bên ngoài.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

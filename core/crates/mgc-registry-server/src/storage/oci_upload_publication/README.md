# Oci Upload Publication

OCI upload completion and verified blob publication. The owner preserves the existing database transaction, offset checks, filesystem writes, and public RegistryStore methods.

**Methods:** `finish_oci_upload, finalize_oci_upload, publish_oci_blob_from_file`.

# Oci Upload Publication — Tiếng Việt

Hoàn tất OCI upload và publish blob có xác minh. Owner giữ nguyên transaction database, kiểm tra offset, thao tác filesystem và các method công khai của RegistryStore.

**Method:** `finish_oci_upload, finalize_oci_upload, publish_oci_blob_from_file`.

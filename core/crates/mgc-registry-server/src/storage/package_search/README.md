# Package Search

Builds the existing registry package search results from package metadata.

**Ownership:** `search_packages`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

---

# Package Search — Tiếng Việt

Tạo kết quả tìm package theo hành vi hiện có từ metadata package.

**Phạm vi sở hữu:** `search_packages`. Module giữ nguyên contract storage hiện có và không chuyển thao tác registry sang package manager bên ngoài.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

# Trusted Publisher

Owns trusted publisher bindings and trusted distribution-tag updates.

**Ownership:** `set_trusted_publisher, trusted_publisher, trusted_publisher_binding, set_trusted_dist_tag`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

# Trusted Publisher — Tiếng Việt

Sở hữu liên kết trusted publisher và cập nhật distribution tag tin cậy.

**Phạm vi sở hữu:** `set_trusted_publisher, trusted_publisher, trusted_publisher_binding, set_trusted_dist_tag`. Module giữ nguyên contract storage hiện có và không chuyển thao tác registry sang package manager bên ngoài.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

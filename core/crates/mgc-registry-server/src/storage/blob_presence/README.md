# Blob presence

Defines `BlobPresence` and the storage lookup that distinguishes a missing blob, a length-matched blob, and a torn or mismatched blob. The state remains length-based; full digest verification still occurs when serving content.

# Blob presence — Tiếng Việt

Định nghĩa `BlobPresence` và truy vấn phân biệt blob thiếu, blob khớp độ dài và blob bị cắt/lệch. Trạng thái vẫn dựa trên độ dài; digest được xác minh đầy đủ khi phục vụ nội dung.

# Pypi Files

Looks up and stores the existing PyPI file index entries.

**Ownership:** `get_pypi_file_digest, get_pypi_files, put_pypi_file`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

# Pypi Files — Tiếng Việt

Truy vấn và lưu các entry index file PyPI hiện có.

**Phạm vi sở hữu:** `get_pypi_file_digest, get_pypi_files, put_pypi_file`. Module giữ nguyên contract storage hiện có và không chuyển thao tác registry sang package manager bên ngoài.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

# Oci Upload Session

Resumable OCI session lifecycle. The owner preserves the existing database transaction, offset checks, filesystem writes, and public RegistryStore methods.

**Methods:** `oci_upload_lock, create_oci_upload, append_oci_upload, truncate_oci_upload, oci_upload_path, oci_upload_offset`.

# Trusted Pypi File

Stores a PyPI file after the existing trusted-publisher validation path.

**Ownership:** `put_trusted_pypi_file`. This module keeps the existing storage contract and delegates no registry operation to an external package manager.

**Tests:** existing registered integration coverage remains under `core/crates/mgc-registry-server/tests/`; owner-local tests are linked below when present.

# Trusted Pypi File — Tiếng Việt

Lưu file PyPI sau luồng xác thực trusted-publisher hiện có.

**Phạm vi sở hữu:** `put_trusted_pypi_file`. Module giữ nguyên contract storage hiện có và không chuyển thao tác registry sang package manager bên ngoài.

**Kiểm thử:** test integration đã đăng ký vẫn ở `core/crates/mgc-registry-server/tests/`; test gần owner được liên kết bên dưới nếu có.

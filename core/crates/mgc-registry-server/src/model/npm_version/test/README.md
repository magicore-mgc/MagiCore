# npm version tests / Test version npm

Checks package-version camelCase keys, `_id`/`_rev`, and omitted optional scripts at the nearest owner. Deprecation input acceptance is tested in the dedicated sibling owner. Tests are source-only and `NOT_RUN`.

Kiểm tra các khóa camelCase, `_id`/`_rev` và việc bỏ field `scripts` tùy chọn ngay tại owner gần nhất. Dạng đầu vào deprecation được kiểm tra ở owner riêng bên cạnh. Test mới chỉ có trong source và `NOT_RUN`.

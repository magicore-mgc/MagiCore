# npm package tests / Test package npm

Checks the `dist-tags` wire key and package maintainer/default data at the nearest package-model owner. Test bodies are separate from production and remain `NOT_RUN` until the storage gate is satisfied.

Kiểm tra khóa wire `dist-tags` cùng dữ liệu maintainer/giá trị mặc định ngay tại owner package. Nội dung test tách khỏi production và vẫn `NOT_RUN` cho tới khi đáp ứng điều kiện dung lượng.

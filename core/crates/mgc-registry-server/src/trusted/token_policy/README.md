# Token Policy

Owns trusted token lifetime and active-token capacity constants.

**Owned API:** `TRUSTED_TOKEN_TTL_SECS, MAX_ACTIVE_TRUSTED_TOKENS`. Imports are shared through the local trusted prelude; public names re-export to preserve `crate::trusted::*`.

# Token Policy — Tiếng Việt

Sở hữu constant policy về thời hạn và sức chứa token trusted.

**API sở hữu:** `TRUSTED_TOKEN_TTL_SECS, MAX_ACTIVE_TRUSTED_TOKENS`. Import dùng chung qua prelude nội bộ; tên công khai được export để giữ nguyên `crate::trusted::*`.

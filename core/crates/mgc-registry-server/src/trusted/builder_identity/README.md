# Builder Identity

Matches OIDC claims to repository bindings and maps claims into the public builder identity.

**Owned API:** `claims_match_repository_binding`. Imports are shared through the local trusted prelude; public names re-export to preserve `crate::trusted::*`.

# Builder Identity — Tiếng Việt

Đối chiếu OIDC claims với repository binding và chuyển claims sang builder identity công khai.

**API sở hữu:** `claims_match_repository_binding`. Import dùng chung qua prelude nội bộ; tên công khai được export để giữ nguyên `crate::trusted::*`.

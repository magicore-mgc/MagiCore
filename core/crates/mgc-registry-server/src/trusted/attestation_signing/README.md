# Attestation Signing

Creates canonical signed provenance entries and Sigstore Fulcio/Rekor attestations.

**Owned API:** `TRUSTED_PUBLISH_PREDICATE_TYPE, sign_attestation, sign_sigstore_attestation`. Imports are shared through the local trusted prelude; public names re-export to preserve `crate::trusted::*`.

# Attestation Signing — Tiếng Việt

Tạo provenance entry có chữ ký canonical và attestation Sigstore Fulcio/Rekor.

**API sở hữu:** `TRUSTED_PUBLISH_PREDICATE_TYPE, sign_attestation, sign_sigstore_attestation`. Import dùng chung qua prelude nội bộ; tên công khai được export để giữ nguyên `crate::trusted::*`.

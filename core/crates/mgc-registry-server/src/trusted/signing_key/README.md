# Signing Key

Reads, validates, creates, and locates the registry signing key under the bounded no-symlink policy.

**Owned API:** `load_or_create_signing_key, signing_key_path`. Imports are shared through the local trusted prelude; public names re-export to preserve `crate::trusted::*`.

# Signing Key — Tiếng Việt

Đọc, xác minh, tạo và tìm signing key registry theo policy bounded/no-symlink.

**API sở hữu:** `load_or_create_signing_key, signing_key_path`. Import dùng chung qua prelude nội bộ; tên công khai được export để giữ nguyên `crate::trusted::*`.

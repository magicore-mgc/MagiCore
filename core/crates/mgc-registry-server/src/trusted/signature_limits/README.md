# Signature Limits

Owns default and maximum trusted-signature page sizes.

**Owned API:** `SIGNATURE_PAGE_SIZE, MAX_SIGNATURE_PAGE_SIZE`. Imports are shared through the local trusted prelude; public names re-export to preserve `crate::trusted::*`.

# Signature Limits — Tiếng Việt

Sở hữu page size mặc định và giới hạn tối đa của trusted signature.

**API sở hữu:** `SIGNATURE_PAGE_SIZE, MAX_SIGNATURE_PAGE_SIZE`. Import dùng chung qua prelude nội bộ; tên công khai được export để giữ nguyên `crate::trusted::*`.

# Blob transfer / Truyền blob

Owns blob existence, download digest verification, and chunked upload through `mgc-http`. Existing request sequence and whole-buffer behavior remain unchanged.

Quản lý kiểm tra blob, xác minh digest khi tải và upload chia chunk qua `mgc-http`. Thứ tự request và cách dùng buffer hiện tại được giữ nguyên.

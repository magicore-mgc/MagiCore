# OCI client errors / Lỗi OCI client

Defines local status/digest failures for this client. Public methods continue returning `anyhow::Result`; exact user-visible messages remain compatible.

Định nghĩa lỗi status/digest cục bộ cho client. Method công khai vẫn trả `anyhow::Result`; message hiển thị được giữ tương thích.

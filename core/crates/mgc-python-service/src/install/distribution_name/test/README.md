# Distribution-name tests

These tests pin the PEP 503 normalization behavior used when matching manifest dependencies to lock entries. They do not claim registry resolution or install coverage. Tests are authored and `NOT_RUN` in the current source-first phase.

## Test tên distribution

Các test khóa hành vi chuẩn hóa PEP 503 khi đối chiếu dependency manifest với entry lock. Chúng không chứng minh resolve registry hay cài package. Test đã viết và `NOT_RUN` trong pha source-first hiện tại.

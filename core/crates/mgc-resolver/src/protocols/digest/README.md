# Registry digest helpers

Owns SHA-256 lowercase-hex output and the BLAKE3 `files/blake3/xx/hash` CAS path formatter. These helpers are used across Rust, Go, Python, Hugging Face and adapter lifecycle code.

Sở hữu SHA-256 hex thường và formatter CAS BLAKE3 `files/blake3/xx/hash`. Helper được dùng ở Rust, Go, Python, Hugging Face và lifecycle adapter.

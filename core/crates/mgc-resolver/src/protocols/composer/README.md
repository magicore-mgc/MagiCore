# Composer (Packagist) resolver / Resolver Composer (Packagist)

`protocols::composer` implements the native Composer protocol against Packagist v2 metadata: `GET {repository}/p2/<vendor>/<package>.json`. `composer.rs` owns protocol state and constructors (`MGC_COMPOSER_REPOSITORY_URL`, default `https://repo.packagist.org`); `metadata_client.rs` owns HTTP fetch/parse and dist download; `package_catalog/` owns name validation, p2 types (including Composer's minified `"__unset"` sentinel) and version projection; `version_constraints.rs` owns Composer constraint and version semantics; `registry.rs` implements the shared `RegistryProtocol` contract.

Mapping: the highest version satisfying the constraint becomes the resolved package id (`vendor/package` + version), `dist.url` becomes the artifact URL, `dist.shasum` (sha1) is recorded as `checksum-sha1:<hex>` and `dist.reference` as `dist-reference:<hex>` when no shasum is published. `require` edges become `ResolvedEntry::deps` (the production graph the shared resolver walks); `require-dev` edges become `require-dev:<name>:<constraint>` markers plus platform constraints (`php`, `ext-*`, `lib-*`, `composer-*`) as `require:`/`require-dev:` markers, so the default graph traversal never resolves development dependencies. `replace:`/`provide:` entries become `substituted:<name>` markers.

GitHub `api.github.com/repos/<owner>/<repo>/zipball/<ref>` dists are rewritten to `codeload.github.com/<owner>/<repo>/legacy.zip/<ref>` because the API host returns 403 to clients without a browser User-Agent; codeload serves the same commit anonymously. Integrity is fail-closed: a malformed shasum, a missing dist URL or neither shasum nor reference is an error.

Unit tests live next to their owners (`package_catalog/test/`, `test/version_constraints/`, `test/composer_protocol/`) and use a captured `monolog/monolog` p2 document in `test/fixtures/`. The live lane is `cli/tests/composer_live_e2e.rs`: it resolves, downloads and verifies against the real registry, skips honestly when `repo.packagist.org` is unreachable (unless `MGC_E2E_COMPOSER_NETWORK=required`), and never substitutes a mock for Packagist.

`protocols::composer` triển khai protocol Composer native trên metadata Packagist v2: `GET {repository}/p2/<vendor>/<package>.json`. `composer.rs` giữ trạng thái/constructor (`MGC_COMPOSER_REPOSITORY_URL`, mặc định `https://repo.packagist.org`); `metadata_client.rs` giữ HTTP tải/parse và tải dist; `package_catalog/` giữ kiểm tra tên, kiểu p2 (kể cả sentinel `"__unset"` của metadata minified) và chiếu version; `version_constraints.rs` giữ ngữ nghĩa ràng buộc và version Composer; `registry.rs` cài `RegistryProtocol` dùng chung.

Ánh xạ: version cao nhất thoả ràng buộc thành package id đã resolve; `dist.url` thành URL artifact; `dist.shasum` (sha1) ghi `checksum-sha1:<hex>`, `dist.reference` ghi `dist-reference:<hex>` khi không có shasum. Cạnh `require` vào `ResolvedEntry::deps` (graph production); cạnh `require-dev` thành marker `require-dev:<name>:<constraint>`; package platform (`php`, `ext-*`, `lib-*`, `composer-*`) thành marker, nên duyệt graph mặc định không kéo dev dependency. `replace:`/`provide:` thành marker `substituted:<name>`.

Dist zipball GitHub được đổi sang dạng codeload vì API trả 403 khi thiếu User-Agent trình duyệt; codeload phục vụ cùng commit ẩn danh. Toàn vẹn fail-closed: shasum sai dạng, thiếu dist URL hoặc thiếu cả shasum lẫn reference đều là lỗi.

Test unit nằm cạnh owner và dùng tài liệu p2 `monolog/monolog` đã capture trong `test/fixtures/`. Lane thật là `cli/tests/composer_live_e2e.rs`: resolve, tải và xác minh trên registry thật, skip trung thực khi `repo.packagist.org` không tới được (trừ khi `MGC_E2E_COMPOSER_NETWORK=required`), không thay Packagist bằng mock.

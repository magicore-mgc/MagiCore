# Swift registry owners / Owner registry Swift

This folder keeps the `swift::registry::SwiftRegistryProtocol` facade and the compatibility path `swift::registry::registry::SwiftRegistryProtocol`. `registry.rs` owns protocol state and HTTP helpers; `resolve.rs` owns version/checksum/archive selection; `protocol.rs` implements the shared trait and download/verification behavior; `materialize.rs` owns the checkout layout; `zip_cache/` owns bounded retained archives and its environment configuration.

Folder này giữ facade `swift::registry::SwiftRegistryProtocol` và đường tương thích `swift::registry::registry::SwiftRegistryProtocol`. `registry.rs` quản lý state và helper HTTP; `resolve.rs` xử lý chọn version/checksum/archive; `protocol.rs` implement trait dùng chung và download/verify; `materialize.rs` quản lý layout checkout.

The ZIP cache is process-local, bounded by both retained bytes and entry count, and configured by `MGC_SWIFT_REGISTRY_CACHE_MAX_BYTES` / `MGC_SWIFT_REGISTRY_CACHE_MAX_ENTRIES`. App's same-instance resolve/install path carries the protocol object so resolved archives can be reused; direct installs and lock replay retain the `from_env()` fallback. Cache hits still pass through install checksum verification. Errors cross the unchanged `mgc_types::MgError`/`MgResult` API; Git and local file dependencies continue to fail closed. The five integration cases live in `test/` and are included by the unchanged Cargo integration-test target `tests/protocols_swift.rs`.

Cache ZIP chỉ trong process, có giới hạn cả byte được giữ lẫn số entry, cấu hình qua `MGC_SWIFT_REGISTRY_CACHE_MAX_BYTES` / `MGC_SWIFT_REGISTRY_CACHE_MAX_ENTRIES`. Luồng resolve/install cùng instance của App giữ lại protocol để tái dùng archive đã resolve; direct install và replay lock vẫn dùng fallback `from_env()`. Cache hit vẫn phải qua bước xác minh checksum lúc install. Error giữ API `mgc_types::MgError`/`MgResult`; dependency Git và local tiếp tục fail-closed. Năm integration case nằm trong `test/`, được include từ Cargo target không đổi `tests/protocols_swift.rs`.

Swift registry HTTP response limits are 16 MiB for version lists, 1 KiB for checksum files, and 512 MiB for ZIP archives/download misses. Responses over the limit fail closed through `mgc-http::get_bytes_limited`; archives above 512 MiB need a future streaming-to-disk path. These are per-response limits and do not cap aggregate memory when requests run concurrently.

Giới hạn response HTTP của registry Swift là 16 MiB cho version list, 1 KiB cho checksum, 512 MiB cho ZIP/archive tải lại khi cache miss. Response vượt giới hạn fail-closed qua `mgc-http::get_bytes_limited`; archive lớn hơn 512 MiB cần luồng streaming xuống đĩa ở bước sau. Đây là giới hạn từng response, không phải trần tổng RAM khi nhiều request chạy đồng thời.

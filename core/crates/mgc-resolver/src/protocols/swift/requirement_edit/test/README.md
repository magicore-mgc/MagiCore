# Swift requirement-edit unit tests

This directory contains independent nearest-owner suites for version bumps and dependency removal. The legacy tests keep separate `PKG` fixtures and preserve their original assertions.

## Tiếng Việt

Thư mục này chứa suite gần owner riêng cho bump version và xóa dependency. Test legacy tiếp tục có fixture `PKG` riêng, giữ nguyên assertion gốc.

# Package.swift text parser / Parser văn bản Package.swift

Owns balanced `.package(...)` scanning, registry/Git dependency extraction, requirement encoding, and the small quote/range helpers consumed by Swift requirement editing.

Quản lý quét `.package(...)` cân bằng, lấy dependency registry/Git, mã hóa requirement và các helper quote/range nhỏ được Swift requirement editor dùng chung.

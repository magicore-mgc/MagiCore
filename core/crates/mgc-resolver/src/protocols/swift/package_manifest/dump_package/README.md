# dump-package JSON parser / Parser JSON dump-package

Owns decoding the new registry/remote and legacy source-array JSON shapes, mapping supported requirements, preserving dependency order, and warning/skipping unsupported source or range forms.

Quản lý parse JSON registry/remote kiểu mới và source-array kiểu cũ, ánh xạ requirement hỗ trợ, giữ thứ tự dependency và cảnh báo/bỏ qua loại source hoặc range chưa hỗ trợ.

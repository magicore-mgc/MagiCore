# Interval range matching

## Purpose

Owns parsing bracketed version intervals (`[a,b]`, `[a,b)`, `(a,)`, `[a]`) into inclusive/exclusive bound checks. Shared by the NuGet and Maven constraint parsers, which use the same interval notation.

## Vietnamese

Sở hữu việc parse interval version dạng ngoặc (`[a,b]`, `[a,b)`, `(a,)`, `[a]`) thành kiểm cận đóng/mở. Dùng chung cho parser constraint NuGet và Maven vì cùng ký pháp interval.

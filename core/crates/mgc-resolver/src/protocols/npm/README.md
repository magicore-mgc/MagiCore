# NpmProtocol slot

This public slot remains unsupported and returns the same `MgError::Unsupported` fields and guidance. The Web adapter's native npm install/resolve path is separate and is not changed here.

Slot public này vẫn unsupported và trả cùng field/guidance `MgError::Unsupported`. Đường install/resolve npm native của adapter Web riêng biệt và không bị thay đổi.

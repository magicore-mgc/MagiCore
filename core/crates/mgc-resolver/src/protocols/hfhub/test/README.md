# Protocol configuration tests

Checks the explicit base URL normalization owned by HfHubProtocol. Authentication and environment-driven HTTP behavior remain covered only by black-box tests where configured; no environment mutation is introduced here.

Kiểm tra chuẩn hóa URL gốc tường minh do HfHubProtocol sở hữu. Hành vi HTTP lấy auth/môi trường chỉ nằm ở black-box test phù hợp; test này không sửa biến môi trường toàn cục.

# ModelResolution owner

Owns the public result DTO for one immutable model revision. The type remains re-exported at protocols::ModelResolution and protocols::hfhub::ModelResolution. Resolution behavior is covered by the unchanged protocols_hfhub integration suite.

Phụ trách DTO kết quả công khai của một revision model bất biến. Type tiếp tục được export tại protocols::ModelResolution và protocols::hfhub::ModelResolution. Hành vi resolve được bao phủ bởi integration suite protocols_hfhub giữ nguyên.

# Model identity tests

These nearest-owner tests cover the accepted syntax and exact legacy MgError mapping. The frozen black-box suite additionally verifies invalid inputs fail before contacting the network.

Các test gần owner kiểm tra cú pháp được chấp nhận và mapping MgError cũ chính xác. Suite black-box được giữ nguyên còn kiểm tra input sai bị chặn trước khi gọi mạng.

# Model identity owner

Validates the exact org/name syntax and immutable 40-hex revision rule before HTTP. Typed local failures map to the same MgError::Other messages as the previous resolver. The public-operation no-request behavior is also covered by the frozen protocols_hfhub integration cases.

Kiểm tra cú pháp org/name chính xác và quy tắc revision bất biến 40-hex trước HTTP. Lỗi typed cục bộ được ánh xạ về cùng thông báo MgError::Other như resolver cũ. Hành vi không gửi request khi input sai cũng nằm trong các ca integration protocols_hfhub được giữ nguyên.

# File integrity tests

Nearest-owner tests cover the known Git object hash, LFS SHA-256 precedence, and the shared Integrity error category. The unchanged integration suite checks both successful and tampered model bytes.

Test gần owner bao phủ Git object hash đã biết, ưu tiên SHA-256 LFS và nhóm lỗi Integrity dùng chung. Integration suite không đổi kiểm tra byte model hợp lệ và bị sửa.

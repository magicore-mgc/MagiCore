# ModelFile owner

Owns the public locked-file data shape only. Its fields and derives remain compatible with protocols::ModelFile. Public construction and integrity behavior are covered by core/crates/mgc-resolver/tests/protocols_hfhub.rs; that HTTP/API suite remains unchanged.

Phụ trách duy nhất cấu trúc dữ liệu file đã lock. Field và derive giữ tương thích với protocols::ModelFile. Việc tạo DTO công khai và kiểm tra toàn vẹn được bao phủ tại core/crates/mgc-resolver/tests/protocols_hfhub.rs; suite HTTP/API này giữ nguyên.

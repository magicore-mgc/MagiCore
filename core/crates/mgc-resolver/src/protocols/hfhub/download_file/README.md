# Download file owner

Owns the GET of a previously locked direct URL. It preserves the shared client, reads the response body before status evaluation, and returns the same Network messages. Successful download behavior is covered by the unchanged protocols_hfhub HTTP integration test.

Phụ trách GET URL trực tiếp đã lock. Giữ client dùng chung, đọc body trước khi xét status và trả cùng thông báo Network. Luồng tải thành công được bao phủ bởi HTTP integration test protocols_hfhub không đổi.

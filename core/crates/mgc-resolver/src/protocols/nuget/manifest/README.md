# NuGet manifest owner

Owns the public PackageReference type and extraction of resolved/unresolved PackageReference elements from project text.

## Tiếng Việt

Quản lý type PackageReference công khai và trích xuất các phần tử resolved/unresolved từ nội dung project. Caller trong Lib adapter tiếp tục dùng `protocols::nuget::parse_package_references`. Unit test parser hiện có ở `test/`.

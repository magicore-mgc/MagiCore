# NuGet framework owner

Parses supported .NET TFM families and ranks same-family/compatible .NET Standard candidates for consumer-target selection.

## Tiếng Việt

Parse các họ TFM .NET đang hỗ trợ và xếp hạng candidate cùng họ/tương thích .NET Standard theo consumer. Unit test chung `xml_attr_and_tfm` nằm tại `test/`.

# NuGet registration-integrity owner

Follows the selected registration leaf to the catalog document, enforces the listed gate and validates the authoritative SHA-512 base64 package hash. It returns the resolver's existing `sha512:` marker and keeps outward failures in the shared `MgError` categories.

## Tiếng Việt

Theo registration leaf đã chọn tới catalog, bắt buộc trạng thái listed và kiểm tra package hash SHA-512 base64 chính thống. Owner trả marker `sha512:` hiện có và giữ lỗi outward trong các category `MgError` dùng chung.

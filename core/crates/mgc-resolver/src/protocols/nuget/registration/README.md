# NuGet registration owner

Discovers resources from the service index, follows paginated registration pages, and flattens complete catalog leaves.

## Tiếng Việt

Tìm resource từ service index, theo các registration page phân trang và làm phẳng catalog leaf đầy đủ. Lỗi tải/parse và fail-closed khi index không đầy đủ được giữ nguyên. Unit test flatten leaves ở `test/`.

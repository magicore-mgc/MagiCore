# CocoaPods dependency extraction / Trích dependency CocoaPods

This owner maps JSON `dependencies` objects to `(name, requirement)` edges. Missing or non-object dependency data yields an empty edge list, matching the current protocol behavior.

Owner này chuyển object JSON `dependencies` thành cạnh `(name, requirement)`. Dữ liệu dependency thiếu hoặc không phải object trả danh sách cạnh rỗng, đúng hành vi protocol hiện tại.

# CocoaPods protocol tests / Test protocol CocoaPods

This folder pins the public client's explicit-CDN normalization behavior. Typed error mapping is tested under `client/test/`; the app-level HTTP fixtures live in `adapters/app/tests/native_rn_tests.rs`.

Folder này khóa hành vi chuẩn hóa CDN tường minh của client công khai. Ánh xạ lỗi typed được test trong `client/test/`; fixture HTTP tầng app nằm tại `adapters/app/tests/native_rn_tests.rs`.

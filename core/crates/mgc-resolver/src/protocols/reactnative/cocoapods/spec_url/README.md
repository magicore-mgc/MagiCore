# CocoaPods spec URL / URL spec CocoaPods

This owner contains the pure CDN path rule, including lowercase first-character sharding and the `0-9` digit bucket. It performs no network request and retains the current path output.

Owner này chứa quy tắc đường dẫn CDN thuần, gồm phân shard theo ký tự đầu viết thường và bucket chữ số `0-9`. Module không tạo request mạng và giữ output đường dẫn hiện tại.

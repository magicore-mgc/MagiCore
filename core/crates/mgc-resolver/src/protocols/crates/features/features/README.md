# features implementation owners

EN: Child owners of the Cargo feature graph facade. `feature_graph` closes the package graph and owns graph errors, `activation` expands Cargo feature declarations and owns declaration errors, and `resolved_entry` projects the result and owns missing-checksum errors.

VI: Các owner con của facade graph feature Cargo. `feature_graph` đóng graph package và sở hữu lỗi graph, `activation` mở rộng feature và sở hữu lỗi khai báo, còn `resolved_entry` chiếu kết quả và sở hữu lỗi thiếu checksum.

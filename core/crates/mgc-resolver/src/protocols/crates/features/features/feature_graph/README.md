# feature_graph

EN: Resolve dependency edges to a stable transitive crate closure. `FeatureGraphError` carries activation, index, projection, alternate-registry, and cache-invariant failures to the protocol boundary.

VI: Resolve các cạnh dependency thành closure crate bắc cầu ổn định. `FeatureGraphError` mang lỗi activation, index, projection, alternate registry và bất biến cache tới boundary protocol.

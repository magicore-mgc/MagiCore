# features

EN: Facade for Cargo feature activation, graph closure, and resolved-entry projection. Each algorithm owns its typed errors before conversion to the existing shared `MgError` categories; integration behavior remains in the resolver crate test target.

VI: Facade cho kích hoạt feature Cargo, đóng graph và projection entry đã resolve. Mỗi thuật toán sở hữu lỗi typed trước khi chuyển về nhóm `MgError` hiện có; hành vi integration tiếp tục ở test target của crate resolver.

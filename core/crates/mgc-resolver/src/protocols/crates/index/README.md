# index

EN: Sparse-index path, parsing, and version/checksum selection. `IndexError` owns parse, selection, checksum, and nested HTTP failures; shared error conversion preserves the existing `Other`, `Integrity`, and `Network` categories.

VI: Đường dẫn, parse sparse-index và chọn version/checksum. `IndexError` sở hữu lỗi parse, lựa chọn, checksum và HTTP lồng; chuyển đổi giữ nguyên nhóm `Other`, `Integrity` và `Network` hiện tại.

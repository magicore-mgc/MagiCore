# resolve

EN: Legacy single-package RegistryProtocol resolve route. `ResolveError` owns index parsing, version selection, checksum, alternate-registry, and nested HTTP failures before conversion to `MgError`.

VI: Route resolve một package của RegistryProtocol hiện hành. `ResolveError` sở hữu lỗi parse index, chọn version, checksum, alternate registry và HTTP lồng trước khi chuyển sang `MgError`.

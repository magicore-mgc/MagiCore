# selected_metadata / selected_metadata

Reuses version-specific PyPI metadata already fetched during Python-target selection, or fetches and parses the selected release metadata at the original point in the resolution sequence.

Tái sử dụng metadata theo version đã tải khi chọn Python target, hoặc tải và parse metadata của release được chọn đúng vị trí cũ trong trình tự resolve.

The owner preserves request count/order and the exact parse diagnostic; it adds no HTTP or cache policy.

Owner giữ số lượng/thứ tự request và diagnostic parse; không thêm HTTP/cache policy.

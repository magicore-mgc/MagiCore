# artifact_markers / artifact_markers

Projects the selected wheel or source archive into the existing lockfile marker strings, preserving tag and Requires-Python values and order.

Chiếu wheel hoặc source archive đã chọn thành marker lockfile hiện có, giữ nguyên tag, Requires-Python và thứ tự.

This owner does not choose artifacts or change compatibility policy; those decisions remain in wheel_selection and python_release_selection.

Owner này không chọn artifact và không đổi policy tương thích; các quyết định đó thuộc wheel_selection và python_release_selection.

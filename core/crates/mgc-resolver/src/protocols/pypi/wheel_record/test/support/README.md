# test_support / hỗ trợ test

Owns the one stored-method ZIP fixture and `ResolvedEntry` fixture shared by the PyPI importable tests and nearest wheel-record runtime test. These helpers compile only under `cfg(test)`.

Sở hữu fixture ZIP stored và `ResolvedEntry` dùng chung giữa test PyPI importable và test runtime wheel-record gần owner. Helper chỉ được biên dịch khi `cfg(test)`.

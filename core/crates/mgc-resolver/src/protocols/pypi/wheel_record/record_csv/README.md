# record_csv / CSV RECORD

Parses the exact three-field RECORD row and owns typed parse reasons. The higher-level verifier maps those reasons to the existing `MgError::Integrity` message.

Parse đúng dòng RECORD ba trường và sở hữu nguyên nhân lỗi parse typed. Verifier cấp cao ánh xạ các lỗi này về thông điệp `MgError::Integrity` hiện có.

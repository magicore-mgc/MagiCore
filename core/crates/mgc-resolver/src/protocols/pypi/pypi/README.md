# PyPI coordinator / Điều phối PyPI

Owns stable `PypiProtocol`, configuration and default constructors. Request, resolution and policy are wired through sibling owners. The three coordinator test groups live in `test/` and are registered directly from `pypi.rs`.

Sở hữu `PypiProtocol` ổn định, cấu hình và constructor mặc định. Request, resolve và policy được nối qua owner bên cạnh. Ba nhóm test của coordinator nằm trong `test/` và được đăng ký trực tiếp từ `pypi.rs`.

# extract_root tests

## Responsibility / Trách nhiệm

Nearest tests for acquiring a real directory root and rejecting symlink/non-directory substitutions. Existing and newly added cases are authored but NOT_RUN during the source-first phase.

## Tiếng Việt

Test gần nhất cho phần lấy root là thư mục thật, từ chối symlink hoặc thay thế bằng loại file khác. Các case cũ và mới đã được viết nhưng NOT_RUN trong giai đoạn ưu tiên source.

# extract_target tests

## Responsibility / Trách nhiệm

Nearest tests for building contained file/directory targets component-by-component and refusing linked parents/targets. Existing and newly added cases are authored but NOT_RUN during the source-first phase.

## Tiếng Việt

Test gần nhất cho phần tạo target file/thư mục nằm trong root theo từng thành phần và từ chối parent/target dạng link. Các case cũ và mới đã được viết nhưng NOT_RUN trong giai đoạn ưu tiên source.

# archive

## Responsibility / Trách nhiệm

Provides the stable tar.gz extraction and Cargo archive API while delegating implementation to focused owners. It converts archive-local typed failures into the existing `MgError` variants.

## Tiếng Việt

Cung cấp API ổn định để giải nén tar.gz và xử lý archive Cargo, đồng thời chuyển tiếp implementation sang các owner chuyên trách. Module ánh xạ lỗi typed cục bộ về các variant `MgError` hiện hành.

# extracted_file_write tests

## Responsibility / Trách nhiệm

Nearest tests for stages regular file bytes with create-new, sync and platform-specific atomic replacement. Existing and newly added cases are authored but NOT_RUN during the source-first phase.

## Tiếng Việt

Test gần nhất cho phần ghi staging file thường bằng create-new, sync và thay thế nguyên tử theo hệ điều hành. Các case cũ và mới đã được viết nhưng NOT_RUN trong giai đoạn ưu tiên source.

# archive_path tests

## Responsibility / Trách nhiệm

Nearest tests for archive-name normalization and safe relative filesystem component checks. Existing and newly added cases are authored but NOT_RUN during the source-first phase.

## Tiếng Việt

Test gần nhất cho phần sở hữu chuẩn hóa tên archive và kiểm tra thành phần filesystem tương đối an toàn. Các case cũ và mới đã được viết nhưng NOT_RUN trong giai đoạn ưu tiên source.

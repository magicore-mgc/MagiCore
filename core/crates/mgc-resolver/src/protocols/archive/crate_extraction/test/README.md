# crate_extraction tests

## Responsibility / Trách nhiệm

Nearest tests for exact Cargo package-prefix and root-manifest validation before materializing a crate archive. Existing and newly added cases are authored but NOT_RUN during the source-first phase.

## Tiếng Việt

Test gần nhất cho phần xác minh prefix cargo chính xác và manifest gốc trước khi materialize archive crate. Các case cũ và mới đã được viết nhưng NOT_RUN trong giai đoạn ưu tiên source.

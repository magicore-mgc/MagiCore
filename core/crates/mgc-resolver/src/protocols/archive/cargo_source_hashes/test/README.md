# cargo_source_hashes tests

## Responsibility / Trách nhiệm

Nearest tests for regular Cargo source hashing relative to the package root without writing files to disk. Existing and newly added cases are authored but NOT_RUN during the source-first phase.

## Tiếng Việt

Test gần nhất cho phần hash file source cargo theo đường dẫn tương đối root package mà không ghi ra đĩa. Các case cũ và mới đã được viết nhưng NOT_RUN trong giai đoạn ưu tiên source.

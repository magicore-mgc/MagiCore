# tar_extraction tests

## Responsibility / Trách nhiệm

Nearest tests for safely extracting regular tar entries after type, path and size checks. Existing and newly added cases are authored but NOT_RUN during the source-first phase.

## Tiếng Việt

Test gần nhất cho phần điều phối giải nén entry tar thường sau khi kiểm tra type, path và kích thước. Các case cũ và mới đã được viết nhưng NOT_RUN trong giai đoạn ưu tiên source.

# ZIP extraction tests

## English

Keeps file-write, traversal, symlink-parent, symlink-destination, and symlink-file-target regressions beside the extraction boundary. All assertions preventing writes outside the destination are retained. Tests are not run yet.

## Tiếng Việt

Giữ regression ghi file, traversal, symlink parent, symlink đích và symlink file-target ngay cạnh ranh giới extraction. Giữ mọi assertion ngăn ghi ra ngoài đích. Chưa chạy test.

# ZIP extraction owner

## English

Coordinates archive reading, safe extraction-root acquisition, sanitized relative paths, contained targets, and the existing shared archive writer. Traversal and symlink protections, size caps, error text, and write order are preserved. File-write, traversal, and Unix symlink cases live in the local test folder.

## Tiếng Việt

Điều phối đọc archive, lấy extraction root an toàn, sanitize relative path, kiểm tra target nằm trong root và gọi writer archive dùng chung. Giữ bảo vệ traversal/symlink, giới hạn kích thước, error text và thứ tự ghi. Test ghi file, traversal và symlink Unix nằm trong folder test owner.

# CRC-32 owner

## English

Owns the reflected IEEE 802.3 CRC-32 implementation with polynomial `0xEDB88320` and preserves the public `crc32` function. No dependency or algorithm change is part of this structural move. Reference-vector and empty-input cases are adjacent; integration smoke remains in the protocol test.

## Tiếng Việt

Sở hữu implementation CRC-32 IEEE 802.3 dạng reflected với polynomial `0xEDB88320`, giữ nguyên hàm public `crc32`. Lượt cấu trúc này không đổi thuật toán hay dependency. Test vector chuẩn và input rỗng nằm cạnh source; integration smoke tiếp tục ở protocol test.

# End-record tests

## English

Retains malformed/truncated ZIP cases through the public read API, adjacent to EOCD lookup and parsing. Executable verification is deferred.

## Tiếng Việt

Giữ các trường hợp ZIP lỗi/truncated qua public read API, đặt gần xử lý EOCD. Chưa chạy kiểm chứng executable.

# End-record owner

## English

Owns End-Of-Central-Directory lookup and field decoding. The coordinator delegates signature search and field parsing while preserving the current scan window and entry-count/offset/size interpretation. Malformed/truncated ZIP coverage is attached to this owner.

## Tiếng Việt

Sở hữu việc tìm và giải mã End-Of-Central-Directory. Coordinator ủy quyền tìm signature và parse trường, giữ nguyên vùng quét và cách đọc số entry/offset/size. Test ZIP lỗi/truncated được gắn với owner này.

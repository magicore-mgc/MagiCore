# Local-entry tests

## English

Checks that stored and DEFLATE payload lengths cannot disagree with the central-directory declaration, including output larger or smaller than expected. Tests are added beside the bounded decoder; they have not been executed yet.

## Tiếng Việt

Kiểm tra payload store và DEFLATE không được lệch độ dài đã khai báo trong central-directory, gồm trường hợp output lớn hoặc nhỏ hơn dự kiến. Test nằm cạnh decoder có giới hạn; hiện chưa chạy.

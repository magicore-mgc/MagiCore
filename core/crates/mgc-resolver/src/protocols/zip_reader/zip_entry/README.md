# ZIP entry DTO owner

## English

Owns the public `ZipEntry` DTO with its stored name and decompressed payload. Public fields, `Debug`, and `Clone` stay unchanged; no new identity or metadata is introduced.

## Tiếng Việt

Sở hữu DTO public `ZipEntry` gồm tên entry và payload đã giải nén. Giữ nguyên field public, `Debug` và `Clone`; không thêm identity hoặc metadata mới.

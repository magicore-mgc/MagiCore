# Maven coordinate validation / Kiểm tra tọa độ Maven

Owns `group:artifact` parsing and cache path component validation. This owner does not normalize valid Maven versions or change the `MgResult` error contract.

Quản lý parse `group:artifact` và validate component của đường dẫn cache. Owner không chuẩn hóa version Maven hợp lệ và không đổi hợp đồng lỗi `MgResult`.

# Maven artifact materialization / Ghi artifact Maven vào local repo

Owns the Maven `m2` directory layout, jar/POM writes, and verified SHA-256 or published SHA-1 sidecar output. Coordinate and version checks run before the first directory write.

Quản lý layout thư mục Maven `m2`, ghi jar/POM và sidecar SHA-256 hoặc SHA-1 đã công bố. Coordinate/version được kiểm tra trước lần ghi thư mục đầu tiên.

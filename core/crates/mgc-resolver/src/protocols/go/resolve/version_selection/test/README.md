# Go version-selection tests

These tests protect exact-pin syntax and rejection of composite/range expressions. The HTTP list and `@latest` journeys stay in the registered crate integration target.

## Tiếng Việt

Các test này khóa cú pháp exact-pin và việc từ chối biểu thức range phức hợp. Luồng HTTP list và `@latest` vẫn nằm trong integration target đã đăng ký của crate.

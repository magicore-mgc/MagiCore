# Go version-materialization tests

Protects release identity parsing at the owner boundary. HTTP sequencing, required `.mod`, integrity markers and full `ResolvedEntry` construction are covered by the crate's hermetic protocol integration suite.

## Tiếng Việt

Khóa hành vi parse identity release tại boundary của owner. Thứ tự HTTP, `.mod` bắt buộc, integrity marker và tạo `ResolvedEntry` đầy đủ được kiểm tra trong integration suite hermetic của crate.

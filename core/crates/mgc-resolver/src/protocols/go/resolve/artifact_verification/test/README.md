# Go artifact-verification tests

Covers sha256 case normalization, changed payload rejection, and missing-evidence fail-closed behavior. Sumdb zip/directory-hash success and tamper cases remain in the hermetic protocol integration suite.

## Tiếng Việt

Kiểm tra chuẩn hóa chữ hoa/thường của sha256, từ chối payload bị đổi và fail-closed khi thiếu bằng chứng. Ca sumdb zip/directory-hash hợp lệ và payload bị sửa tiếp tục nằm trong integration suite hermetic.

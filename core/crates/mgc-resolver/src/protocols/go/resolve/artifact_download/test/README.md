# Go artifact-download tests

Checks exact resolved-URL use and byte delivery through the configured client. HTTP failure mapping remains defined by the Go HTTP owner.

## Tiếng Việt

Kiểm tra việc dùng đúng URL đã resolve và trả bytes qua client đã cấu hình. Ánh xạ lỗi HTTP vẫn do owner HTTP Go quy định.

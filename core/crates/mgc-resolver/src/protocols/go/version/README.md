# Go version owner

Parses Go module versions, including accepted `+incompatible`, and evaluates the current supported operators without changing bare-pin semantics.

## Tiếng Việt

Parse version module Go (gồm `+incompatible` được chấp nhận) và đánh giá các toán tử hiện có; version trần vẫn là pin chính xác. Unit assertion range hiện có được đặt trong `test/`.

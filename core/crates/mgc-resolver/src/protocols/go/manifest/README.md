# Go manifest owner

Owns public go.mod requirement/replacement models and parsing of single-line or block `require`, `replace`, and `exclude` directives.

## Tiếng Việt

Quản lý model công khai và parser directive `require`, `replace`, `exclude` dạng đơn dòng/khối. Directive không thuộc phạm vi tiếp tục được bỏ qua như trước. Các unit assertions parser hiện có nằm trong `test/`; lỗi giữ loại `MgError` cũ.

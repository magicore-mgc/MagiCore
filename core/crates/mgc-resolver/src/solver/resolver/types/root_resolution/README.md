# RootResolution

## Responsibility / Trách nhiệm
Carries the exact package selected for one original root request, including its stable request index and input spec. It distinguishes a direct project selection from transitive instances with the same name and range.

Mang package được chọn chính xác cho một root request ban đầu, gồm index ổn định và spec đầu vào. Type này phân biệt lựa chọn trực tiếp của project với instance transitive trùng tên/range.

## Tests / Kiểm thử
Nearest tests verify the request identity and selected package remain associated. NOT_RUN.

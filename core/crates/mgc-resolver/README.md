# mgc-resolver

PubGrub-based resolution with a batch pipeline (prefetch → queue → resolve) and per-ecosystem protocol engines; provider errors propagate, never silently skipped.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Resolver dựa trên PubGrub với pipeline batch (prefetch → queue → resolve) và các engine protocol ecosystem; lỗi provider được lan truyền, không bỏ qua im lặng. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

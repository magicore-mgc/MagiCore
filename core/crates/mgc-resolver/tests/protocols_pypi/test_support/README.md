# PyPI test support

Owns the localhost-only mock-server preflight and reusable JSON/wheel fixture builders. Helpers are visible only within this integration-test crate.

Sở hữu bước kiểm tra mock-server chỉ chạy localhost và các hàm dựng fixture JSON/wheel dùng chung. Helper chỉ được nhìn thấy trong integration-test crate này.

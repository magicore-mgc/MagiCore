# SRI and native SHA-256 integration suite / Suite SRI và SHA-256 native

Fragments cover full-length canonical SRI, malformed migration input, lossless SHA-256 migration, and native verifier normalization/fail-closed behavior. They are included at the original `v4_sri_digest_shape` target root.

Các fragment bao phủ SRI canonical, migration digest lỗi/chuyển đổi không mất dữ liệu và native verifier. Giữ nguyên target gốc `v4_sri_digest_shape`.

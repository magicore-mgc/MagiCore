# Ownership ledger / Ledger quyền sở hữu

Owns strict deserialization, status validation, `(core, owner, tool)` de-duplication and deterministic projection of the delegation audit ledger into lock metadata.

## Trách nhiệm

Sở hữu deserialize nghiêm ngặt, xác minh status, khử trùng lặp `(core, owner, tool)` và chuyển ledger audit ủy thác thành metadata lock theo thứ tự xác định.

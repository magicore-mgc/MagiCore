# lane_rows_to_v4 / lane_rows_to_v4

Converts one resolved lane without borrowing sibling history. Chuyển một lane đã resolve mà không mượn lịch sử lane khác.

The implementation lives in `lane_rows_to_v4.rs`; `mod.rs` only declares/re-exports the owner and registers its separate tests.

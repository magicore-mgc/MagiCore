# lossy_migration / lossy_migration

Owns the typed refusal when legacy data cannot safely become v4. Sở hữu lỗi từ chối có kiểu khi dữ liệu cũ không thể đổi an toàn sang v4.

The implementation lives in `error.rs`; `mod.rs` only declares/re-exports the owner and registers its separate tests.

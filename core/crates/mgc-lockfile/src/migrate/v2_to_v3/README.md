# v2_to_v3 / v2_to_v3

Upgrades lockfile v2 records and provenance to v3. Nâng record và provenance lockfile v2 lên v3.

The implementation lives in `v2_to_v3.rs`; `mod.rs` only declares/re-exports the owner and registers its separate tests.

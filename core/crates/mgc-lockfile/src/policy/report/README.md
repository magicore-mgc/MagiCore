# V4 verification report / Báo cáo xác minh V4

Owns the public `V4VerifyReport` data contract (`digest_ok`, signature presence/math, optional key ID). It deliberately carries structural facts only; `enforcement/` applies trust policy.

Sở hữu type công khai `V4VerifyReport`; chỉ chứa sự kiện xác minh cấu trúc. `enforcement/` mới áp chính sách tin cậy.

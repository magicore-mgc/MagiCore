# Install integrity / Integrity cài đặt

Owns the SHA-256/SHA-512 SRI format gate and the existing SHA-256 hex/base64 normalization used by native verifiers. It never fabricates a digest; malformed markers remain fail-closed. Actual bytes are still verified by the materializer.

Sở hữu gate SRI SHA-256/SHA-512 và chuẩn hóa SHA-256 hiện có cho native verifier. Không tạo hash; byte tải vẫn do materializer xác minh.

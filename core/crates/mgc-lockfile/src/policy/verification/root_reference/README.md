# Root reference validation / Kiểm tra root reference

Resolves declared root pins, including owner-specific pins, and rejects malformed, missing, empty or ambiguous identities. It does not select a source or alter the lock.

Đối chiếu root pin toàn cục/theo owner; từ chối identity sai, thiếu, rỗng hoặc mơ hồ. Không chọn source thay cho lock.

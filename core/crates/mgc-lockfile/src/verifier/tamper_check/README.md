# Tamper projection / Phép chiếu tamper

Owns the compatibility boolean that projects full verification into `true` only for `VerificationStatus::Tampered`. It does not skip signature, trust, or file checks.

Owner này giữ boolean tương thích, trả `true` chỉ khi verify đầy đủ cho `VerificationStatus::Tampered`. Nó không bỏ qua kiểm tra chữ ký, trust hay file.

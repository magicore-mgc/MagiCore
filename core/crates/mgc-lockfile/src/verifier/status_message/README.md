# Verification status messages / Message trạng thái xác minh

Owns stable end-user strings for every `VerificationStatus` variant. It does not change the status decision or decide whether callers should warn or block.

Owner này giữ chuỗi hiển thị ổn định cho mọi variant `VerificationStatus`. Nó không quyết định status và không quyết định caller nên cảnh báo hay chặn.

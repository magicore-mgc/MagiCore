# Verification status / Trạng thái xác minh

Owns the public `VerificationStatus` enum and its stable variant payloads. This is a data-only owner; behavior contracts are tested by the verifier and status-message owners.

Owner này giữ enum public `VerificationStatus` và payload ổn định của từng variant. Đây là owner dữ liệu; contract behavior được test ở verifier và status-message.

# Lockfile v4 public types

## Responsibility

Owns the public v4 document, metadata, package and signed-payload data types. Compatibility-only wire records remain in their own serde owners.

## Trách nhiệm

Quản lý type công khai cho document v4, metadata, package và payload được ký. Record wire chỉ phục vụ tương thích nằm tại owner serde riêng.

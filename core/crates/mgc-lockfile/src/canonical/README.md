# Canonical v4 lockfile

## Responsibility

Owns the v4 document types, deterministic signed-payload TOML representation, payload digest, custom serde compatibility and document revision validation. `mod.rs` preserves the existing `mgc_lockfile::canonical::*` API.

## Trách nhiệm

Quản lý type tài liệu v4, biểu diễn TOML tất định của payload được ký, digest payload, serde compatibility và kiểm tra revision. `mod.rs` giữ nguyên API `mgc_lockfile::canonical::*` hiện tại.

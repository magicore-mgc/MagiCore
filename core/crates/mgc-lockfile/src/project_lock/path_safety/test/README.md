# Path-safety tests / Test an toàn path

These tests cover missing-path classification, non-directory rejection, and Unix symlink recognition. Parent-swap concurrency remains an explicit gap for a later hardening test/design.

Các test kiểm tra phân loại path không tồn tại, từ chối file thay directory và nhận diện symlink Unix. Race swap parent vẫn là gap cần thiết kế/test hardening riêng sau này.

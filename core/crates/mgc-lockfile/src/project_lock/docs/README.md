# Project-lock tracking / Theo dõi project lock

`ProgressReport.md` records source-static evidence and unresolved security/runtime limits. `Checklist.md` keeps the structural batch separate from post-source executable verification.

`ProgressReport.md` ghi bằng chứng source-static và giới hạn bảo mật/runtime chưa giải quyết. `Checklist.md` tách batch cấu trúc khỏi kiểm chứng thực thi sau source pass.

# v4 graph

## Responsibility

Stable API facade for lossless v4 graph conversion, manifest closure, lock construction and lane merge.

## Trách nhiệm

Façade API ổn định cho chuyển graph v4 lossless, kiểm tra manifest closure, dựng lock và gộp lane.

## Contract

This folder owns only this named operation and its module boundary. Existing crate API and test locations stay stable.

Folder này chỉ sở hữu operation có tên và ranh giới module tương ứng. API crate và vị trí test hiện có được giữ nguyên.

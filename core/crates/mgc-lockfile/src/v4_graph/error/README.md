# error

## Responsibility

Maps graph refusal reasons into the existing shared lockfile error contract; this owner adds no new public error variant.

## Trách nhiệm

Ánh xạ lý do từ chối graph sang error contract chung hiện có; owner này không thêm variant public mới.

## Contract

This folder owns only this named operation and its module boundary. Existing crate API and test locations stay stable.

Folder này chỉ sở hữu operation có tên và ranh giới module tương ứng. API crate và vị trí test hiện có được giữ nguyên.

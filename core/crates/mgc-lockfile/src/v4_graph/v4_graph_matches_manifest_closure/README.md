# v4_graph_matches_manifest_closure

## Responsibility

Checks explicit or manifest-derived roots, version ranges, selected ecosystems and orphan-free graph reachability before lock replay.

## Trách nhiệm

Kiểm root tường minh hoặc từ manifest, range version, ecosystem được chọn và graph không có package mồ côi trước khi replay lock.

## Contract

This folder owns only this named operation and its module boundary. Existing crate API and test locations stay stable.

Folder này chỉ sở hữu operation có tên và ranh giới module tương ứng. API crate và vị trí test hiện có được giữ nguyên.

# V4 lane merge base

## Purpose

Owns splitting a root pin (`mgc-root-v1:<...>` or `name@version`) and filtering V4 base packages down to rows that are not this lane's own, returning `None` when the base document is unusable.

## Vietnamese

Sở hữu việc tách root pin (`mgc-root-v1:<...>` hoặc `name@version`) và lọc package base V4 còn các row không thuộc lane này, trả `None` khi tài liệu base không dùng được.

# merge_v4_lane_packages

## Responsibility

Replaces one owner/ecosystem lane, preserves sibling rows, merges sources and roots, and prunes unreachable package and peer records.

## Trách nhiệm

Thay dữ liệu của một owner/ecosystem, giữ lane sibling, gộp source/root và dọn package/peer không còn reachable.

## Contract

This folder owns only this named operation and its module boundary. Existing crate API and test locations stay stable.

Folder này chỉ sở hữu operation có tên và ranh giới module tương ứng. API crate và vị trí test hiện có được giữ nguyên.

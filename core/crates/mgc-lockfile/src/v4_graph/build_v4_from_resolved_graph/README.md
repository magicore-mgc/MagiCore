# build_v4_from_resolved_graph

## Responsibility

Builds the canonical v4 document, registry source, root table, artifact records and peer-context digest table from a resolved graph.

## Trách nhiệm

Dựng lock v4 canonical gồm registry source, root ownership, artifact và bảng digest peer từ graph đã resolve.

## Contract

This folder owns only this named operation and its module boundary. Existing crate API and test locations stay stable.

Folder này chỉ sở hữu operation có tên và ranh giới module tương ứng. API crate và vị trí test hiện có được giữ nguyên.

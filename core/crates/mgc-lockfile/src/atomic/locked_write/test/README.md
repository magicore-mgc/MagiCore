# Locked-write tests / Test ghi có lock

The focused test pins source retention and the unchanged public error category/message. Crash order, contention, stale cleanup and old-or-new document recovery remain in the existing integration test target.

Test tập trung ghim source và category/message công khai không đổi. Thứ tự crash, tranh lock, dọn temp cũ và phục hồi document cũ-hoặc-mới vẫn thuộc integration test hiện tại.

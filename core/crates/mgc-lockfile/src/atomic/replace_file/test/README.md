# Replacement tests / Test thay file

This platform-neutral contract checks that replacement publishes the staging bytes and consumes the staging entry. Long-path and platform-specific error cases are kept with their OS owner.

Contract dùng chung kiểm tra byte staging được publish và entry staging bị tiêu thụ. Case đường dẫn dài và lỗi riêng platform nằm tại owner hệ điều hành.

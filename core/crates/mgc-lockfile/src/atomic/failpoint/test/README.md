# Failpoint tests / Test failpoint

Tests pin the public crash-phase names and order without mutating shared environment variables. Process-parking and SIGKILL behavior remain covered by the existing integration harness.

Test ghim tên và thứ tự phase công khai mà không sửa biến môi trường dùng chung. Hành vi dừng process và SIGKILL vẫn do integration harness hiện có kiểm tra.

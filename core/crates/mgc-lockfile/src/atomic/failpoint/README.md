# Failpoint / Điểm dừng crash

This owner provides the stable ordered phase list and environment-driven park hook used by lock-writer crash tests. It does not write lock data or interpret recovery state.

Owner này cung cấp danh sách phase ổn định và hook dừng theo biến môi trường cho test crash của lock writer. Module không tự ghi dữ liệu lock hay diễn giải trạng thái phục hồi.

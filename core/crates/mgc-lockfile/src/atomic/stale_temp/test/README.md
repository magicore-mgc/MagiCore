# Stale-temp tests / Test temp cũ

These focused tests cover generated-name shape and fail-closed pid parsing. Filesystem age, process death, and cleanup-under-lock are covered by the existing integration tests.

Các test này kiểm tra hình dạng tên sinh ra và parse pid theo hướng fail-closed. Tuổi file, process chết và cleanup khi có lock được kiểm tra trong integration tests hiện có.

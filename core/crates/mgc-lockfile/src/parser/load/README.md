# Lockfile loading / Nạp lockfile

Owns bounded path-to-document loading, the lossless-v4 versus legacy-model boundary, and the actionable v3-on-v4 guard. `LockLoadError` maps to the same public parse errors.

Owner này nạp document từ path có giới hạn, giữ ranh giới giữa v4 lossless và model legacy, cùng guard v3 gặp v4 có hướng xử lý. `LockLoadError` ánh xạ về ParseError public như cũ.

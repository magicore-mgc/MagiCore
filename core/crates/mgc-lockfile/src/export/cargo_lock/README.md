# # Cargo.lock exporter

## Purpose

Owns the Cargo.lock skeleton: TOML header, `version = 4`, one `[[package]]` per Rust entry with optional Cargo source URL mapping.

## Vietnamese

Sở hữu skeleton Cargo.lock: header TOML, `version = 4`, một `[[package]]` mỗi entry Rust kèm mapping source URL Cargo tuỳ chọn.

# Yarn lockfile parser

Parses the classic Yarn v1 text format and deliberately rejects Berry metadata instead of guessing.

Parse định dạng text Yarn v1 cổ điển và chủ động từ chối metadata Berry thay vì đoán.

The accepted shape, unsupported-format diagnostic and output fields remain owned by this parser.

Parser này sở hữu cấu trúc được chấp nhận, thông báo format không hỗ trợ và các field output.

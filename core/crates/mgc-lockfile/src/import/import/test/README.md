# Import coordinator tests / Test điều phối import

These source tests verify that imported pins retain the real input lockfile name and that the resulting source identity is accepted after an adapter classifies the ecosystem. They are authored but NOT_RUN until the source pass closes.

Các test kiểm tra pin nhập giữ đúng tên lockfile đầu vào và source identity được chấp nhận sau khi adapter phân loại ecosystem. Test đã viết nhưng NOT_RUN tới khi đóng source pass.

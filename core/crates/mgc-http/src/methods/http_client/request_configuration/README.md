# Request configuration owner

EN: Stores auth, retry, rate-limit, and cache configuration on HttpClient. The cache setter only stores the current HttpCache value; request execution does not consume it yet.

VI: Lưu cấu hình auth, retry, rate-limit và cache trên HttpClient. Hàm cache hiện chỉ lưu HttpCache; luồng request chưa sử dụng giá trị này.

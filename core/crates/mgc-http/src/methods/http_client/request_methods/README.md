# HTTP request methods owner

EN: Owns the public GET, PUT, POST, PATCH, and DELETE conveniences, including per-request timeout and headers. Pure request-building tests inspect the method and URL without sending traffic.

VI: Sở hữu các hàm GET, PUT, POST, PATCH, DELETE công khai, gồm timeout và header riêng từng request. Test dựng request kiểm tra method/URL mà không gửi traffic.

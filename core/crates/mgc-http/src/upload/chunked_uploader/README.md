# ChunkedUploader / Bộ upload theo chunk

Owns shared uploader configuration and the focused start, chunk, finalize and file-upload operations. The public type remains available at mgc_http::upload::ChunkedUploader.

Quản lý cấu hình uploader chung và các thao tác start, chunk, finalize, upload file. Type công khai giữ tại mgc_http::upload::ChunkedUploader.

Each operation has a same-name folder, local errors, README and nearest test. Runtime validation remains deferred.

Mỗi thao tác có folder cùng tên, lỗi local, README và test gần nhất. Runtime validation đang chờ giai đoạn test sau.

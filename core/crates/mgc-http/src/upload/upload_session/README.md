# UploadSession / DTO phiên upload

Owns the public OCI upload-session data type and its serde field contract. The DTO is exported as mgc_http::upload::UploadSession.

Quản lý kiểu dữ liệu phiên upload OCI và hợp đồng field serde. DTO được export qua mgc_http::upload::UploadSession.

This DTO is not currently wired into the file-upload resume flow; the source behavior is recorded in the parent upload report.

DTO hiện chưa được nối vào luồng resume upload file; trạng thái source được ghi ở báo cáo owner cha.

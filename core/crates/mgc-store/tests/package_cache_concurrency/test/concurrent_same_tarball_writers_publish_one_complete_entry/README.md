# Concurrent tarball writers / Writer tarball đồng thời

This owner verifies that simultaneous writers publish one complete cache entry and leave no staging files. The test body is included into the integration target root to preserve the existing harness name.

Owner này kiểm tra nhiều writer đồng thời chỉ publish một cache entry hoàn chỉnh và không để file staging. Thân test được include vào root integration target để giữ nguyên tên harness cũ.

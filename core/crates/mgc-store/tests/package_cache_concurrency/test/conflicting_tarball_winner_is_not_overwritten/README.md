# Conflicting tarball winner / Winner tarball xung đột

This owner verifies that a different payload for an existing package ID fails closed and leaves the original bytes unchanged. The test body is included into the integration target root to preserve the existing harness name.

Owner này kiểm tra payload khác cho package ID đã có bị từ chối và byte ban đầu không đổi. Thân test được include vào root integration target để giữ nguyên tên harness cũ.

# Package cache path tests / Test đường dẫn package cache

This folder wires focused cache-path tests into the stable Cargo target root. Each behavior owner defines one test with a matching implementation filename and README.

Folder này wiring các test path cache tập trung vào root Cargo target ổn định. Mỗi behavior owner định nghĩa một test, có file implementation cùng tên và README.

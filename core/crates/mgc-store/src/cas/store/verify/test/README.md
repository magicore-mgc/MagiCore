# Verification Tests

**Purpose:** Test public streamed verification and path rejection at the verify owner.

**Mục đích:** Kiểm thử xác minh streaming public và từ chối path tại owner verify.

These tests are registered by `verify.rs`. They are authored but have not been run while the repository follows source-first refactoring.

Các test được đăng ký từ `verify.rs`. Test đã được viết nhưng chưa chạy trong giai đoạn refactor source trước.

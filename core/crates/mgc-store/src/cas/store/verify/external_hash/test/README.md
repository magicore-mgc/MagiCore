# External Hash Tests

**Purpose:** Check acceptance of a full hexadecimal digest and rejection of malformed input.

**Mục đích:** Kiểm tra chấp nhận digest hex đầy đủ và từ chối input sai.

The tests do not call a registry or network service. They have not been run.

Test không gọi registry hay dịch vụ mạng. Chưa chạy test.

# Membership Tests

**Purpose:** Check the observable presence/removal lifecycle for a stored blob.

**Mục đích:** Kiểm tra vòng đời tồn tại/xóa quan sát được của blob đã lưu.

The test uses only the public store operations and remains NOT_RUN until repository source refactoring closes.

Test dùng các thao tác store public và vẫn NOT_RUN cho đến khi hoàn tất refactor source toàn repo.

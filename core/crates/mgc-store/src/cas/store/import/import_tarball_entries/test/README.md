# Tarball import tests

Checks that the coordinator returns the CAS address containing each entry's exact bytes. Atomic race handling and tampered dedup remain covered by the frozen adversarial integration suite.

Kiểm tra coordinator trả địa chỉ CAS chứa đúng byte của từng entry. Xử lý race nguyên tử và dedup bị sửa vẫn do integration adversarial đóng băng bao phủ.

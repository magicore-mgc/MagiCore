# Byte import tests

Checks that executable mode participates in the content address for identical bytes. Batch durability, declared-hash rejection, and concurrent dedup remain covered by the frozen integration suite.

Kiểm tra executable mode có tham gia địa chỉ nội dung khi byte giống nhau. Durability batch, từ chối hash khai sai và dedup đồng thời vẫn do integration suite đóng băng bao phủ.

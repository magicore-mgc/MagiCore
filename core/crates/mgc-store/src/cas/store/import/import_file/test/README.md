# File import tests

Covers the regular-file public path and verifies bytes at the resulting CAS address. Symlink and durability behavior remain covered by frozen crate-level security tests.

Bao phủ đường public import file thường và xác nhận byte tại địa chỉ CAS kết quả. Symlink và durability vẫn do security test cấp crate đã đóng băng bao phủ.

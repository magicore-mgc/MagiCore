# CAS ContentStore

**Purpose:** Shared immutable content-addressed storage, with separate owners for errors/types, import, verification/memo and export/staging.

**Mục đích:** Kho CAS bất biến dùng chung, tách owner cho lỗi/type, import, verify/memo và export/staging.

The public CAS facade stays stable. Existing integration tests remain in place for the later test-organization and verification pass.

Facade CAS public được giữ ổn định. Integration test hiện tại giữ nguyên để xử lý ở pass tổ chức test và verify sau.

# tarball_entry

Owns the public data-only item used by CAS tarball imports. It has no validation or methods of its own, so this owner does not add a hollow unit-test folder; import and concurrency integration cases exercise its actual use.

# tarball_entry — trách nhiệm

Sở hữu item dữ liệu công khai dùng trong import tarball vào CAS. DTO không có validation hay method riêng nên owner không tạo thư mục unit-test rỗng; integration test import và concurrency kiểm tra cách dùng thật.

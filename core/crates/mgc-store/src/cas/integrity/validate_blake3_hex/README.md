# validate_blake3_hex

Validates the accepted foreign BLAKE3 representation: exactly 64 lowercase ASCII hexadecimal characters. `error.rs` owns the typed invalid-input contract used by both the validator and `IntegrityHash` constructors.

# validate_blake3_hex — trách nhiệm

Kiểm tra biểu diễn BLAKE3 ngoài được chấp nhận: đúng 64 ký tự hexadecimal ASCII viết thường. `error.rs` sở hữu hợp đồng lỗi typed dùng bởi validator và constructor `IntegrityHash`.

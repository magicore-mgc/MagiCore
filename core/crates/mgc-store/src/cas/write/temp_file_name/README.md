# Temporary filename / Tên file tạm

Owns the single strict parser for MagiCore temporary names and the CAS sweep eligibility rule. `tests/temp_name.rs` remains the registered integration contract for public exports.

Owner này giữ parser nghiêm ngặt duy nhất cho tên temp MagiCore và quy tắc đủ điều kiện GC CAS. `tests/temp_name.rs` tiếp tục là integration contract đã đăng ký cho public exports.

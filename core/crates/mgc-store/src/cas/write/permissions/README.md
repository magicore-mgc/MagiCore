# CAS blob permissions / Permission blob CAS

Owns the existing owner-only Unix modes (`0600`/`0700`) and current non-Unix behavior. It returns the shared store I/O error through the CAS write error mapper.

Owner này giữ mode Unix chỉ-owner hiện tại (`0600`/`0700`) và behavior non-Unix. Lỗi được ánh xạ sang kiểu I/O dùng chung qua error mapper của CAS write.

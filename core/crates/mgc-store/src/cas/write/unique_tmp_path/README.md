# Unique temporary path / Đường dẫn tạm duy nhất

Owns the deterministic shape and collision-reduction inputs for CAS staging paths. Callers still create files atomically and own cleanup/publication.

Owner này quản lý hình dạng tên và các đầu vào giảm va chạm cho path staging CAS. Caller vẫn chịu trách nhiệm tạo file nguyên tử, dọn dẹp và publish.

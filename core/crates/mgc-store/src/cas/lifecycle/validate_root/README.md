# CAS root validation / Kiểm tra root CAS

Owns validation of the root path itself, the Unix current-UID ownership gate, and the small UID syscall helper. Ancestor traversal has its own owner.

Quản lý validate chính đường dẫn root, cổng ownership theo UID trên Unix và helper syscall lấy UID. Việc duyệt ancestor thuộc owner riêng.

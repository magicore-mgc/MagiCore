# Covered staging leases

Owns the query that selects staging claims fully protected by a promoted generation.

## Trách nhiệm

Quản lý truy vấn chọn staging claim đã được promoted generation bảo vệ đầy đủ.

Keep the result columns/order and correlated coverage predicates exact. The database lease owner wires this method into the unchanged public API.

Giữ nguyên các cột/thứ tự kết quả và predicate coverage liên kết. Owner database wiring method này vào public API không đổi.

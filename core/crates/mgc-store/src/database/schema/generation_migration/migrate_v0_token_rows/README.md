# Migrate V0 Token Rows

Owns the `migrate_v0_token_rows` step of the legacy token-schema migration.

## Trách nhiệm

Quản lý bước `migrate_v0_token_rows` trong quá trình migrate schema token cũ.

Keep the same transaction, query order, SQL/DDL text, error propagation, and caller sequence.

Giữ nguyên transaction, thứ tự truy vấn, SQL/DDL, truyền lỗi và thứ tự caller.

# Create V2 Token Tables

Owns the `create_v2_token_tables` step of the legacy token-schema migration.

## Trách nhiệm

Quản lý bước `create_v2_token_tables` trong quá trình migrate schema token cũ.

Keep the same transaction, query order, SQL/DDL text, error propagation, and caller sequence.

Giữ nguyên transaction, thứ tự truy vấn, SQL/DDL, truyền lỗi và thứ tự caller.

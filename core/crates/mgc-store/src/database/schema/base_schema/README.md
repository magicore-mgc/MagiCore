# Base schema

Creates the initial SQLite tables inside the open schema transaction. This owner contains DDL only; migration ordering stays in `schema::open`.

## Lược đồ cơ sở

Tạo các bảng SQLite ban đầu bên trong transaction schema đang mở. Owner này chỉ giữ DDL; thứ tự migration do `schema::open` điều phối.

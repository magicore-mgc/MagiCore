# Package-file upsert / Upsert file package

Keeps one package's file listing in SQLite and the rebuildable MessagePack layer, preserving the current database-first mutation and subsequent full-index persistence order.

Đồng bộ danh sách file một package vào SQLite và lớp MessagePack có thể dựng lại; giữ thứ tự cập nhật database trước rồi lưu toàn index như hiện tại.

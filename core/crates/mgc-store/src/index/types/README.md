# Index types / Kiểu dữ liệu chỉ mục

Defines the public per-file record and the private MessagePack wire records. Keep serialized field names and derives stable unless the cache format is deliberately versioned.

Định nghĩa record file công khai và các wire record MessagePack riêng. Giữ ổn định tên field/derive đã serialize, trừ khi chủ động tăng version format cache.

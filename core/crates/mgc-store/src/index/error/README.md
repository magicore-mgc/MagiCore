# Index errors / Lỗi chỉ mục

Holds domain errors that need an explicit fail-closed diagnostic at the index boundary. Public methods keep their existing `anyhow::Result` signatures.

Chứa lỗi nghiệp vụ cần diagnostic fail-closed tường minh tại biên chỉ mục. Method công khai giữ nguyên chữ ký `anyhow::Result`.

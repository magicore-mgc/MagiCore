# mgc-exec

Passthrough execution behind an allowlist with a secret-sanitizing exec audit; forbidden process shapes are matched and blocked.

See [`docs/README.md`](docs/README.md) for the module guide, source map, handoff boundaries and verification steps.

## Bản tiếng Việt

Thực thi passthrough sau allowlist kèm exec audit đã lọc bí mật; hình dạng tiến trình bị cấm được khớp và chặn. Xem [`docs/README.md`](docs/README.md) để có hướng dẫn module, bản đồ mã nguồn, ranh giới bàn giao và các bước kiểm chứng.

# Audit writer

Owns the public audit module facade and separates JSONL persistence from the entry schema and event-specific record builders. All records share one in-process serialized append boundary.

# Audit writer — tiếng Việt

Sở hữu facade module audit công khai và tách lưu JSONL khỏi schema entry cùng các builder sự kiện. Mọi bản ghi dùng chung một ranh giới append tuần tự trong process.

# Signed policy manifest owners

This module provides signed, exact read-only exception data. Canonical bytes, key identity, verification, lookup and rotation selection have distinct owners. The parent module preserves the public policy_manifest API.

# Owner manifest policy có ký — tiếng Việt

Module này cung cấp dữ liệu exception chỉ đọc, chính xác và có ký. Canonical bytes, key identity, verification, lookup và rotation selection có owner riêng. Module cha giữ API policy_manifest công khai.

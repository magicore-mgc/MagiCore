Constrained recognition of Rust compiler and rustdoc child invocations. The `mod.rs` file exports recognition helpers; `rustc_child.rs` parses argv; `test/` tests accepted and rejected forms.

Folder này nhận diện có giới hạn invocation con của rustc/rustdoc. `mod.rs` export helper; `rustc_child.rs` parse argv; `test/` kiểm tra dạng được nhận và bị từ chối.

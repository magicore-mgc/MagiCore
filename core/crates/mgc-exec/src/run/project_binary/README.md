Project-binary execution owner for captured, inherited and cancellable stdio. `mod.rs` exports the stable entry points; `project_binary.rs` canonicalizes the concrete file, preserves MGC self-answer and package/dependency/script guards, applies device/runtime scope denies to the root executable, then hands execution to the shared spawn pipeline. The package binary intentionally bypasses the static host-tool allowlist. `ExecOptions` controls environment, cwd, timeout and optional audit; this API does not guarantee these options were configured and does not sandbox the child. This root check does not prevent an allowed script/runtime from spawning a protected descendant; the process-tree policy currently watches package-manager descendants, and broader scope inheritance remains separate work. Tests in `test/` cover path contracts and root denial before spawn. Caller-supplied binary paths remain explicit; this module does not resolve package names or search caches.

Folder này sở hữu luồng chạy binary project với capture, stdio kế thừa và hủy theo supervisor. `mod.rs` export các entry point ổn định; `project_binary.rs` canonicalize file cụ thể, giữ MGC self-answer và guard package/dependency/script, áp deny device/runtime theo scope cho executable gốc rồi chuyển vào spawn pipeline dùng chung. Binary package được miễn allowlist tĩnh của tool host theo chủ đích. `ExecOptions` quyết định env, cwd, timeout và audit tùy chọn; API không đảm bảo caller đã cấu hình các tùy chọn đó và cũng không sandbox process con. Gate này không chặn runtime/script được phép spawn descendant nhạy cảm; process-tree policy hiện theo dõi package-manager descendant, enforcement kế thừa scope rộng hơn là phần việc riêng. Test trong `test/` bao phủ path contract và chặn executable gốc trước spawn. Caller vẫn phải đưa path binary cụ thể; module này không tự resolve tên package hay tìm cache.

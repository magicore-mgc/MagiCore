Timeout configuration owner. `mod.rs` exposes the resolver; `timeout.rs` selects explicit, disabled, or environment-configured timeouts; `error.rs` classifies invalid values without echoing them; `test/` covers parsing, precedence and diagnostic safety; `docs/` tracks owner work.

Owner cấu hình timeout. `mod.rs` export bộ phân giải; `timeout.rs` chọn timeout tường minh, tắt hoặc lấy từ môi trường; `error.rs` phân loại giá trị sai mà không in lại giá trị; `test/` kiểm tra phân tích, thứ tự ưu tiên và an toàn chẩn đoán; `docs/` theo dõi công việc.

Project-bound argument validation and typed local errors. The `mod.rs` file exports the validator; `validation.rs` implements checks and owns `error.rs`; `test/` verifies rejection boundaries.

Folder này xác thực argument trong ranh giới project và sở hữu lỗi typed. `mod.rs` export validator; `validation.rs` triển khai kiểm tra và dùng `error.rs`; `test/` kiểm tra biên từ chối.

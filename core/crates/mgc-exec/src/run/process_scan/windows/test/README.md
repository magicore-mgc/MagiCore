Registers the Windows feature tests from their nearest behavior owner. PID ancestry tests live under `ancestry/test/`; retry and native snapshot tests live under their matching owner; only cases that compose several owners stay under `integration/`. All nine test items are preserved byte-for-byte and remain NOT_RUN.

Đăng ký test feature Windows từ owner hành vi gần nhất. Test ancestry PID nằm trong `ancestry/test/`; test retry và snapshot native nằm cùng owner; chỉ case phối hợp nhiều owner mới ở `integration/`. Cả chín test item được giữ nguyên từng byte và vẫn NOT_RUN.

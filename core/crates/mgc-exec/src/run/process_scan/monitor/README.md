# Unix process monitor

EN: This owner preserves the supervision entry point and its typed root-visibility error. The effective root `ExecutionScope` flows through active, pre-exit, post-exit and termination scans; `adb`/`xcrun` descendants are rejected outside DeviceControl, except exact read-only Swift SDK metadata (`--show-sdk-path`/`--show-sdk-platform-path`), `--find`/`-f` tool-path, and Swift/`vtool` build-info queries in build, test, or dev-server scopes. The implementation lives under `monitor/`: `monitor.rs` coordinates the scan, while named child owners handle process snapshots, identity, group liveness, root-exit recovery, descendant refresh, Go environment checks, policy selection and npm blocker-shim authentication. Linux/macOS snapshot acquisition remains in their OS adapters. Nearest tests are grouped under `test/`; `docs/` tracks this owner.

VI: Owner này giữ nguyên entry point cho supervision và lỗi root-visibility có kiểu. `ExecutionScope` hiệu lực của root đi xuyên qua lượt scan đang chạy, trước/sau khi root thoát và termination; descendant `adb`/`xcrun` bị từ chối ngoài DeviceControl, ngoại trừ các truy vấn SDK, `--find`/`-f` tool-path và build-info Swift/`vtool` chỉ đọc chính xác trong scope build, test hoặc dev-server. Implementation nằm trong `monitor/`: `monitor.rs` điều phối scan; các owner con xử lý snapshot, identity, group liveness, khôi phục sau khi root thoát, refresh descendant, kiểm tra environment Go, chọn policy và xác thực npm blocker-shim. Việc lấy snapshot Linux/macOS vẫn ở adapter OS tương ứng. Test gần source được nhóm trong `test/`; `docs/` theo dõi owner.

The npm `--version` exception authenticates MagiCore's own generated deny shim by exact file bytes, non-writable metadata and accepted shell argv forms. It is not framework-version detection or a general npm exemption.

Ngoại lệ npm `--version` xác thực deny shim do MagiCore tạo bằng byte file chính xác, metadata không cho ghi và dạng argv shell được phép. Đây không phải phát hiện phiên bản framework hay miễn trừ npm nói chung.

# Spawn documentation / Tài liệu spawn

This folder tracks the shared spawn pipeline's focused work and evidence. It does not duplicate runtime policy; `spawn.rs`, `error.rs`, and the registered local tests remain authoritative.

Folder này theo dõi công việc và bằng chứng của pipeline spawn dùng chung. Không lặp policy runtime; `spawn.rs`, `error.rs` và các test local đã đăng ký mới là nguồn thực thi.

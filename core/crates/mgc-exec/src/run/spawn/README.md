The shared child-process spawn pipeline. `mod.rs` exports the stable entry point; `spawn.rs` wraps execution with deferred Windows handle-cleanup draining and coordinates the prepared invocation; `preflight/` owns argument validation, timeout/cwd preparation, compat-scope audit and dry-run reports; `command_builder/` constructs platform commands without launching them; `command_environment/` applies explicit environment values and the existing guarded PATH to a constructed command; `report/` owns output projection and exit policy; `cleanup/` combines execution with guarded-PATH/Windows-handle cleanup results; `error.rs` classifies setup, spawn and cleanup failures; `test/` covers pipeline behavior; `docs/` tracks this owner.

Folder này sở hữu pipeline spawn process con dùng chung. `mod.rs` export entry point ổn định; `spawn.rs` bọc execution để drain lỗi cleanup handle Windows và điều phối invocation đã chuẩn bị; `preflight/` sở hữu xác thực đối số, chuẩn bị timeout/cwd, audit compat và report dry-run; `command_builder/` dựng command theo OS nhưng không launch; `command_environment/` áp env explicit và guarded PATH hiện có lên command đã dựng; `report/` sở hữu output projection và exit policy; `cleanup/` ghép kết quả execution với lỗi cleanup guarded PATH/Windows handle; `error.rs` phân loại lỗi setup, spawn và cleanup tại owner; `test/` kiểm tra pipeline; `docs/` theo dõi owner.

# Child command environment

This owner applies the existing `ExecOptions` environment to a constructed child `Command`. It first inherits the caller process environment so applications keep their own `PORT`, `NODE_ENV`, `DATABASE_URL`, and API keys, then layers explicit `ExecOptions` values on top (an explicit assignment replaces the inherited copy) and places MagiCore deny shims before the selected caller PATH. `clean_env` no longer strips the caller environment; it keeps only the executor-owned variables plus the non-Unix critical variables. It does not create the shadow directory, inspect processes, spawn a child, or own PATH/error policy; `run/environment/` remains the source for guarded PATH composition and `EnvironmentError`.

Owner này áp environment từ `ExecOptions` lên child `Command` đã dựng. Nó kế thừa environment process caller trước để ứng dụng giữ `PORT`, `NODE_ENV`, `DATABASE_URL` và API key của mình, rồi xếp giá trị explicit của `ExecOptions` lên trên (gán explicit thay thế bản kế thừa) và đặt MagiCore deny shim trước PATH caller được chọn. `clean_env` không còn xóa environment caller; nó chỉ giữ biến do executor sở hữu cùng các biến critical non-Unix. Owner không tạo shadow directory, scan process hoặc spawn child; cũng không sở hữu policy ghép PATH/lỗi. Nguồn chuẩn của guarded PATH và `EnvironmentError` vẫn là `run/environment/`.

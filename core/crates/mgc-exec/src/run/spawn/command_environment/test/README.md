# Child command environment tests

These nearest-owner cases inspect the environment pairs configured on `std::process::Command` for inherited and clean modes. They use an inert placeholder program and never spawn it. Tests are authored but NOT_RUN until the source refactor is complete and the machine Data volume is under the user limit.

Các test gần owner kiểm tra các cặp environment được cấu hình vào `std::process::Command` ở chế độ kế thừa và clean. Chúng dùng tên chương trình placeholder, không launch. Test đã viết nhưng NOT_RUN tới khi refactor source hoàn tất và Data đạt giới hạn user đặt ra.

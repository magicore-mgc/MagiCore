Public execution request and report data types. The `mod.rs` file exports the stable API; `types.rs` defines the types; `test/` verifies their defaults and contract.

Folder này sở hữu kiểu request/report public của lệnh chạy. `mod.rs` export API ổn định; `types.rs` định nghĩa kiểu; `test/` kiểm tra default và hợp đồng.

# Windows executable identity owner

EN: Owns the process executable SHA-256 cache and bounded streaming hash used by Windows verification. Hashing stays fixed-buffer and uses the existing typed error variants. This owner is compiled only for Windows; it does not add Unix verification behavior.

VI: Sở hữu cache SHA-256 executable của process và băm streaming có giới hạn dùng khi xác minh Windows. Bộ đệm giữ cố định và dùng các variant lỗi typed hiện tại. Owner chỉ build trên Windows, không bổ sung hành vi xác minh Unix.

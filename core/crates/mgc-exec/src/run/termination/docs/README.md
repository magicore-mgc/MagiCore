# Termination documentation / Tài liệu termination

This folder tracks owner-local review and verification for Unix process-group termination. It records only evidence that has actually been observed; source structure does not imply a passing native process test.

Folder này theo dõi review và xác minh cục bộ của owner dừng process group Unix. Chỉ ghi bằng chứng đã quan sát; cấu trúc source không đồng nghĩa test process native đã pass.

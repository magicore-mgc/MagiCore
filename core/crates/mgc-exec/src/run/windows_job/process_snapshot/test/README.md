# Process-snapshot tests

Windows-gated tests cover a real empty Job Object and ensure the PID query returns an empty stable snapshot. Dynamic fan-out and capacity-limit behavior still require Windows stress coverage.

Test Windows dùng Job Object rỗng thật và xác minh truy vấn PID trả snapshot rỗng ổn định. Fan-out động và giới hạn capacity vẫn cần stress test Windows.

# Policy metadata tests

Each policy/classification behavior has a separate nearest-owner test file. The parent inspection test facade includes existing and new scope-policy cases; the DeviceControl regression is source-authored but not run in the source-first phase.

# Test metadata policy

Mỗi behavior policy/phân loại có file test gần owner riêng. Facade test inspection include test hiện có và case scope mới; regression DeviceControl mới được viết nhưng chưa chạy trong phase source-first.

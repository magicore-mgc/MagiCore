# Policy metadata owner

Owns process evidence classification, compatibility-audit invocation, fail-closed command-line reporting, npm shim authentication, Go environment policy, and the root-scope check for `adb`/`xcrun` Job descendants. It consumes only snapshots and metadata observed for confirmed Job members. Existing policy tests live in test/.

# Owner metadata policy

Sở hữu phân loại bằng chứng process, gọi compatibility audit, báo fail-closed khi thiếu command line, xác thực npm shim, policy môi trường Go và kiểm tra scope root cho descendant `adb`/`xcrun` thuộc Job. Chỉ dùng snapshot/metadata quan sát từ member Job đã xác nhận. Test policy hiện có ở test/.

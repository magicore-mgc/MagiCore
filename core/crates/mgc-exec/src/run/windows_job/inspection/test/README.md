# Inspection test facade

The facade includes unchanged test items from subject owner folders into the original inspection test-module scope. Each source file contains one existing test. Error tests remain registered by the error owner.

# Facade test inspection

Facade include test không đổi từ folder owner theo subject vào scope module test inspection ban đầu. Mỗi file source chứa một test hiện có. Test lỗi tiếp tục do owner error đăng ký.

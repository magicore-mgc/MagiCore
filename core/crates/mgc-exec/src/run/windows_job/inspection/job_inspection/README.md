# Native Job inspection owner

Owns the Windows-only process-table refresh, executable path and confirmed child-environment observation, and the existing member-inspection entry point. It delegates capture and policy classification to their owners. Windows cfg gates stay local to this module.

# Owner kiểm tra Job native

Sở hữu refresh process table chỉ dành cho Windows, quan sát executable path và môi trường child đã xác nhận, cùng entry point kiểm tra member hiện có. Module giao capture và phân loại policy cho owner tương ứng. Cfg Windows nằm tại module này.

# Scan result owner

Owns active-descendant evaluation, conversion of private inspection evidence to WindowsProcessScan, and the existing Windows retry/timeout entry point. It does not change the shared process-scan API or retry policy. The nearest existing behavior test lives in test/.

# Owner kết quả scan

Sở hữu đánh giá descendant còn hoạt động, chuyển bằng chứng inspection nội bộ thành WindowsProcessScan, và entry point retry/timeout Windows hiện có. Không thay API process-scan dùng chung hay retry policy. Test hành vi gần owner nằm trong test/.

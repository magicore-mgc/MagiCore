Windows Job Object lifecycle, membership inspection and owned native handles. `mod.rs` exports the guard, inspection path, root-exit cleanup and deferred-error boundary. `windows_job.rs` only wires behavior owners and provides non-Windows stubs. `owned_handle/` owns RAII handles and process identity queries; `deferred_handle_close/` captures bounded per-thread close errors; `job_lifecycle/` creates/configures/assigns/terminates the kill-on-close Job; `primary_thread/` resumes the suspended child only after assignment; `process_snapshot/` performs bounded PID enumeration; `member_capture/` verifies membership and pins process identity. Existing `inspection/` and `root_exit/` owners remain separate; `error.rs` owns typed native failures.

Folder này sở hữu vòng đời Job Object Windows, kiểm tra membership và native handle. `mod.rs` export guard, inspection, cleanup root-exit và deferred-error boundary. `windows_job.rs` chỉ nối các owner và cung cấp stub ngoài Windows. `owned_handle/` giữ RAII handle và truy vấn danh tính process; `deferred_handle_close/` ghi lỗi đóng có giới hạn theo thread; `job_lifecycle/` tạo/cấu hình/gắn/terminate Job kill-on-close; `primary_thread/` chỉ resume child sau khi đã gắn Job; `process_snapshot/` liệt kê PID có giới hạn; `member_capture/` xác minh membership và giữ danh tính process. `inspection/` và `root_exit/` giữ owner riêng; `error.rs` giữ lỗi native typed.

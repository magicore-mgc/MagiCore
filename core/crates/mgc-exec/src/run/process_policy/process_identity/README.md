# Process identity

This owner normalizes executable basenames across path separators and common executable suffixes. It also recognizes only the exact read-only shell probe used for the npm version check. The npm child still passes through the authenticated process policy.

## Identity process

Owner này chuẩn hóa basename executable qua dấu phân cách path và các hậu tố executable phổ biến. Nó chỉ nhận đúng shell probe đọc version npm cụ thể; process npm con vẫn phải qua policy xác thực.

# Process-policy tests

This directory contains matcher contracts that span runtime entrypoints, dependency-resolution policy, and required child metadata. Diagnostic-shape and script-shebang cases live beside their dedicated owners; typed error contracts remain beside `error.rs`. Existing test bodies are relocated, not executed.

## Test process-policy

Folder chứa contract matcher đi qua entrypoint runtime, policy dependency-resolution và metadata child bắt buộc. Case diagnostic-shape và shebang nằm cạnh owner tương ứng; contract lỗi typed vẫn cạnh `error.rs`. Các test hiện có chỉ được chuyển vị trí, chưa chạy.

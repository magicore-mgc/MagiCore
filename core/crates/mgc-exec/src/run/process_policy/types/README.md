# ForbiddenProcess shared type

`ForbiddenProcess` carries only the matched PID, safe name/image evidence, match source, token position and redacted operation shape across scanners and supervision. Raw argv and environment are not stored.

# Type ForbiddenProcess dùng chung

`ForbiddenProcess` chỉ mang PID, evidence name/image an toàn, nguồn match, vị trí token và operation đã redaction giữa scanner/supervision. Không lưu argv hoặc environment thô.

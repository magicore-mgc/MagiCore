# Shared dependency policy tests

`dependency_policy.rs` tests option-value parsing, the `--` boundary, effective `GOPROXY` precedence and the typed denial's stable message. Language-specific decisions live in `languages/*/test/`.

# Test dependency policy chung

`dependency_policy.rs` kiểm tra parse giá trị option, ranh giới `--`, thứ tự `GOPROXY` hiệu lực và message ổn định của lỗi typed. Quyết định riêng từng ngôn ngữ nằm trong `languages/*/test/`.

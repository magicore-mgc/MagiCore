# Zig policy

Owns the dependency-free exception for the exact `version` query and direct `run <file>.zig` invocation; all package/build and other shapes fail closed.

# Policy Zig

Sở hữu ngoại lệ không dependency cho query `version` chính xác và `run <file>.zig` trực tiếp; mọi dạng package/build hay dạng khác bị chặn fail-closed.

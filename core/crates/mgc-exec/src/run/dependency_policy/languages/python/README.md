# Python policy

Owns `python`/`py` package-manager module blocks and the Python build frontend's `--no-isolation` requirement. Package modules are matched by exact name or dotted submodule.

# Policy Python

Sở hữu chặn module package manager của `python`/`py` và yêu cầu `--no-isolation` cho build frontend Python. Module package được so khớp theo tên chính xác hoặc submodule dạng chấm.

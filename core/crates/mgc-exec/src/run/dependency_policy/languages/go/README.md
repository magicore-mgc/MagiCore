# Go policy

Owns Go module/workspace denial, `GOPROXY=off` and `-mod=readonly` requirements, plus the exact built-in tool version probe. Environment precedence is resolved by the shared dispatcher.

# Policy Go

Sở hữu chặn Go module/workspace, yêu cầu `GOPROXY=off` và `-mod=readonly`, cùng probe version tool tích hợp chính xác. Thứ tự environment do dispatcher chung xử lý.

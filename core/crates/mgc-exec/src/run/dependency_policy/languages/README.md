# Ecosystem policy owners

Each child folder owns only its ecosystem rule, its nearest tests and its README. The parent language facade performs tool-name routing; shared normalization and typed denial display remain in `dependency_policy/`.

# Owner policy ecosystem

Mỗi folder con chỉ sở hữu rule ecosystem, test gần nhất và README riêng. Facade languages định tuyến theo tên tool; chuẩn hóa chung và message lỗi từ chối typed nằm ở `dependency_policy/`.

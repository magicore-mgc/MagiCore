# Runtime invocation tests

The aggregate test file preserves the original four cross-runtime cases under the same mgc-exec test target and covers dispatch integration. Parser-specific edge cases live beside their owner implementations in each owner test/ directory.

File test tổng hợp giữ nguyên bốn case runtime ban đầu dưới cùng test target mgc-exec và kiểm tra điều phối. Edge case riêng từng parser nằm cạnh implementation trong test/ của owner tương ứng.

No test execution is claimed in the source-only phase.

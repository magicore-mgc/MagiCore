# Diagnostic tests

`diagnostics.rs` checks stable timeout/child messages, safe match evidence and audit source retention. `error.rs` checks the audit outcome states. Authored tests remain NOT_RUN until structural completion.

# Test chẩn đoán

`diagnostics.rs` kiểm tra message timeout/child ổn định, evidence match an toàn và giữ source audit. `error.rs` kiểm trạng thái audit. Test đã viết nhưng NOT_RUN đến khi hoàn tất cấu trúc.

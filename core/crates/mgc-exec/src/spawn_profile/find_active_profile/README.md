# Find active profile

Owns exact tuple, schema and lock-digest validation when reading a profile. Missing or stale profiles return `None`; invalid content retains the current typed error.

# Tìm profile đang hoạt động

Sở hữu kiểm tra đúng tuple, schema và lock digest khi đọc profile. Profile thiếu hoặc cũ trả `None`; nội dung lỗi giữ typed error hiện tại.

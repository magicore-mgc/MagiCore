# Parallel task worker

Owns one task's guarded executor call, panic-to-error conversion, first-failure update and optional sibling cancellation signal.

# Worker task song song

Sở hữu lời gọi executor có guard cho một task, chuyển panic thành lỗi, cập nhật fail đầu tiên và tín hiệu hủy sibling tùy chọn.

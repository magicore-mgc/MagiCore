# Invocation policy owners

The parent module keeps the public mgc_exec::policy API stable while each DTO and behavior has a named owner. Mutation classification is kept distinct from read-only probe recognition and profile matching. The resolver is pure and its branch order is security-sensitive.

# Owner policy invocation — tiếng Việt

Module cha giữ ổn định API mgc_exec::policy; mỗi DTO và hành vi có owner được đặt tên. Nhận diện mutation tách riêng khỏi probe chỉ đọc và so profile. Resolver là hàm thuần, thứ tự nhánh ảnh hưởng bảo mật.

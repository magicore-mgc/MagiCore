# Embedded sensitive flag

Owns shell-like token normalization used to detect sensitive flags embedded in a single argv string. It does not rewrite shell syntax.

# Flag nhạy cảm nằm trong chuỗi

Sở hữu chuẩn hóa token dạng shell để tìm flag nhạy cảm nằm trong một argv string. Module không viết lại cú pháp shell.

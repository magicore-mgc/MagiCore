# Cycle-path diagnostics / Chẩn đoán đường cycle

## English

Owns selection and name formatting for the existing diagnostic sequence returned with TopoError::Cycle. It preserves the current first-remaining-node and first-outgoing-edge traversal. It does not validate graph indices or promise a canonical/minimal cycle.

## Tiếng Việt

Quản lý chọn và định dạng tên trong cycle path hiện có của TopoError::Cycle. Giữ nguyên cách lần theo node còn lại đầu tiên và cạnh đi ra đầu tiên. Owner này không kiểm tra graph index và không cam kết cycle chuẩn tắc/ngắn nhất.

# Topological-order errors / Lỗi sắp thứ tự topo

## English

Owns the public TopoError::Cycle variant and its stable Display/Error implementation. The facade re-exports the type through the existing module and crate-root routes. No new variant or retry/recovery classification is introduced.

## Tiếng Việt

Quản lý variant public TopoError::Cycle cùng triển khai Display/Error ổn định. Facade re-export type qua module và crate root hiện có. Không thêm variant hoặc phân loại retry/recovery mới.

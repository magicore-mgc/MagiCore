# Typed-error tests / Test lỗi có kiểu

## English

Tests the public error's rendered cycle path directly. These tests are registered by error/mod.rs and are not part of the workspace integration target.

## Tiếng Việt

Kiểm tra trực tiếp chuỗi cycle path do lỗi public hiển thị. Test được đăng ký tại error/mod.rs và không thuộc integration target workspace.

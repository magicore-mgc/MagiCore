# Topological-order tests / Test sắp thứ tự topo

## English

Nearest-owner tests for Kahn dependency levels, fan-out/diamond graphs, cycle rejection and the empty graph. The local node fixture belongs only to these cases. The workspace integration target retains graph manifest and polyglot manifest scenarios.

## Tiếng Việt

Test gần owner nhất cho level phụ thuộc Kahn, graph fan-out/diamond, từ chối cycle và graph rỗng. Fixture node cục bộ chỉ phục vụ các trường hợp này. Workspace integration target giữ test cạnh graph và manifest đa ngôn ngữ.

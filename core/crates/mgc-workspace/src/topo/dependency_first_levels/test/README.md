# Dependency-first level tests

These tests cover dependent-to-dependency edge orientation, level reversal, independent nodes, and cycle-error preservation. They build in-memory graphs only and do not install packages or execute commands.

## Tiếng Việt

Các test này kiểm tra hướng cạnh dependent-to-dependency, đảo level, node độc lập và giữ nguyên lỗi cycle. Chúng chỉ dựng graph trong bộ nhớ; không cài package hay chạy command.

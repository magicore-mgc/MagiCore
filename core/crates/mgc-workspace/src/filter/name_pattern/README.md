# Package-name wildcard matching / Khớp wildcard tên package

## English

Owns the current two-part name wildcard rule such as *-service and mgc-*. Patterns with a different number of wildcard segments remain unhandled here and fall through to the coordinator's existing exact-name branch.

## Tiếng Việt

Quản lý quy tắc wildcard tên gồm hai phần như *-service và mgc-*. Pattern có số đoạn wildcard khác tiếp tục không được owner này nhận diện và rơi về nhánh exact-name hiện có của coordinator.

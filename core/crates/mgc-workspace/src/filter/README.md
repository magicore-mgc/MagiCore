# Workspace filter / Bộ lọc workspace

## English

Routes the existing package-name and relative-path selector syntax. The coordinator preserves the current precedence; scoped names, partial name patterns, and path globs have focused owners. The crate-root filter_matches function remains the public entry point.

## Tiếng Việt

Điều phối cú pháp lọc theo tên package và đường dẫn tương đối hiện có. Coordinator giữ nguyên thứ tự ưu tiên; scoped name, wildcard tên và glob path có owner riêng. Hàm filter_matches ở crate root vẫn là entry point public.

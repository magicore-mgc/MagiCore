# Filter coordinator tests / Test coordinator bộ lọc

## English

Tests exact-name and empty-selector behavior at the public coordinator entry point. Scoped names, partial name patterns, and path globs are covered by their own nearest-owner test folders.

## Tiếng Việt

Kiểm tra tên chính xác và selector rỗng qua entry point coordinator public. Scoped name, wildcard tên và glob path được kiểm tra trong test folder gần owner tương ứng.

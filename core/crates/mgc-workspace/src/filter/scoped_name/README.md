# Scoped package-name matching / Khớp tên package scoped

## English

Owns the current @scope/* and @scope/** matching rules. Both existing suffix forms keep the same prefix semantics; this extraction does not redefine wildcard depth.

## Tiếng Việt

Quản lý quy tắc khớp @scope/* và @scope/** hiện có. Hai dạng suffix tiếp tục cùng ngữ nghĩa prefix; batch này không định nghĩa lại độ sâu wildcard.

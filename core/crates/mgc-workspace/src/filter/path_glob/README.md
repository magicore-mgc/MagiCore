# Relative path glob matching / Khớp glob đường dẫn tương đối

## English

Owns path normalization and the existing segment glob helpers. A single star matches one path segment; double star uses the current head/tail algorithm. Non-UTF8 lossy conversion and the current multiple-double-star behavior are preserved.

## Tiếng Việt

Quản lý chuẩn hóa path và các helper glob segment hiện có. Một dấu sao khớp một segment; hai dấu sao dùng thuật toán head/tail hiện tại. Cách chuyển lossy cho path không UTF-8 và hành vi nhiều double-star được giữ nguyên.

# Catalog loader tests / Test bộ nạp catalog

## English

Nearest tests for absent config and default/named catalog loading. The tests describe current behavior and are authored but not run in the source-first phase.

## Tiếng Việt

Test gần owner nhất cho config bị thiếu và nạp catalog mặc định/có tên. Test mô tả hành vi hiện tại, mới được viết và chưa chạy trong phase source-first.

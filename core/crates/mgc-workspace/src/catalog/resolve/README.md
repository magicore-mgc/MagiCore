# Catalog specifier resolution / Phân giải specifier catalog

## English

Owns the existing catalog: prefix, whitespace trimming, default alias and named-map lookup. Missing keys and non-catalog strings return None; the resolver does not fetch packages or mutate manifests.

## Tiếng Việt

Quản lý prefix catalog:, trim whitespace, alias default và tra cứu map có tên hiện có. Key thiếu và chuỗi không phải catalog trả None; resolver không tải package và không sửa manifest.

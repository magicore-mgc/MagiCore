# Catalog resolution tests / Test phân giải catalog

## English

Nearest tests for default, named and non-catalog specifiers. They exercise the public resolver contract without performing registry or install operations.

## Tiếng Việt

Test gần owner nhất cho specifier mặc định, có tên và không phải catalog. Test xác nhận hợp đồng resolver public, không gọi registry hay install.

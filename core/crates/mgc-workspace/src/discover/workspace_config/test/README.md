# Workspace configuration tests / Test cấu hình workspace

## English

Tests custom layout parsing through the existing discovery API and rejection of symlinked workspace config. The missing-config default is exercised by the coordinator owner's empty-workspace case.

## Tiếng Việt

Kiểm tra layout tùy chỉnh qua API discovery hiện có và từ chối file cấu hình workspace là symlink. Trường hợp mặc định khi thiếu config được bao phủ tại test coordinator.

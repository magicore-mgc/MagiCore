# Workspace configuration types / Kiểu dữ liệu cấu hình workspace

## English

Owns the existing public DiscoverOptions shape. This type carries the two configured layout paths and adds no parsing or path policy of its own.

## Tiếng Việt

Chứa kiểu DiscoverOptions public hiện có. Kiểu này mang hai đường dẫn layout đã cấu hình, không tự phân tích TOML hay áp dụng chính sách đường dẫn.

# Workspace configuration / Cấu hình workspace

## English

Reads the workspace configuration as a regular non-symlink file and parses the configured apps/packages layout. Missing configuration retains the existing apps/ and packages/ defaults. DiscoverOptions is the existing public data shape returned by this owner.

## Tiếng Việt

Đọc file cấu hình workspace dưới dạng file thường, từ chối symlink và phân tích layout apps/packages. Khi không có config, giữ mặc định apps/ và packages/. DiscoverOptions là kiểu dữ liệu public hiện có do owner này cung cấp.

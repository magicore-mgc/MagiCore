# Workspace layout path safety / An toàn đường dẫn layout workspace

## English

Resolves configured workspace roots below the project and checks entries without following symlinks. It retains the current rejection of absolute paths, parent/root components, symlink traversal, and symlinked workspace directories.

## Tiếng Việt

Phân giải đường dẫn workspace bên trong project và kiểm tra entry mà không đi theo symlink. Owner giữ nguyên cách từ chối đường dẫn tuyệt đối, thành phần parent/root, đường đi qua symlink và thư mục workspace là symlink.

# Workspace path-safety tests / Test an toàn đường dẫn workspace

## English

Keeps project-containment and symlink-refusal scenarios next to the path owner. The tests exercise discovery's existing public route so they cover the coordinator-to-path boundary.

## Tiếng Việt

Đặt các tình huống giới hạn project và từ chối symlink cạnh owner path. Test gọi đường API discovery hiện có để bao phủ cả ranh giới coordinator đến path.

# Discovery coordinator tests / Test điều phối discovery

## English

This directory registers the nearest-owner tests for the public target-discovery composition. The separate owner tests cover config parsing, path containment, recursive scanning, and graph assembly.

## Tiếng Việt

Thư mục này đăng ký test gần nhất cho luồng tổng hợp tìm target qua API hiện có. Test của từng owner riêng bao phủ cấu hình, giới hạn đường dẫn, quét đệ quy và dựng graph.

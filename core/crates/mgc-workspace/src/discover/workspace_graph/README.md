# Workspace graph construction / Dựng graph workspace

## English

Reads package manifests for discovered targets and creates directed edges for dependencies whose specifier begins with workspace:. All four current dependency maps remain included; unresolved workspace package names retain the existing error.

## Tiếng Việt

Đọc manifest package đã tìm được và tạo cạnh có hướng cho dependency có specifier bắt đầu bằng workspace:. Cả bốn nhóm dependency hiện có tiếp tục được xét; tên package workspace không tồn tại vẫn trả lỗi như cũ.

# Workspace project scanning / Quét project trong workspace

## English

Walks configured workspace directories in the existing order, rejects directory symlinks through the path owner, recognizes package.json, and stops descending once a project is found. A local allowlist test covers every established backend manifest name.

## Tiếng Việt

Quét đệ quy thư mục workspace theo thứ tự hiện tại, nhờ owner path từ chối symlink, nhận diện package.json và dừng đi sâu khi đã tìm thấy project. Test allowlist riêng bao phủ các tên backend manifest hiện có.

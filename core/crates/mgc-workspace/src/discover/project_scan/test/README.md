# Project-scan tests / Test quét project

## English

Exercises recursive discovery across apps/packages, nested directories, empty folders, manifest recognition, and sorted target output.

## Tiếng Việt

Kiểm tra discovery đệ quy trong apps/packages, thư mục lồng nhau, thư mục trống, nhận diện manifest và thứ tự target sau sắp xếp.

# CAS extraction API / API giải nén qua CAS

## Responsibility / Trách nhiệm

Keeps the four stable durable/rebuildable CAS extraction entry points and delegates archive staging, destination preparation and publication to focused owners.

## Tiếng Việt

Giữ bốn API giải nén CAS durable/rebuildable ổn định; ủy quyền staging archive, chuẩn bị cây đích và publish cho các owner chuyên trách.

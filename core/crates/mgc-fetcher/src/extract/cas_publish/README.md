# CAS publish and claims / Publish CAS và claim

## Responsibility / Trách nhiệm

Imports staged files, exports verified copies using the selected durability mode, and writes the generation-scoped fail-closed blob claim after both failpoints' original boundaries.

## Tiếng Việt

Import file đã staging, export bản sao đã xác minh theo chế độ durability, rồi ghi claim blob theo generation với fail-closed và giữ nguyên vị trí hai failpoint.

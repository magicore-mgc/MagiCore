# CAS destination tree / Cây đích của CAS

## Responsibility / Trách nhiệm

Creates explicit archive directories and file parents one path component at a time, rejecting symlinks and non-directory ancestors before CAS export.

## Tiếng Việt

Tạo thư mục archive và parent của file theo từng thành phần; từ chối symlink hoặc ancestor không phải thư mục trước khi CAS export.

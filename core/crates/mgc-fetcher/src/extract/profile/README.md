# Fetcher extraction profile / Profile giải nén fetcher

## Responsibility / Trách nhiệm

Prints the existing opt-in timing line for CAS extraction without changing its environment switch, labels or measurement boundaries.

## Tiếng Việt

In dòng timing CAS hiện có khi được bật; giữ nguyên biến môi trường, nhãn và ranh giới đo.

# Extraction error taxonomy / Phân loại lỗi giải nén

## Responsibility / Trách nhiệm

Keeps extraction-local typed failures and their existing display strings; public functions wrap them in `anyhow::Error` while retaining the source chain.

## Tiếng Việt

Quản lý lỗi typed cục bộ và giữ nguyên thông điệp hiện có; API công khai bọc bằng `anyhow::Error` nhưng vẫn giữ chuỗi nguyên nhân.

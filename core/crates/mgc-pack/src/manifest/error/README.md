# Manifest sanitization errors / Lỗi sanitize manifest

Owns typed validation failures, including the fail-closed malformed-`private` case, and their English diagnostics. The public function still returns `anyhow::Result`.

Quản lý lỗi validation typed, gồm trường hợp `private` sai kiểu bị fail-closed, cùng diagnostics tiếng Anh. Hàm công khai vẫn trả `anyhow::Result`.

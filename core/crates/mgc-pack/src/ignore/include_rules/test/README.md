# Include-rule tests

These cases run as modules of the existing `test_ignore` integration target and call the stable public selection API. They verify forced metadata inclusion and rejection of generated/repository path components without exposing the private helper.

READMEVN: Các case chạy trong integration target `test_ignore`, gọi API chọn file công khai; xác nhận file metadata bắt buộc và path luôn bị loại mà không lộ helper private.

# OIDC validation limits

English: Central names for JWT lifetime/size and issuer-cache TTL, refresh interval and capacity.

Tiếng Việt: Tập trung tên giới hạn tuổi thọ/kích thước JWT cùng TTL, chu kỳ refresh và dung lượng cache issuer.

Values and public constant paths are preserved. These are current defaults, not a claim that every value is configurable.

# Issuer claim tests

English: These nearest-owner cases cover only decoding and rejecting malformed/unusable unverified issuer payloads. They do not establish trust or signature validity.

Tiếng Việt: Các ca sát owner chỉ kiểm tra giải mã và từ chối payload issuer chưa xác minh bị lỗi/không dùng được. Chúng không xác thực issuer hay chữ ký.

The public trusted-publishing integration cases remain in `core/crates/mgc-oidc/tests/validation.rs`.

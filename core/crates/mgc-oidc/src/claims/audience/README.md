# Audience model

English: Owns the untagged JSON audience representation and exact membership comparison. `contains` compares strings without normalization.

Tiếng Việt: Sở hữu biểu diễn audience JSON untagged và phép so khớp membership chính xác. `contains` so sánh chuỗi không chuẩn hóa.

Tests cover both the string and array wire forms.

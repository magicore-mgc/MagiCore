# OIDC workload claims

English: Owns the serialized issuer/subject/audience/time/repository/workflow/event fields and `same_workload_identity` equality contract. The comparison intentionally omits audience and token timestamps.

Tiếng Việt: Sở hữu các field issuer/subject/audience/time/repository/workflow/event và hợp đồng `same_workload_identity`. Phép so sánh hiện tại cố ý không xét audience và thời gian token.

All serde names, defaults and public fields are preserved.

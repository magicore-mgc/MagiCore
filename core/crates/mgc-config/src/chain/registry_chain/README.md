# Registry-chain owners / Các owner registry-chain

This owner only wires and exports four behavior boundaries: legacy compatibility, checked resolution, scoped registry data, and registry-chain construction.

Owner này chỉ nối và xuất bốn ranh giới hành vi: tương thích legacy, checked resolution, dữ liệu registry có scope và xây registry-chain.

Each behavior lives in a same-name implementation folder. Public exports preserve the existing mgc_config::chain paths. Tests for URL identity stay beside the builder implementation.

Mỗi hành vi nằm trong folder implementation cùng tên. Public export giữ nguyên đường dẫn mgc_config::chain. Test nhận diện URL đặt cạnh implementation builder.

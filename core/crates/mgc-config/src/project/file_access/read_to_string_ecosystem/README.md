# Project ecosystem loader / Bộ nạp ecosystem project

Composes the safe `mgc.toml` text reader with the TOML ecosystem parser. The composition keeps the `project config` source label and missing-file behavior.

Ghép bộ đọc `mgc.toml` an toàn với parser ecosystem TOML. Owner giữ nhãn nguồn `project config` và behavior khi file chưa tồn tại.

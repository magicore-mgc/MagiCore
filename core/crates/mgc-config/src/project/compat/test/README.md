# Compatibility settings tests

These tests pin the fail-closed default for git dependency resolution, empty host allowlist, field names, and explicit opt-in roundtrip. Host and dependency authorization remain consumer responsibilities.

# Test cấu hình tương thích

Các test khóa default fail-closed khi phân giải dependency Git, allowlist host rỗng, tên field và roundtrip opt-in tường minh. Việc cấp quyền host/dependency vẫn thuộc consumer.

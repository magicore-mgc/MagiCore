# Per-core settings tests

These files pin serde defaults, field spelling, value roundtrips, empty-vector omission, and the corresponding core's scaffold mapping beside its DTO. Broad public `ProjectConfig` API and TOML loading checks remain in `mgc-config/tests/project.rs`.

# Test cấu hình riêng từng core

Các file này khóa serde default, tên field, roundtrip giá trị, contract bỏ qua vector rỗng và mapping scaffold của core tương ứng ngay cạnh DTO. Kiểm tra public API `ProjectConfig` tổng quát và luồng TOML vẫn nằm trong `mgc-config/tests/project.rs`.

# Core marker identity / Identity core marker

Owns core-name canonicalization, accepted-core validation, regular-file marker parsing and cross-checks against `mgc.toml`. The public `ProjectConfig` helper names remain in the owner facade.

Quản lý chuẩn hóa tên core, kiểm tra core được chấp nhận, đọc marker dạng file thường và đối chiếu `mgc.toml`. Các helper `ProjectConfig` hiện có vẫn được giữ ở facade owner.

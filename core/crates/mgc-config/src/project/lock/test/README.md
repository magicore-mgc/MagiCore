# Lock settings tests

These tests pin `None` omission for every optional lock setting and the serialized names/values for explicit signature policy, timeout, grace period, and schema configuration.

# Test cấu hình lock

Các test khóa việc bỏ mọi field lock tùy chọn khi `None` và tên/value serialize của policy chữ ký, timeout, thời gian grace và schema được cấu hình tường minh.

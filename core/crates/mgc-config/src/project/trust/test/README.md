# Trust settings tests

These tests pin the missing-key default and explicit key-ID serialization and roundtrip. Cryptographic trust behavior remains covered by lock verification tests.

# Test cấu hình trust

Các test khóa default khi thiếu key và serialization/roundtrip của key ID tường minh. Hành vi xác minh mật mã tiếp tục được kiểm tra ở test lock verifier.

# Manifest signature owners / Owner chữ ký manifest

This folder contains per-language and shared manifest recognizers used by `core_detection`; the coordinator controls precedence and ambiguity handling.

Folder này chứa bộ nhận diện manifest theo từng ngôn ngữ và logic dùng chung; `core_detection` chịu trách nhiệm thứ tự ưu tiên và xử lý mơ hồ.

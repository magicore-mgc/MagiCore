# Signature content probes

## Purpose

Owns content-based core signature detection: case-insensitive marker matching, dependency-table lookup (including workspace and target-specific tables), and extension scans that reject a matching symlink instead of following it.

## Vietnamese

Sở hữu nhận diện signature core dựa trên nội dung: khớp marker không phân biệt hoa thường, tra dependency table (kể cả workspace và theo target), và quét theo extension từ chối file khớp là symlink thay vì đi theo.

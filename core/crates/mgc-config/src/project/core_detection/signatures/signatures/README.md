# Language recognizer implementations / Triển khai nhận diện ngôn ngữ

This directory holds the focused Node, Rust, Python, Go, JVM, .NET, App, and infrastructure recognizers declared by the sibling `signatures.rs` module.

Thư mục này chứa owner nhận diện Node, Rust, Python, Go, JVM, .NET, App và hạ tầng được khai báo bởi module `signatures.rs` cùng cấp.

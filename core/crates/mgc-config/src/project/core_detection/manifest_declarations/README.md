# Manifest declarations / Khai báo core trong manifest

Coordinates explicit MagiCore core declarations and conflict/known-core policy. Per-manifest parsing lives in `package_json/`, `cargo/` and `pyproject/`; each parser keeps its source-file safety checks and core canonicalization.

Điều phối khai báo core MagiCore tường minh và policy xung đột/kiểm tra core hợp lệ. Parser theo manifest nằm trong `package_json/`, `cargo/` và `pyproject/`; mỗi owner giữ kiểm tra file nguồn và chuẩn hóa core riêng.

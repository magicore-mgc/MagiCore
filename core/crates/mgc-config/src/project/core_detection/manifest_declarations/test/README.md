# Manifest declaration tests / Test khai báo manifest

Tests the cross-manifest aggregation policy: no declaration, deterministic conflicts and unknown-core rejection. Each format's parse/canonicalization tests stay in its own child owner.

Kiểm tra policy gom khai báo nhiều manifest: không có khai báo, xung đột ổn định và từ chối core lạ. Test parse/chuẩn hóa theo format nằm trong owner con tương ứng.

# Cargo core declaration / Khai báo core Cargo

Owns parsing and canonicalization of Cargo's `[package.metadata.magicore].core` field through the shared project-file safety reader.

Quản lý parse và chuẩn hóa trường `[package.metadata.magicore].core` của Cargo qua bộ đọc file project có kiểm tra an toàn.

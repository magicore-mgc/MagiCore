# npmrc owners / Các owner npmrc

This facade preserves `mgc_config::npmrc::{NpmRc, NpmCredential}` while splitting types, loading/merge, parsing, scoped credential matching, lookup and secure token writes. Authentication policy and public routes are unchanged.

Facade này giữ `mgc_config::npmrc::{NpmRc, NpmCredential}` và tách type, load/merge, parse, chọn credential theo scope, lookup và lưu token an toàn. Policy auth và public route không đổi.

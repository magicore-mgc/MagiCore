# lookup owner / Owner lookup

Provides legacy token, host-normalization and registry selection helpers.
Cung cấp tra token cũ, chuẩn hóa host và chọn registry.

The public API and error contract remain on `mgc_config::npmrc::NpmRc`.
Public API và error contract tiếp tục ở `mgc_config::npmrc::NpmRc`.

# parse owner / Owner parse

Parses npmrc key/value lines and expands environment placeholders without spawning npm.
Parse các dòng npmrc và khai triển biến môi trường mà không chạy npm.

The public API and error contract remain on `mgc_config::npmrc::NpmRc`.
Public API và error contract tiếp tục ở `mgc_config::npmrc::NpmRc`.

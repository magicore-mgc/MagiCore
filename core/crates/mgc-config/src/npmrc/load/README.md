# load owner / Owner load

Loads and merges user/project npmrc files. Project values override user values; project symlinks fail closed.
Nạp và gộp npmrc user/project. Giá trị project ghi đè user; symlink project bị chặn.

The public API and error contract remain on `mgc_config::npmrc::NpmRc`.
Public API và error contract tiếp tục ở `mgc_config::npmrc::NpmRc`.

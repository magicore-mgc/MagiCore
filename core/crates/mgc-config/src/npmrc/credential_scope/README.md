# credential_scope owner / Owner credential_scope

Selects the most specific safe URL credential scope and rejects conflicts.
Chọn credential scope URL cụ thể, an toàn nhất và từ chối xung đột.

The public API and error contract remain on `mgc_config::npmrc::NpmRc`.
Public API và error contract tiếp tục ở `mgc_config::npmrc::NpmRc`.

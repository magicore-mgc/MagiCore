# Native Language Profile

This folder owns the standalone runtime profile branches for C, C++, Objective-C, Objective-C++, Zig.

Thư mục này sở hữu các nhánh runtime profile độc lập cho C, C++, Objective-C, Objective-C++, Zig.

`native_language_profile.py` contains the implementation; `__init__.py` only exports it.

`native_language_profile.py` chứa phần triển khai; `__init__.py` chỉ export API.

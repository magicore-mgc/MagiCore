# Web Language Profile

This folder owns the standalone runtime profile branches for Dart, Go, JavaScript, Python, Rust, Swift, TypeScript.

Thư mục này sở hữu các nhánh runtime profile độc lập cho Dart, Go, JavaScript, Python, Rust, Swift, TypeScript.

`web_language_profile.py` contains the implementation; `__init__.py` only exports it.

`web_language_profile.py` chứa phần triển khai; `__init__.py` chỉ export API.

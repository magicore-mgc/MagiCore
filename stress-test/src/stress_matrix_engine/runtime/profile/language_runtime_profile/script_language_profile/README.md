# Script Language Profile

This folder owns the standalone runtime profile branches for GDScript, PHP, Shell, Terraform HCL.

Thư mục này sở hữu các nhánh runtime profile độc lập cho GDScript, PHP, Shell, Terraform HCL.

`script_language_profile.py` contains the implementation; `__init__.py` only exports it.

`script_language_profile.py` chứa phần triển khai; `__init__.py` chỉ export API.

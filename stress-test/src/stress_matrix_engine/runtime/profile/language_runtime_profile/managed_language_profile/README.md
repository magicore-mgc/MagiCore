# Managed Language Profile

This folder owns the standalone runtime profile branches for C#, Java, Kotlin.

Thư mục này sở hữu các nhánh runtime profile độc lập cho C#, Java, Kotlin.

`managed_language_profile.py` contains the implementation; `__init__.py` only exports it.

`managed_language_profile.py` chứa phần triển khai; `__init__.py` chỉ export API.

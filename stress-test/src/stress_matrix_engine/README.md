# Stress Matrix Engine

Provides the decomposed, behavior-preserving owners for the cross-framework stress runner.

Cung cấp các owner đã tách của runner stress nhiều framework, giữ nguyên hành vi hiện tại.

stress_matrix_engine.py is the compatibility export facade; focused behavior belongs to documented child owners.

stress_matrix_engine.py là facade export tương thích; behavior nằm trong owner con có README riêng.

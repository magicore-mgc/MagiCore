# Runtime Health

This folder classifies the store doctor checks for the declared store scope.

Thư mục này phân loại các kiểm tra store doctor theo scope đã khai báo.

`runtime_health.py` owns the classification; `__init__.py` only exports it.

`runtime_health.py` sở hữu phần phân loại; `__init__.py` chỉ export API.

# Data Collection

This folder owns the data collection responsibility for the stress-matrix command.

Thư mục này sở hữu trách nhiệm data collection của lệnh stress-matrix.

`data_collection.py` contains the implementation; `__init__.py` only exports it.

`data_collection.py` chứa phần triển khai; `__init__.py` chỉ export API.
